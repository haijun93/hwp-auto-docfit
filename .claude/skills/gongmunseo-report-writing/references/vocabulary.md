# 어휘 뉘앙스 사전 (「칼퇴를 위하여 2 — 오늘은 내가 요리사」 기반)

정부보고서·연설문에서 자주 쓰이는 단어들을 기능별로 묶고, 사전적 의미가 비슷해도 실제 어감·쓰임이 어떻게 다른지 정리한다. 모두 최근 정부 보고서·대통령 연설문을 원산지로 삼아 재구성한 표현이다.

## 1. 필요하다류 — 정책 추진의 동기를 간접적으로 설명

| 단어 | 뜻 | 뉘앙스 |
|---|---|---|
| 필요 (대표) | 반드시 요구되는 바가 있음 | 가장 무난. "무엇이 필요한지"를 구체적으로 밝히며 쓴다. 정부가 쓸 때는 외부에 요구하기보다 **스스로의 다짐**을 표현하는 경우가 많다 (정책추진의 방향·방법·태도에 흔히 붙음). |
| 필수 | 꼭 있어야 하거나 하여야 함 | 여러 정책 중 **더 중요한 것을 선별**하는 느낌. "지금 필요한 게 여럿인데, 그중 A가 필수적이지!" |
| 절실 | 느낌·생각이 뼈저리게 강렬함 | 필수와 거의 같으나 '뼈저리게'라는 감정적 강도가 더해짐. |
| 요구 | 필요에 의하여 달라고 청함 | "요구가 있으므로 필요를 느낀다"는 논리. 정부 자신에게 요구한다는 관점(다짐)으로도 쓰임. |
| 강구 | 대책·방법을 궁리하여 찾아냄 | 필요보다 **역동적**. 대책·방법에 초점, 속도·범위·방식과 잘 어울림("조속히/신속히 강구"). |

주의: "필요"류 단어를 계속 반복하면(필요·필요·필요) 듣는 사람이 피로해진다. 다양화할 것.

## 2. 중요하다류 — 행위의 정당성 확보

| 단어 | 뜻 | 뉘앙스 |
|---|---|---|
| 중요 (대표) | 귀중하고 요긴함 | "정말 중요할 때만" 써야 힘이 산다. 매우/더욱/가장과 잘 붙음. |
| 핵심 | 가장 중심이 되는 부분 | **객관적** 느낌(과학·사실 서술에 잘 쓰이는 단어라서). "가장"의 의미가 이미 내포되어 비교급(~보다) 대신 단독으로 씀. |
| 역점 | 심혈을 기울이거나 쏟는 점 | 핵심보다 **주관적**, 의지가 담김. "~에 역점을 두다" |
| 긴요(하다) | 꼭 필요하고 중요하다 | '긴급'이 아니라 '꼭 필요+중요'라는 뜻에 주의. 실제로는 자주 쓰이지 않는 단어. |
| 열쇠 | 문제 해결의 가장 중요한 요소(비유) | 단정적·강한 느낌 — 연설문에 더 어울림(정치가의 언어). 딱딱하게는 "관건"으로 대체 가능(단, 관건은 재차 강조 수식어와 안 어울림). |
| 계기 | 결정적 원인/기회 | 실제로는 '기회'에 가깝게 흔히 쓰임. "재도약의/초석의/협력의/성과 창출의 계기" 조합을 눈여겨볼 것. |
| 선결과제 | 다른 문제보다 먼저 해결해야 하는 문제 | 외부에 대한 **요청**의 의미. (1)중요성 강조 (2)사회적 합의 등 조건부 단서를 달 때 사용. |
| 전제조건 | 성립을 위해 앞서 이루어져야 하는 조건 | 선결과제보다 **이미 알려진, 수긍하기 쉬운 사실**을 재확인할 때 어울림. |
| 분수령 | 발전의 전환점(비유) | "지금이 제일 중요해!"를 점잖게 표현. 정부보고서엔 거의 안 쓰고 연설문에 가끔. 중요보다 객관적 느낌. |
| 시대적 과제 | 그 시대에 특징적인 과제 | 거대한 아젠다 설정(부담됨) vs. 이미 진행 중인 흐름을 관찰해 결론 내리는 용법 — 후자가 안전. 오해 소지가 있으면 "글로벌 추세"로 대체. |

## 3. 시급하다류 — "왜 지금인가"

중요한 것과 지금 해야 하는 것은 별개다. 시급성은 "왜 어제도 내일도 아니고 지금인가"에 초점을 둔다.

| 단어 | 뜻 | 뉘앙스 |
|---|---|---|
| 시급 (대표) | 시각을 다툴 만큼 절박하고 급함 | 그 자체로 강조어(몹시)가 있어 수식어 없이 단독 사용 가능. "시급을 요하는 일"로 쓰면 어감이 다소 누그러짐(글자 수는 늘지만 의미는 같음). |
| 절박 | 일이 가까이 닥쳐 몹시 급함 | 시급보다 **주관적/감정적**, 위기상황을 더 강조. 속도감 있는 문맥과 잘 어울림. |
| 지체할 수 없는 / 더 이상 늦출 수 없는 | (부정문으로 시급성 표현) | "마감기한"이 있는 느낌 — 기준점이 뚜렷할 때. 시급하다에는 명시적 기한 개념이 없음. 정부보고서·연설문에 한자어 "지체할 수 없다"가 더 흔함. |

- "지체 없이"는 지체할 수 없는(상태)과 달리 **행위의 속도**를 표현(예: "지체 없이 과제 추진") — 하겠다류의 "가속화"와 연결됨.
- 시급/절박 등을 쓸 때는 반드시 그 근거(왜 급한지)를 함께 제시해야 한다.

## 4. 상황류 — 중립적 상태 설명으로 신뢰 쌓기

중요하다·시급하다로 관심을 끌었다면, 이제 탄탄한 상황 분석으로 신뢰를 쌓는 단계. 상황 설명은 보통 '때·장소'를 구체적으로 밝힐수록 설득력이 커진다.

| 단어 | 뜻 | 뉘앙스 |
|---|---|---|
| 상황 | 일이 되어가는 과정/형편 | "~하고 있는 상황"처럼 문장을 누그러뜨리며 맺는 관용구. 진행형 강조, 또는 객관적 분석 보고 느낌을 줄 때 씀. (참고: "양상"은 진행형 의미가 없어 대체 불가) |
| 확대/축소/증가/감소 | 규모↔수치 변화 | 규모 문제인지 수치 문제인지 구분해서 사용. "감소세 확대", "오히려 증가"처럼 암울한 표현과 잘 어울림. |
| 급변/급증/급감 | 갑작스러운 변화 | 강하고 센 표현 — 강한 정책(구조개혁 등)을 정당화할 때 어울림. 과장되면 신뢰를 잃으니 주의. |
| 직면 | 어떤 일을 직접 당하거나 접함 | "~에 직면"은 구체적 대상과 함께 쓰도록 유도하는 표현. 현재 시점 뉘앙스. (결과·미래 뉘앙스는 "초래", 사건의 발단 쪽은 "야기") |
| 부상/부각 | 관심의 대상으로 떠오름 / 특징지어 두드러짐 | 둘 다 "이미 중요한 것을 재차 강조"할 때도 씀. 부각은 정부보고서, 부상은 연설문에 상대적으로 더 흔함. 부각은 "필요성이 부각"처럼 구체어 없이도 자연스럽지만, 부상은 "필요한 과제로 부상"처럼 구체어와 함께 쓰는 게 자연스러움. |
| 상존 | 아직 그대로 존재함(가능성이 도사림) | "어떤 가능성이 있다/기미가 있다"는 느낌. 경제·외교 분야에서 흔함. (동음이의어 "항상 존재하는 상존"은 잘 안 씀 — 헷갈리므로 "언제나/늘"로 풀어쓰는 게 낫다) |
| 수준 | 기준이 되는 표준·정도 | "세계 최고 수준"처럼 단정을 살짝 완화하는 "약"의 의미로 자주 쓰임. |
| 가능성 | 실현될 성질/정도 | 보통 "가능성이 크다/작다/있다"처럼 지칭어로 쓰지만, 문장을 맺는 설명어로도 쓰임(다만 뭔가 미완결된 느낌이 들어 추천하지 않음). |
| 인식 | 분별하고 판단하여 앎 | 문장 끝에서 **주관적 판단**을 표현. 장기 방향 설정·이해관계자 공동 대응 국면에서 파괴력 있는 단어. |
| 전망/예상/예측 | 미래를 헤아려 내다봄 | 과거(경과)·현황·미래(예측) 중 미래 예측 어휘는 한정적이므로 수식어 조합으로 다양화. |

## 5. 문제류 — 문제를 "지적"하지 않고 "느끼게" 한다

핵심 원칙: **"~것이 문제입니다"로 문장을 맺지 않는다.** "문제"는 목차/맥락상 이미 암시되어 있으므로 묵음 처리하고, 사실만 개조식으로 서술한다.
- 예: "민원이 폭주하고 있는 상황" (자연스러움) vs. "민원이 폭주하고 있다는 문제" (부자연스러움) → 그냥 "민원 폭주"로 개조식 처리.
- "문제"라고 꼬집는 것은 상대의 공감을 전제해야 하는 위험한 단정이기 때문에, 정부 언어는 사실만 제시하고 판단은 독자에게 맡기는 쪽으로 발달했다.

| 단어 | 뜻 | 뉘앙스 |
|---|---|---|
| 미흡/부족/부재 | 기준 미달/없음 | 강도: 미흡 < 부족 < 부재(부재는 매우 강한 단어라 실제로는 잘 안 씀). **반드시 비교 기준을 함께 제시**해야 설득력이 생긴다(국민 눈높이, 국제기구 권고 기준 등). |
| 악화 | 형세가 나쁜 쪽으로 바뀜 | 앞에 오는 대상은 중립어가 자연스러움("여건/상황/지표가 악화"). 이미 부정적인 대상엔 "심화"가 더 자연스러움("양극화 심화"). |
| 부진/여전 | 기세가 활발하지 않음 / 전과 같음 | 부진은 **숫자로 나타낼 수 있는 것**(수출·실적·성적·지표)과 잘 어울림 — 기대치보다 낮은 숫자. 여전은 원래 중립 단어지만 부정적 표현 뒤에 붙어 부정적으로 읽힘. 부진↔호조 대비쌍으로 자주 쓰임. |
| 위축 | 힘에 눌려 졸아듦 | **활동적인 대상**과 잘 어울림(경제활동·법집행 등). 정적인 명사엔 "활동"을 붙여야 자연스러움("교육 위축"(X) → "교육활동 위축"(O)). |
| 한계 | 실제 작용 가능한 범위의 선 | 어디에나 잘 붙지만, **어떤 면에서 한계인지** 명시해야 글이 산다("경제 성장에 한계"). |
| 곤란 | 사정이 몹시 딱하고 어려움 | 한계와 비슷하나, 한계는 상태, 곤란은 그로 인한 **처지/결과**. "한계에 다다라 곤란을 느낀다"는 인과 관계로 이해. |
| 우려 | 근심·걱정 | "이런 문제가 있다!"가 아니라 "있을 수도 있지 않을까?"의 조심스러운 톤. "상존"과 비슷하나, 상존은 장밋빛 상황이 전제될 때 더 자연스럽고, 우려는 부정적 방향이 더 심화될까 걱정할 때도 쓸 수 있음. |
| 만연 | 나쁜 현상이 널리 퍼짐(비유) | "나쁜 현상"이 지칭어로 올 때 어울림(예: "악행 만연"). |
| 호소 | 딱한 사정을 간곡히 알림 | 전문적 수치 분석이 아니라 **현장의 목소리**를 담을 때. 정부→국민 방향의 "호소"는 정부보고서엔 거의 안 쓰고 연설문에 가끔. |

## 6. 하겠다류 — 향후 계획·추진 의지 표명

핵심 단어는 "추진"(perform) — 목표를 향해 밀고 나아감. 정책 의지 표명 거의 모든 상황에 쓸 수 있는 만능 단어.

| 단어 | 뜻 | 뉘앙스 |
|---|---|---|
| 신설/도입/마련/수립 | 새로 설치 / 끌어들임 / 헤아려 갖춤 / 이룩하여 세움 | 완전히 대체 가능한 경우도 있으나 어울림이 다름 — 제도는 신설·도입·마련·수립 모두 가능, 로드맵은 수립·마련만 자연스럽고 신설은 어색. |
| 개선/개편 | 고쳐 더 좋게 / 조직을 고쳐 편성 | 개선=더 나아지게 고침(가치판단 내포), 개편=구성을 바꿈(가치중립, 결과적으로 개선을 지향). |
| 전환 | 다른 방향/상태로 바뀜 | 개선·개편과 비슷하나, **방향/방식이 사전에 이미 정해져 있음**(동전 뒤집기 이미지). |
| 강화/확대/확산 | 수준을 높임 / 규모를 키움 / 퍼짐 | 상황류의 확대·증가와 달리 여기서는 **의지 표명**(할 것이다)의 의미. |
| 제고 | 쳐들어 높임 | "~제고"는 추상적 가치(만족도·경쟁력 등)를 높인다는 뜻으로 관용적으로 씀. |
| 육성/양성 | 길러 자라게 함 / 유능한 사람을 길러냄 | 육성=산업·역량 등 포괄적 대상, 양성=주로 '사람(인재)'. |
| 조성 | 무엇을 만들어 이룸 / 분위기·정세를 만듦 | 물리적 조성(공간)과 분위기 조성 모두 가능. |
| 지원 | 지지하여 도움 | 가장 무난한 지원 표현. |
| 정비/조정 | 흐트러진 체계를 정리 / 기준·실정에 맞게 정돈 | 정비=체계를 제대로 갖춤, 조정=기준에 맞춰 손질. |
| 가속화 | 속도를 더함 | "지체 없이"와 연결되는 개념. |
| 검토 | 사실·내용을 분석하여 따짐 | 확정이 아니라 **검토 단계**임을 명시할 때. |
| 유도 | 목적한 방향으로 이끎 | 직접 개입보다 간접적 방식(인센티브 등)을 시사. |

### "OO 추진" vs "OO" 단독 사용 주의
"신설 추진"처럼 동사 뒤에 "추진"을 붙이면 (1) 강력히 추진하겠다는 **의지 강조**로도, (2) 노력은 하되 **결과는 장담 못 한다**는 **톤 조절(책임 회피용 여지)**로도 읽힐 수 있다. 어느 의도로 쓰든, 독자는 대개 "그냥 한다"는 뜻으로 받아들이는 경향이 있으므로 — 정말 결과를 장담할 수 없는 사안일 때만 "추진"을 붙이고, 확정 사안에는 군더더기로 남기지 않는 것이 명료성 원칙에 부합한다.
