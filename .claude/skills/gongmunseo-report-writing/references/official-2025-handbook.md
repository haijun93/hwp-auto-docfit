# 「2025 행정업무운영 편람」 기반 공식 작성규정

이 파일은 사용자가 업로드한 「2025 행정업무운영 편람」(행정안전부)에서 발췌·정리한 **법적 근거가 있는 공식 규정**이다. `vocabulary.md`·`sentence-structure.md`·`logical-writing.md`가 "칼퇴를 위하여" 저자 개인의 문체 노하우(어감·설득력 관점)라면, 이 파일은 「행정 효율과 협업 촉진에 관한 규정」 및 동 시행규칙에 근거한 **강제 규정**이다. **두 내용이 충돌하면 이 파일을 우선한다.**

## 1. 쉬운 공문서 쓰기 (영 제7조제1항·제2항)

공문서는 어문규범에 맞는 한글로, **간결하고 명확하게, 이해하기 쉬운 용어**로 작성해야 한다. 뜻을 정확히 전달하기 위해 필요한 경우에만 괄호 안에 한자·외국어를 병기한다.

### 1) 쉬운 말로 쓰기
- 어려운 한자어·번역투 대신 쉬운 표현: `사용료를 일할 계산하여` → `사용료를 날짜 계산하여`
- 줄임말은 되도록 피하고, 써야 하면 처음 나올 때 풀어쓰고 괄호에 원어 병기: `지자체` → `지방자치단체(이하 지자체)`, `R&D` → `연구 개발(R&D)`
- 외국어 대신 쉬운 우리말: `브로슈어` → `안내서, 소책자`, `뉴노멀 시대` → `새 일상/새 기준`
- 과도한 명사화·번역투·피동 표현 지양: `적극 뒷받침하기 위해` → `적극적으로 뒷받침하기 위해`, `사용 중에 있으나` → `사용되고 있으나`
- 천 원 단위 대신 만 원 단위로: `21,345천원` → `2,134만 5천 원`

### 2) 자주 나오는 순화어 예시 (전체 목록은 국립국어원 '다듬은 말' 참고)
| 어려운 말 | 다듬은 말 |
|---|---|
| 긴요하다 | 아주 중요하다 |
| 제고하다 | 높이다 |
| 금번/금회 | 이번 |
| 익일/익월/익년 | 다음 날/다음 달/다음 해 |
| 당해 | 그, 해당 |
| 상존 | 늘 있음 |
| 용이하다 | 쉽다 |
| 존치하다 | 그대로 두다 |
| 적기 | 알맞은 시기, 제철 |
| 확행 바랍니다 | 꼭 하시기 바랍니다 |
| 만전을 기할 예정이다 | 최선을 다할 예정이다 |
| 가용한 | 쓸 수 있는 |
| 수범 사례 | 모범 사례 |
| AI / R&D / MOU / ICT | 인공 지능(AI) / 연구 개발(R&D) / 업무 협약 / 정보 통신 기술(ICT) |
| 거버넌스 / 액션 플랜 / 로드맵 | 민관 협력·협치 / 실행 계획 / (추진)계획 |
| 스타트업 / 태스크포스(TF) | 창업(초기) 기업, 새싹 기업 / 전담팀, 특별팀 |

> **vocabulary.md와의 관계**: `vocabulary.md`(칼퇴를 위하여 2권)에서 소개한 "긴요/제고/상존/역점" 등은 실제 정부 문서·연설문에 여전히 자주 등장하는 관용적 표현이며, 뉘앙스 학습에는 유효하다. 다만 **대국민 공지·고시·안내문처럼 일반 국민이 읽는 문서**에는 이 표의 쉬운 말을 우선 적용한다. 내부 결재용 보고서·정책보고서에서는 관용적 표현을 써도 무방하나, 과도한 한자어·번역투는 피한다.

### 3) 어문 규범(두음법칙 등)
- `남여`(X) → `남녀`(O), `백분율`(O, `률`이 아님 — 모음/ㄴ받침 뒤엔 `율`), `회계 년도`(X) → `회계 연도`(O, '연도'는 독립된 단어)

## 2. 항목의 구분 (규칙 제2조제1항) — 공식 항목기호 체계

문서 내용을 둘 이상의 항목으로 나눌 때는 **다음 순서**를 공식 기호로 쓴다 (필요한 경우 □, ○, -, · 등 특수기호로 대체 가능).

| 구분 | 항목 기호 |
|---|---|
| 첫째 항목 | 1. 2. 3. 4. … |
| 둘째 항목 | 가. 나. 다. 라. … |
| 셋째 항목 | 1) 2) 3) 4) … |
| 넷째 항목 | 가) 나) 다) 라) … |
| 다섯째 항목 | (1) (2) (3) (4) … |
| 여섯째 항목 | (가) (나) (다) (라) … |
| 일곱째 항목 | ① ② ③ ④ … |
| 여덟째 항목 | ㉮ ㉯ ㉰ ㉱ … |

- 특수기호(□, ○, -, · 등)는 전자적 입력·전자화 과정에서 오류가 날 수 있는 것은 피한다.
- **표시위치**: 첫째 항목기호는 왼쪽 기본선에서 시작. 둘째 항목부터는 바로 위 항목 위치에서 오른쪽으로 2타(한글 1자, 영문·숫자 2자)씩 들여쓴다.
- 항목이 두 줄 이상이면 둘째 줄부터 항목 내용의 첫 글자에 맞춰 정렬하거나 왼쪽 기본선에서 시작 — 단, **한 문서 안에서는 방식을 통일**한다.
- 항목기호와 내용 사이는 1타 띄운다.
- **항목이 하나뿐이면 항목기호를 부여하지 않는다.**
- 가독성을 위해 본문 항목 사이 위아래 여백은 자유롭게 조정 가능(줄 띄우기 포함).

> **1페이지 간단 보고에서 □를 최상위로 쓰는 관행**은 「보고서·계획서」 형식(내부결재용, 발신 불필요)에서 흔히 쓰는 특수기호 방식이며 공식 항목기호(1./가./1)…)의 대체 표기로 허용된다. 다만 **정식 기안문·시행문**(수신자에게 발신하는 문서)에서 본문 항목을 나열할 때는 위 표의 `1. → 가. → 1) → 가)` 순서를 기본으로 따른다.

## 3. "끝" 표시 (규칙 제4조제5항)

- 본문 내용의 마지막 글자에서 **2타(한 글자) 띄우고 "끝."** 표시. 예: `…주시기 바랍니다.∨∨끝.`
- 첨부물(붙임)이 있으면 붙임 표시문 다음에 2타 띄우고 "끝." 표시. 예: `붙임 1. 서식승인 목록 1부.\n    2. 승인서식 2부.∨∨끝.`
- 본문/붙임 표시문이 오른쪽 한계선에서 끝나면, 다음 줄 왼쪽 기본선에서 2타 띄우고 "끝." 표시.
- 본문이 **표로 끝나는 경우**: 표의 마지막 칸까지 작성됐으면 표 아래 왼쪽 기본선에서 2타 띄우고 "끝." 표시. 표 중간에서 기재사항이 끝나면 "끝." 대신 다음 칸에 **"이하 빈칸"** 표시.

## 4. 붙임(첨부) 표시

- `붙임∨∨○○○계획서 1부.∨∨끝.`처럼 붙임 항목이 하나면 한 줄로, 여러 개면 번호를 매겨 나열.
- 붙임은 본문 다음에 바로 이어 쓰거나 한 줄 띄워 써도 무방.
- 계산서·통계표·도표 등 작성 책임을 밝힐 필요가 있는 첨부물에는 여백에 작성자를 표시.

## 5. 숫자·날짜·시간·금액 표기 (영 제7조제4항·제5항, 규칙 제2조제2항)

- **숫자**: 아라비아 숫자로 표기.
- **날짜**: 연·월·일 글자를 생략하고 마침표로 표기. `0`은 표기하지 않는다.
  - `2021.12.12.`(X) → `2021. 12. 12.`(O, 마침표 뒤 한 타 띄움)
  - `1985.09.06.`(X) → `1985. 9. 6.`(O, `0` 생략)
- **시간**: 24시각제, 시·분 글자 생략, 쌍점(:)으로 구분. `오후 3시 20분`(X) → `15:20`(O)
- **금액**: 아라비아 숫자로 쓰고, 숫자 다음 괄호 안에 한글 병기. `금113,560원(금일십일만삼천오백육십원)`

## 6. 용지·기타

- 문서 작성 용지는 기본적으로 A4(가로 210mm×세로 297mm) 직사각형 규격.
- 개방형 문서 형식(hwpx, odt, docx 등) 사용 권장, 표에서 셀 병합·대각선 등 복잡한 편집은 지양(기계 판독성 저하).
- 화살표 등은 도형 삽입 대신 유니코드 특수문자(→, ⇨, ⇒) 사용 권장.

## 7. 참고: 이해하기 쉬운 작성을 위한 추가 원칙 (규칙 제2조제3항 관련)

- 읽기 쉽고 알기 쉬운 용어 사용, 불필요한 전문용어·한자 남용 지양.
- 특정 집단(성별·지역·인종·장애 등)을 차별하는 표현 삼가기: `결손가정`, `학부형` 등 지양.
- 문맥상 불필요한 인적 정보(성별·나이 등)는 삭제.
