# 문장 구조·명료성 원칙 (「칼퇴를 위하여 3 — 영업사원」, 「4 — 밤중일기」 기반)

## 1. 모든 문장은 A + B (지칭 + 설명)

정부보고서 개조식 문장은 대부분 다음 구조를 갖는다.

```
[기대효과/전제 (A)] + [행위 (B)]
예: "고질적인 병폐를 뿌리 뽑기 위해(A), OO법 개정 추진(B)"
```

- **꼭 전달할 메시지는 마지막(B)에 온다.** "한 문장을 들으면 결국 마지막 단어가 남더라."
- 단, 무조건 강조어를 뒤로 보낸다고 문장이 좋아지는 건 아니다. 예: "조직문화 만족도 제고를 위해, 수·금요일 정시퇴근 추진"에서 "조직문화 만족도 제고"는 이미 앞선 문장에서 나온 표현의 중언부언일 수 있다 — 정말 새로운 정보/행위가 B에 오도록 설계해야 한다.
- A 없이 B(행위)만 있고, B 앞에 단어만 나열해 수식하는 방식(괄호에 단어만 채워 넣는 식)은 주의. 왜 그 행위를 하는지(A)가 분명한, 구체적인 배경 설명이 뒷받침되어야 한다.

### A+B 연결어: 동적 표현 vs 정적 표현

| 구분 | 형태 | 예 |
|---|---|---|
| 동적(용언형) | ~하고, ~하려고(성공하려고) | "다이어트에 성공하려고, 매주 운동" |
| 정적(체언형) | 명사+"을 위해" | "다이어트 성공을 위해, 매주 운동" |

- 보고서는 보통 **정적** 표현(개조식)을 선호하지만, 강하고 직접적인 메시지를 전달할 상황에서는 **동적** 표현을 섞어 쓰는 것도 전략이다. 힘 있게 직접 말할 상황과 그 반대 상황을 구분하는 것이 핵심.
- 인과관계: "~로 인해/~때문에"(원인) vs "행위+하고/한다"(결과) — 동적/정적 톤에 맞춰 선택.
- 비교/대조: "~는 상승, ~는 상승"(비교) / "~는 증가, 반면 ~는 감소"(대조)

## 2. 명료성(clarity)과 경제성(economy) — 공무원 언어의 두 지향점

공무원의 말은 "불필요한 오해를 피하는 것"이 핵심 특징이다. 이는 역설적으로 두 방향으로 나타난다.
1. **명료성**: 확실한 것은 분명하게 — 언어를 간결하게 쓸수록 자연히 경제성도 따라온다.
2. **모호성**: 확실하지 않은 것은 일부러 모호하게 — 단, 이 스킬은 명료성 쪽을 기본값으로 삼는다.

### 명료화 연습: 한 문장에 필요한 정보를 순서대로 채워 넣기

막연한 문장은 "누가/언제/어디서/무엇을"이 빠져 오해를 부른다. 필요한 조건을 하나씩 추가하며 구체화한다.

```
1단계: 사람은 지하철 무료  (주관적, 위험)
2단계: OO 기준으로 측정한 사람은 지하철 무료  (기준 추가)
3단계: (오후 2시 기준) 기준을 충족한 사람은 지하철 무료  (시점 추가)
4단계: 내년부터, 전국의 모든 지하철에서 무료  (시행 시점·범위 추가)
```

- 강조할 내용과 덜 중요한 정보를 구분해 배치를 조정한다(중요한 정보는 크게, 덜 중요한 정보는 괄호로 작게 처리하는 방식도 있음).

## 3. 개조식 = "무엇을 개조(改造)하는가"

개조식은 문장을 통째로 쓰지 않고 핵심만 나열하는 방식이다. 완결된 "~하고 있다"를 명사형/명사구로 응축한다.
- "민원이 계속 폭주하고 있는 상황" → 개조식으로는 "민원 폭주" 또는 "민원 폭주 중"처럼 압축 가능.
- 문장을 "~하는 상황"으로 길게 늘이면 어감이 누그러지고 객관적 분석 보고 느낌이 생긴다(글의 경제성 관점에서는 군더더기일 수 있으나, 의도적으로 생동감을 죽여야 할 때는 유효한 선택).
- 한 줄에 2~3개 문장을 욱여넣지 않는다 — 개조식 한 항목엔 하나의 메시지만 담는다.

## 4. 연결어 사용

- 정지형(개조식 문장을 명사형으로 끝맺는 방법)과 "~형"/"~화" 같은 접미사 활용을 적재적소에 쓴다.
- 앞에 괄호((안), (가칭), (2026년), (1), (현황) 등)를 붙이는 관행은 형식(formatting.md 참고)과 맞닿아 있으니 서식 규칙을 함께 확인한다.

## 5. 결과 vs 발단: 초래·야기·직면의 구분

- **직면**: 지금 당장 눈앞에서 마주함 (현재 시점 뉘앙스)
- **초래**: 결과로서 무엇을 불러옴 (미래/결과 뉘앙스)
- **야기**: 사건을 끌어 일으킴 (발단 뉘앙스)
