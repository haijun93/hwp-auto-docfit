# v1.80.12 — 2026-10-26

표 템플릿 UI의 좌측 분류 버튼 컴팩트화, 좌우 분할 창의 유연한 조절(드래그 스플리터), 그리고 갤러리 전체의 자유로운 위·아래 스크롤을 적용한 긴급 릴리즈 버전입니다.

## 새로 된 점

- **좌측 분류 칩 버튼 컴팩트화 (상단 메뉴와 동일 크기 적용)**:
  - 기존 거대 ChoiceChip으로 인해 8줄 이상 화면을 가득 채우던 분류 버튼들을 상단 메뉴와 동일한 **높이 28px, 텍스트 글자 수 비례 너비, 4px 간격**의 컴팩트 버튼으로 전면 리뉴얼했습니다.
  - 분류 영역이 기존 대비 70% 이상 축소되어 2~3줄로 촘촘하게 정돈되며, 하단 갤러리 카드를 위한 화면 공간이 대폭 확보되었습니다.
- **좌·우 분리 창 유연 조절 (드래그 스플리터 탑재)**:
  - 좌측 갤러리와 우측 조판 미리보기 사이의 고정 분할선을 **실시간 마우스 드래그로 조절 가능한 스플리터**(`MouseRegion(resizeColumn)`)로 전환했습니다.
  - 마우스 드래그로 좌우 폭을 자유롭게 늘리고 줄일 수 있으며, 스플리터 더블 클릭 시 기본 최적 비율(42%)로 즉시 초기화됩니다.
- **전체 위·아래 자유 스크롤 (CustomScrollView & Scrollbar)**:
  - 검색창·분류 칩·템플릿 카드가 각각 따로 고정되지 않고, **전체 갤러리 영역이 하나의 연속된 스크롤 표면**으로 부드럽게 위아래 이동하도록 `CustomScrollView` 및 상시 표시 스크롤바(`Scrollbar(thumbVisibility: true)`)를 전면 적용했습니다.
  - 우측 미리보기·조작 패널 역시 전용 스크롤바를 통해 마우스 휠 및 드래그로 자유롭게 상하 이동이 가능합니다.
