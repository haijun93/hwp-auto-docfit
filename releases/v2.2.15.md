# v2.2.15 릴리스

HWP AutoDocFit 2.2.15 릴리스 안내입니다.

## 바뀐 점

### 사이드메뉴

- 사이드메뉴 맨 위에 '새문서' 버튼을 추가했습니다. 누르면 스냅샷 서식 고르기 창이 열리고, 고른 서식을 한/글에서 새 문서로 엽니다.
- 개발자 모드: 사이드메뉴만 보이는 '사이드메뉴 모드'를 추가했습니다. 화면 왼쪽 또는 오른쪽 가장자리에 붙어 항상 위에 표시되며, 설정 버튼 아래의 버튼으로 켜고 끕니다. '항상 위' 버튼도 함께 추가했습니다.
- 개발자 모드: '자료함' 버튼을 추가했습니다. 4.0에서 완성할 가상 관계형 자료함(4분면 화면, 파일 끌어 놓기·붙여넣기로 자료 추가)을 미리 쓸 수 있습니다.

### 타임머신 검색

- 새 '본문검색': 모든 사용자가 쓸 수 있는 키워드 검색입니다. 관련도순(BM25)으로 정렬하고, 2글자 검색과 여러 단어 검색을 지원하며, 일치 위치를 미리보기로 보여 줍니다(3,000건 기준 0.4초 안팎).
- 기존 위계 중심 검색은 '연관검색'으로 이름을 바꾸고 개발자 모드에서만 보입니다.

### 몽땅클립보드

- 메모를 바로 입력해 클립보드 항목으로 추가할 수 있습니다. 파일을 끌어다 놓아 항목을 추가할 수 있습니다.

### 공문서 위계 분석 엔진(개발 2단계)

- 번호·기호 계열 목록 작성과 계열 순서 추정을 Rust 코어에 추가했습니다. 아직 앱 동작에는 연결하지 않았습니다.

Python 3.14 기반으로 빌드합니다.
