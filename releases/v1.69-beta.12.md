# 한글편집 후처리 도구 v1.69 Beta 12

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- **서식 통일 카드에 옵션 3가지 추가** (모두 기본 꺼짐, 고른 값을 기억)
  - 표 제외: 기본 표 서식·표 서식통일을 뺍니다.
  - 자간 정리 제외: 서식통일이 서식을 고친 문장의 자간 조정·외톨이 글자 당기기를 하지 않습니다(내어쓰기는 맞춤).
  - 페이지 맞춤 제외: 문단 아래 간격 페이지 맞춤과 관련 문단 페이지 배치를 뺍니다.
- **한 번에 적용 카드에 '페이지 맞춤 제외' 추가** (기본 꺼짐): 문단 아래 간격 페이지 맞춤과 관련 문단 페이지 배치를 뺍니다.
- **자간 정리 카드의 '표 내 자간 정리'를 '표 제외'로 변경** (기본 꺼짐): 켜면 표 칸 안 문장은 자간 정리에서 뺍니다. 동작은 같고 켜고 끄는 방향만 반대입니다.
- **서식통일 뒤 '작업 결과 확인' 창을 기본으로 띄우지 않음**: 결과는 처리 기록과 최종 검수 보고서에 남습니다. 설정창 '검토와 작업 완료'에서 다시 켤 수 있습니다.
