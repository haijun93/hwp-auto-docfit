# v2.2.6 릴리스

HWP AutoDocFit 2.2.6 릴리스 안내입니다.

## 바뀐 점

### 엑셀 표를 한/글 표로

- 몽땅클립보드 관리 화면의 「엑셀 표를 한/글 표로」로 복사한 셀을 한/글 표로 바꿉니다. 한/글에서 Ctrl+V 하면 됩니다.
- 글자 바탕색, 앞뒤·연속 빈칸, 특수 공백, 제어 문자, 맨 앞 작은따옴표를 없앱니다.
- 병합, 열 폭 비율, 굵게, 정렬, 칸 배경색, 보이는 숫자 형식(1,234·87.5%)과 칸 안 줄바꿈을 유지하고 표 폭을 본문에 맞춥니다.

### 몽땅클립보드

- 스티커 메모처럼 씁니다: 크기 조절, 접기, 모두 지우기, 줄마다 고정·삭제.
- 화면캡처: 「캡처」 단추를 넣고 같은 캡처가 두 번 기록되지 않게 했습니다. 스크린샷 폴더 감시는 기본으로 켜집니다.
- 항목을 오른쪽 클릭해 기본 프로그램 또는 고른 프로그램으로 엽니다(그림·글·파일).
- 웹주소와 웹페이지에서 복사한 글은 기본 브라우저로 원래 페이지를 엽니다.
- 한/글·엑셀 내용을 서식 형식까지 함께 저장해 다시 붙입니다(항목당 32MB까지).

### 파일명 일괄변경

- 가운데 구분선을 끌어 칸 크기를 조절하고, 창 크기에 맞춰 칸이 함께 늘고 줄어듭니다.

Python 3.14 기반으로 빌드합니다.

## 배포 검증

- CI 실행 41480666203 통과(Python 3.14, Python 회귀 2041건, Flutter 255건). 스플래시 58.75ms, 웜 시작 1,629·1,679ms(기록만, v2.2.5와 차이 없음).
- 배포 exe 시험: 내려받은 Portable·Setup의 SHA-256이 릴리스 값과 일치, 화면 내용 시험 통과(화면 오류 0건), 실행 중 파일 이름 변경 전달 확인. 개발 작업이 함께 돌던 PC에서 첫 화면은 31,001ms·21,947ms로 측정되었습니다.
- 엑셀→한/글 표: 실제 Excel에서 복사해 실제 한/글에 붙여 그림으로 확인(병합, 열 비율, 굵게, 칸 배경색, 정렬, 숫자 형식, 칸 안 줄바꿈 유지, 빈칸 제거).
- 몽땅클립보드: Rust 시험 38건 통과.

## 알려진 문제

- 몽땅클립보드의 스티커 창 조작, 캡처 단추, 연결 프로그램, 서식 왕복, 브라우저 출처 열기는 실제 창에서 시험하지 않았습니다. 켜 둔 에이전트와 잠금이 같아 함께 띄우지 못했습니다. 저장 형식이 바뀌었으니 문제가 있으면 알려 주세요.
- 파일명 쉬운 화면과 구분선은 위젯·코어 시험만 거쳤습니다.
- 서식 복사 재연의 표 높이(8082→5982)와 쪽 여백 차이가 남아 있습니다(사용자 수정 파일 대기).
