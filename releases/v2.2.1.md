# v2.2.1 릴리스

HWP AutoDocFit 2.2.1 릴리스 안내입니다.

## 바뀐 점

### 서식 규칙

- 항목기호 바로 뒤에 「가 오면 빈칸을 두지 않습니다(예: `ㅇ「법령」 개정`). 번호 항목은 빈칸 1칸입니다(`2. 「법령」`).
- 문서 끝 붙임 목록: `2.` 이후 번호를 붙임 뒤 숫자 1 위치에 맞추고, 꺾인 줄은 번호와 빈칸 뒤 본문 첫 글자에 맞춥니다.
- 번호 항목의 내어쓰기를 최종 서식에서 실제 Shift+Tab 값으로 맞춥니다. 서식 복사의 고정 값도 같습니다.

### 보안

- PDF 처리 라이브러리 pypdf를 6.21.4로 올렸습니다.

Python 3.14 기반으로 빌드합니다.
