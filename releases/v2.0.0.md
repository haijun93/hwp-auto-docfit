# v2.0.0 — 2026-10-28

HWP AutoDocFit 2.0.0 정식 릴리즈 안내입니다.
본 버전은 한컴오피스 HWP/HWPX 문서의 자동 조판과 서식 맞춤을 차세대 통합 단일 셸 및 멀티 AI 에이전트(Codex, Claude, DeepSeek-R1) 협업 검증 엔진으로 전면 업그레이드한 대규모 메이저 업데이트입니다.

## 🌟 주요 변경 사항

### 1. 차세대 통합 단일 셸 워크스페이스 (Flutter 6-Tab)
- `IntegratedWorkspace` 및 `TabNavigationShell` 기반의 6개 탭 구조 정식 안착.
  - 탭 1: 자간/행간 자동 맞춤 (AutoDocFit Core)
  - 탭 2: 표 단위 서식기 (Table Units)
  - 탭 3: 표 그림판 (Table Sketch)
  - 탭 4: 다이어그램 에디터 (Diagram Editor)
  - 탭 5: 마인드맵/흐름도 에디터 (Flow Editor)
  - 탭 6: 공공 서식 도구함 (Tools Workspace)
- 영구 탭 마운트 시 `CloseGuards` 창 닫기 거부권 충돌 방지를 위한 `isModal: false` 수명주기 디커플링 완료.

### 2. 한글 타이포그래피 및 조판 규칙 대폭 강화
- **TODO 76~82 (표 셀 줄간격 및 자간 정책 개편)**:
  - 표 셀 줄간격 최소 100% (`table_linespacing_min`), 자간 최소 -25% (`table_spacing_min`) 정책 안착.
  - 기존의 레거시 `넓은_표칸(20자)` 예외 분기를 완전 폐기하여 일관된 표 셀 가독성 확보.
- **TODO 96 (원문자/항목기호 콜론 후속 자동 들여쓰기)**:
  - 원문자(`①~⑳`), 번호(`1.`), 한글 항목기호 뒤에 전각/반각 콜론(`:`, `：`) 또는 무공백 콜론(`①사업목적:인공지능`)이 올 때 후속 행 본문 시작점을 콜론 뒤 위치로 자동 정렬.
