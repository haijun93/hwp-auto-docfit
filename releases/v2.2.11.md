# v2.2.11 릴리스

HWP AutoDocFit 2.2.11 릴리스 안내입니다.

## 바뀐 점

### 엑셀 표를 한/글 표로

- 「칸 배경색 빼기」를 고르면 칸 음영만 빼고 글자색·굵게·병합·정렬은 그대로 옮깁니다(기본은 배경색 유지).
- 엑셀 글자색을 한/글 표에 반영합니다.

### 파일명 일괄변경

- 이름 바꾸기가 중간에 실패하면 임시 이름으로 남은 파일을 원래 이름으로 되돌리고, 되돌리지 못하면 보존 위치를 알려 줍니다.
- 이모지가 들어간 이름의 길이를 Windows 기준으로 정확히 검사합니다.

### 타임머신

- 연관 문서를 기준일이 최근인 순서로 보여 줍니다.

Python 3.14 기반으로 빌드합니다.
