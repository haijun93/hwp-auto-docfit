# 한글편집 후처리 v1.72 Beta 16 (핫픽스)

Windows 64비트용 테스트 베타 릴리스입니다. **본문 글자가 바뀌던 결함 두 가지**를 고친 핫픽스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **숨은 글자가 있는 문단의 글자 훼손 수정**: 고정폭 빈칸처럼 화면 글 읽기에 나오지 않는 글자가 있는 문단에서, 쉼표·콜론·따옴표·공백 정리가 한 칸씩 밀린 위치의 글자를 지우던 문제를 고쳤습니다(예: `구비2,241,275천원,` → `275천, ,`, `주민과의 대화` → `주민과의 ’화`). 이제 실제 글자 위치를 맞춰 고치고, 위치를 맞출 수 없는 문단은 고치지 않습니다.
- **날짜 정리가 시각을 날짜로 보던 문제 수정**: `2026. 10. 4. 15:00`의 `10. 4. 15`를 날짜로 보고 점을 붙여 `15.:00`이 되던 문제를 고쳤습니다. 빠진 끝 점 채우기, 대시 → 물결표, 요일 앞 점 정리는 그대로입니다.
- 용어 **문두기호**를 **항목기호**로 바꿨습니다(화면 글·설명). 예전에 저장한 사용자 서식도 그대로 읽습니다.
- 그 밖의 기능은 Beta 15와 같습니다. 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.
- 안내: Beta 13·14에서 자동 업데이트할 때 `Failed to load Python DLL` 오류가 나면 아래 실행 파일을 직접 내려받아 바꿔 주세요(Beta 15에서 수정된 문제).

\* Beta 15의 해당 규칙 코드는 Beta 11과 같습니다. 숨은 글자를 흉내 낸 시험 문단에서 Beta 15 코드가 `275천, ,`·`비  :` 훼손을 그대로 재현하고, Beta 16은 바르게 처리하는 것을 확인했습니다.
