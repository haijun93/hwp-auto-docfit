# 한글편집 후처리 v1.76.2 베타

## v1.76.1 대비 변경

- TXT·MD→HWPX·PDF·PNG·JPG 변환을 추가했습니다.
- HWPX→TXT·MD 추출을 추가했습니다. 문단·표를 텍스트로 내보내며 글꼴·쪽 배치·그림은 유지하지 않습니다.
- 변환 런타임을 EXE에 포함했습니다. 별도 ZIP 다운로드 없이 첫 실행에 C:\HWP_AUTODOCFIT으로 저장·설치합니다.
- 해당 경로에 쓰기 권한이 없으면 사용자 LocalAppData 폴더로 대체합니다.
- 런타임 설치는 내장 ZIP의 체크섬을 검사하고 오프라인으로 실행합니다.
- TXT는 UTF-8·CP949·UTF-16을 지원하고 MD 목차·표는 내장 Markdown 생성 경로를 사용합니다.
- 원본과 기존 결과를 덮어쓰지 않습니다. 표·그림 복사와 tldraw 제외 정책을 유지합니다.

## 개선 효과 및 검증 범위

- 별도 런타임 다운로드 1회를 제거했습니다. 같은 PC에서의 처리 속도·조판 점수 개선율은 새로 측정하지 않았습니다.
- 실제 엔진의 TXT·MD→HWPX→TXT·MD 왕복 변환을 확인했습니다.
- Python·Flutter 전체 검사와 Windows EXE 실행·버전·내장 엔진 설치/실행 검사를 통과한 산출물로 배포합니다.
- PDF·PNG·JPG는 설치된 한/글이 필요하며 실제 한/글 문서 조판은 별도 실기기 검증 대상입니다.
- OCR 모델과 Pandoc은 포함하지 않습니다. OCR 및 DOCX·EPUB의 기존 추가 도구 조건은 유지됩니다.
