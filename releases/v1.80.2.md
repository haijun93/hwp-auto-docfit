# v1.80.2 — 2026-10-22

파일포맷 변경에 **PDF 압축**을 더한 버전입니다. 메일·전자결재 첨부 한도에 걸리는 PDF를 앱 안에서 바로 줄입니다.

## 새로 된 점

- **PDF 압축**(파일포맷 변경 메뉴의 「PDF 압축」):
  - 재조판 없이 PDF 안의 그림만 다시 저장합니다(쪽 크기 기준 150dpi, JPEG 품질 75). 내용 스트림도 다시 압축하고 같은 객체를 합칩니다.
  - 글자층·쪽 수·쪽 크기·회전은 그대로입니다. 결과를 다시 열어 원본과 쪽마다 대조하고, 다르면 저장하지 않습니다.
  - 흑백 1비트, 투명 마스크, CMYK·색인 그림, 작은 그림은 건드리지 않습니다.
  - 결과는 `원본(PDF압축).pdf`로 저장되며 원본은 그대로입니다. 5% 미만으로 줄면 파일을 만들지 않고 알립니다.
  - 한/글 없이 동작합니다.
- **보안 PDF도 보안 그대로**:
  - 인쇄·복사·수정 제한이 걸린 PDF는 줄인 뒤 원본과 같은 권한값으로 다시 잠급니다(AES-256). 보호가 풀린 사본은 만들지 않습니다.
  - 열기 암호 PDF, 문서보안(DRM) 파일, 전자서명 PDF(다시 저장하면 서명이 무효가 됨)는 줄이지 않고 이유를 알립니다.
- 새 구성 요소: pypdf 6.21.2(BSD-3-Clause).

## 검수

- 시험 PDF(1회 측정, 업무 원본은 쓰지 않음):
  - 스캔형 보고서 3쪽: 2.2MB → 533KB(−76%)
  - 스캔형 12쪽(JPEG 품질 95): 4.2MB → 947KB(−78%)
  - 보안 PDF 12쪽(인쇄만 허용): 4.2MB → 948KB(−78%), 암호화·권한값 유지
  - 한/글로 만든 글자 위주 3쪽(95KB)은 "이미 충분히 작음"으로 파일을 만들지 않음
- 서식 예시 3종 재연: 불일치 0/0/0. 단위 시험 1416개·Flutter 화면 시험 27개 통과.
- 시작 속도(스마트 런처)는 1.80.x와 같이 기록만 합니다.
