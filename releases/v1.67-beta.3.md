# 한글문서 후처리 도구 v1.67 Beta 3

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- 줄 끝에서 갈라진 어절은 마지막 줄에 5자 미만이 남으면 앞줄로 당기고, 그 밖에는 글자 수가 많은 쪽으로 붙입니다(같으면 앞줄). 열거 뒤의 `등`은 바로 앞 어절과 한 어절로 묶습니다(예: `바나나 등으로`).
- 자간을 조정한 뒤 문두기호 문장의 내어쓰기를 다시 적용하고 단어 분리를 재검사합니다(최대 3회, 2차부터는 내어쓰기가 바뀐 문단만). 본문이 `「`·`『`로 시작하면 내어쓰기는 그 다음 글자에 맞춥니다.
- 쪽 맞춤: `□` 논리묶음의 논리단위가 5개 이하이면 묶음 전체를 단위가 많은 쪽(같으면 앞쪽)으로 모읍니다. 줄간격이 한계값이라 한 방향으로 옮길 수 없으면 반대 방향으로 보완합니다.
- 서식 정리: 같은 문두기호의 라벨이 굵게 되면 다른 문단의 머리말도 굵게 맞추고(괄호 설명 제외), 문두기호 문장 사이의 빈 줄을 지워 문단 위 여백으로 대신합니다. 두 기능 모두 설정에서 켜고 끌 수 있습니다(기본 켜짐).
- 저장한 결과물을 다시 열어 쪽 배치·단어 분리를 검사하고, 작업 수행 점수와 판정을 `(최종검수).json`으로 남깁니다. 결과 검사 기능이 없는 세부 작업은 판정을 막지 않고 참고로 표시합니다.
