# 한글편집 후처리 v1.72 Beta 8

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **내어쓰기 종전 방식 복귀**: Beta 5~7의 문두기호별 빈칸 내어쓰기 규칙(ㅇ 1칸·- 3칸을 기호 뒤에 더하던 규칙)을 걷어내고, 둘째 줄을 종전처럼 Shift+Tab(글 시작 위치) 기준으로 맞춥니다.
- **부연설명(`※`·`*`·`**`) 앞 빈칸을 보고서 서식대로**: 문단 왼쪽 끝에서 센 앞 빈칸 수를 위 문장에 따라 맞춥니다.
  - `□` 아래: `※` 4칸 · `*` 5칸 · `**` 4칸
  - `ㅇ`·`-` 아래: `※` 5칸 · `*` 6칸 · `**` 5칸
  - 위에 `□`·`ㅇ`·`-` 문장이 없을 때(번호 항목 아래, 단독 사용): `※` 3칸 · `*` 4칸 · `**` 3칸
  - `**`의 두 번째 별표가 `*`와 세로로 맞으므로 별도의 별표(`**`) 정렬은 하지 않습니다.
- **`-` 앞 빈칸 3칸**: 보고서 서식 문서대로 `-` 문장 앞 빈칸을 2칸에서 3칸으로 바꿨습니다.
- **붙임 번호 위치 수정**: `붙임`이 오른쪽으로 밀리고 `2.`가 `1.` 아래에 오지 않던 문제를 고쳤습니다.
- **붙임 표기 유지**: `붙임  1.`·`붙임 : 1.`·`붙임: 1.`을 모두 허용합니다. 쌍점을 쓴 표기는 사용자가 쓴 그대로 두고, 쌍점이 없을 때만 '붙임' 뒤를 2칸으로 맞춥니다.
- 예전 설정 파일에 `부연설명 들여쓰기`가 꺼진 채 저장돼 있으면 한 번 켭니다. 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.
