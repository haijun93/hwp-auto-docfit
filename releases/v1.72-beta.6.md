# 한글편집 후처리 v1.72 Beta 6

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **붙임 번호 세로 정렬 수정**: Beta 5에서 붙임 번호의 기준 위치를 재지 못해(`매개 변수의 개수가 잘못되었습니다`) 정렬이 통째로 건너뛰어지던 오류를 고쳤습니다. 문서 끝 `붙임`~`끝.` 번호 목록이 첫 번호와 세로로 같은 위치에 맞춰집니다.
- **문두기호별 내어쓰기 빈칸 규칙 보완**: `-`(3칸)·`*`·`**`·`※`(5칸)는 `항세기:`처럼 콜론·괄호 라벨이 붙은 문장도 `기호 끝 + 빈칸 N칸` 위치에 맞춥니다. `ㅇ` 문장은 라벨이 있으면 기존대로 라벨 뒤에 맞춥니다.
- **업데이트 확인 개선**: GitLab과 GitHub를 모두 조회해 더 높은 버전을 알려주고, 한쪽에 접속하지 못해도 다른 쪽으로 확인합니다. 릴리스 응답 형식이 달라도 `'str' object has no attribute 'get'` 오류가 나지 않습니다.
- 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.
