# 한글편집 후처리 v1.71

Windows 64비트용 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- **별표(`*`, `**`) 정렬 독립 단계 분리**: `*`, `**`로 시작하는 부연설명 문단을 독립 단계(`star_align`)로 분리하여 항상 기본 실행되도록 개선했습니다. 상위 항목과의 위치 맞춤 시 음수 여백이 발생하는 경우 앞 빈칸을 자동으로 삭제하여 들여쓰기 위치를 정확히 맞춥니다.
- **페이지 수 맞춤 시 표 셀 세로 여백 연동**: 문서를 세로로 조정(페이지 수 맞춤)할 때 본문 문단 간격뿐만 아니라 표의 셀 세로 여백(`MarginTop`, `MarginBottom`)도 원래 여백에 비례하여 함께 축소되도록 개선했습니다. (목표 쪽수 미달 시 원본 여백으로 완전 복원, 한 칸 표 보호)
- **원상복구 및 초기화 도구(`설치파일 초기화.exe`) 추가**: 앱 실행 시 시스템에 설치/등록되는 보안 모듈 DLL(`C:\HwpAutomation\MapoHwpAutoDocFitSecurity.dll`), 한/글 자동화 레지스트리 키, 사용자 설정 및 캐시 폴더를 깨끗하게 원상복구(삭제)하는 초기화 전용 실행 파일을 함께 배포합니다.
- **통합 압축파일(ZIP) 제공**: 다운로드 3종 파일(메인 프로그램, 설치파일 초기화 도구, 보고서 예시 파일)을 한 번에 내려받으실 수 있도록 `HWP_AutoDocFit-v1.71.zip` 압축파일을 함께 첨부합니다.
