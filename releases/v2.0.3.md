## 바뀐 점

### 1. 그림판 탭(새로 추가)
- 하단 탭 맨 오른쪽에 **그림판**이 생겼습니다.
- 사진을 끌어 놓거나, 「배경 열기」를 누르거나, Ctrl+V로 붙여 넣으면 배경으로 깔립니다. 배경은 맨 뒤에 고정되어 끌어도 움직이지 않고, 「배경 지우기」로만 지웁니다.
- 펜(자유 곡선), 글상자, 도형·선 12가지를 사진 위에 올립니다. 선 색과 굵기를 고를 수 있습니다.
- 올린 것은 모두 따로 된 개체라서 PPT처럼 하나씩 옮기고, 크기를 바꾸고, 글을 고치고, 지울 수 있습니다.
- 「PNG 내보내기」로 그림 파일로 저장하고, 「그림 복사」 뒤 한/글에서 붙여 넣으면 그림으로 들어갑니다.

### 2. 표그림판 올가미와 여러 개체 함께 다루기
- **올가미** 도구로 자유 곡선을 그려 둘러싼 선과 글을 고릅니다. 긴 선은 둘러싼 부분만 골라지고, Shift를 누르고 그리면 더 고릅니다.
- 고른 개체는 함께 끌어 옮기고, 복사·잘라내기·붙여넣기·복제(Ctrl+C/X/V/D), 전체 선택(Ctrl+A), 삭제(Delete), 방향키로 한 칸 옮기기를 할 수 있습니다. 위쪽 선택 줄에서 굵기·선 종류를 한꺼번에 바꿉니다.
- **지우개**가 끌고 지나간 칸만 정확히 지웁니다.

### 3. 표그림판 칸 배경 그림
- 사진을 표 칸 안에 끌어 놓으면 그 칸의 배경 그림이 되어 칸 크기에 맞춰 채워집니다.
- 「칸 그림」 도구로 칸을 고른 뒤 Ctrl+V를 눌러도 됩니다. 칸을 고르고 Delete를 누르면 배경 그림이 지워집니다.
- 한/글에 표로 붙여 넣으면 칸 배경 그림이 한/글의 「그림 채우기」로 함께 들어갑니다.

### 4. 마인드맵 가지 모양과 지도 테마
- 가지 모양 10가지 중에서 고르고, 이 가지만 / 같은 단계 / 하위 포함 / 전체 중 어디까지 바꿀지 정합니다.
- 지도 테마: 모양 5가지(기본·알약·캡슐·밑줄·블록) × 색 8가지 × 바탕 3가지(밝게·어둡게·옅은 색).

### 5. 다이어그램 자석 연결
- 선을 연결점 가까이 가져가면 붙고, 도형 몸체에 놓아도 연결됩니다.
- 연결된 도형을 옮기면 선이 서로 마주 보는 면으로 따라 붙습니다. 이미 그린 선의 끝도 다른 도형으로 다시 붙일 수 있습니다.
- 도형을 끌 때 다른 도형과 가장자리·가운데가 맞으면 빨간 점선이 나타나 맞춰 줍니다.

### 6. 업데이트 안내에 바뀐 점 표시
- 설정의 업데이트 안내에 새 버전의 바뀐 점 제목이 비어 보이던 문제를 고쳤습니다.

## 시험

- Python 단위 시험, Flutter 위젯 시험, 편집기 모델 시험(`diagram_editor`) 모두 통과.
- 실제 앱(소스 실행, WebView2) 화면 시험: 표그림판 올가미 선택·이동·복제, 정밀 지우개, 칸 배경 그림(클립보드 사진 → 칸 → 한/글 붙여넣기 뒤 그림 채우기 확인), 마인드맵 가지 모양·테마, 다이어그램 자석 연결·맞춤 점선, 그림판(사진 배경 → 펜 → 글상자 → 옮기기 → 그림 복사).
