# v2.2.25

## 바뀐 점
- 노트북(개발자 모드): 노트 태그·태그로 거르기, 같은 검색어의 근거를 출처별로 나란히 보는 '여러 출처 비교', Markdown 내보내기에 태그·출처 비교 포함
- 자료함(개발자 모드): 폴더 스캔을 자료함 엔진에서 증분으로(바뀌지 않은 파일은 다시 쓰지 않음), 진행률 표시와 취소, 엔진을 못 쓰면 기존 방식으로 자동 전환
- 표그림판: '이미지에서 표 인식' — 표를 그린 그림(png·jpg 등)에서 가로·세로 선을 찾아 겹쳐 보여 주고 적용/취소, 적용 후 되돌리기 한 번으로 원래대로
- 몽땅클립보드: Excel 표 항목에 '음영 없이 복사'(셀 배경 음영만 빼고 글자색·테두리·병합 유지, 변환 실패 시 원본 그대로)
- 타임머신 연관검색(개발자 모드): 정기 문서 계열(예: 분기별 주요업무추진실적)을 이전·다음 기간 묶음으로 제공(화면 표시는 다음 버전)
- 자료함 검색 내부 정리(동작 변화 없음)
