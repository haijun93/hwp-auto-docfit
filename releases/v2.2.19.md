# v2.2.19 릴리스

HWP AutoDocFit 2.2.19 릴리스 안내입니다.

## 바뀐 점

### 보안

- 자료함 엔진(klib)의 외부 구성요소를 최신 안전 버전으로 바꿨습니다. 알려진 취약점이 있던 구성요소(압축 파일 처리, 캐시, 일본어·한국어 형태소 분석기 등)를 갱신하거나 제거했습니다.
- 한국어 형태소 사전(ko-dic)을 쓰는 선택 기능은 사전 배포 서버가 사라지고 취약점이 있어 뺐습니다. 자료함 본문검색은 2글자 조각·초성·오타 검색으로 그대로 동작합니다.

자료함 기능은 v2.2.18과 같습니다(개발자 모드).

Python 3.14 기반으로 빌드합니다.
