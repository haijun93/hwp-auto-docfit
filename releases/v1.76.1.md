# 한글편집 후처리 v1.76.1 베타

v1.76.0 공개 태그·실행 파일을 보존하고, 이후 병합된 기능을 새 버전으로 배포합니다.

## 이전 버전 대비 개선

- 표 복사: 흐름표·기본 표·조직표·장식표를 HTML 표와 텍스트로 복사해 한/글 2020에서 Ctrl+V로 붙여넣습니다.
- 그림 복사: 자유 도형·마인드맵을 Windows DIB·PNG로 복사합니다.
- HWP→HWPX: 한/글 내장 저장으로 직접 변환하며 원본·기존 결과를 덮어쓰지 않습니다. Node/kordoc이 필요하지 않습니다.
- tldraw 메뉴·설정·SDK 자산을 제외합니다. 일반 표/다이어그램은 유지합니다.
- Windows 짧은/긴 경로의 파일 동일성 검사를 보완했습니다.

## 검증 범위 및 개선 효과

- Python 1,207개 중 통과 1,202·조건부 제외 5, Flutter 69개, JS 15개 통과.
- Chromium에서 표 복사 데이터 및 마인드맵 PNG 복사 요청 확인.
- 새 EXE는 Windows CI 전체 검사·모듈 자가진단·실제 창 버전 확인 후 배포합니다.
- 추가된 복사·변환 경로를 검증했습니다. 같은 PC에서 처리 시간·조판 점수 개선율은 새로 측정하지 않았습니다.
- 실제 한/글 2020 붙여넣기와 HWP→HWPX 문서 수용·조판은 별도 실기기 검증 대상입니다.
- HTML 표의 테두리·배치는 한/글 HTML 해석에 따라 차이가 있을 수 있습니다. 정밀 서식에는 HWPX 저장 경로를 사용하세요.
