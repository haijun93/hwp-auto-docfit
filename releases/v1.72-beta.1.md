# 한글편집 후처리 v1.72 Beta 1

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- **별표(`*`, `**`) 문두기호 정렬 및 내어쓰기 규칙 개선**:
  - **빈 줄(공백 줄) 별표 연쇄 보존**: 문단 사이에 단락 구분을 위한 빈 줄(엔터)이 있어도 `*`와 `**` 간의 별표 정렬 연쇄가 끊어지지 않도록 개선했습니다.
  - **`**` 선행 공백 사전 보정**: `**` 문단의 표준서식 선행 공백을 `*`보다 1칸 적게 자동 설정하여 첫 번째 별표(`*`)와 두 번째 별표(`**`의 2번째 `*`)가 동일한 가로 열에 자연스럽게 위치하도록 맞춥니다.
  - **파이프라인 순서 재조정**: 별표 정렬(`star_align`)을 최종 내어쓰기(`hanging_indent`)보다 먼저 실행하여 정렬이 확정된 문단을 기준으로 내어쓰기가 계산되도록 개선했습니다.
  - **별표 정렬 시 내어쓰기 실시간 갱신**: 별표 위치 맞춤 중 선행 공백 삭제나 왼쪽 여백 변경 시 문단의 내어쓰기(Shift+Tab) 기준점을 즉시 동기화하여 본문 시작선과 2번째 줄 내어쓰기 선이 정확히 일치하도록 처리했습니다.
- **앱 시작 스크립트(`start_app.vbs`) 개선**: 가상환경(`.venv`)이 없더라도 시스템 파이썬(Python 3.14 등)을 자동으로 감지하여 원클릭으로 실행될 수 있도록 개선했습니다.
