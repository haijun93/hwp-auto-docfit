# 한글편집 후처리 도구 v1.69 Beta 14

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- **작업 카드 옵션과 '세부 작업' 목록 연동**
  - 카드 옵션을 켜고 끄면 같은 카드의 세부 작업 목록에서 관련 작업이 바로 함께 꺼지고 켜집니다.
  - 반대로 세부 작업에서 관련 작업을 하나라도 켜면 '제외' 옵션이 꺼지고, 모두 끄면 켜집니다. 앱 화면 목록·세부 작업 창·설정창 어디서 바꿔도 같습니다.
  - 자간 정리: '기존 자간 초기화' ↔ 문서 전체 자간 초기화, '표 제외' ↔ 표·컨트롤 자간 조정·줄 병합·단어 검사
  - 서식 통일: '표 제외' ↔ 기본 표 서식·표 서식통일, '자간 정리 제외' ↔ 서식통일 문장 자간 정리, '페이지 맞춤 제외' ↔ 문단 아래 간격 페이지 맞춤
  - 한 번에 적용: '자간 조정 포함' ↔ 자간 작업 7개, '표 제외' ↔ 표 관련 작업, '페이지 맞춤 제외' ↔ 페이지 맞춤·관련 문단 페이지 배치. 자간 작업을 모두 끄면 '자간 조정 포함'이 꺼집니다.
- **서식 통일 세부 작업에 '서식통일 문장 자간 정리' 추가**: 끄면 서식을 고친 문장의 자간 조정·외톨이 글자 당기기를 하지 않습니다(카드의 '자간 정리 제외'와 같음).
- **서식 통일 카드의 '페이지 맞춤 제외'가 기본으로 켜져 보임**: 서식 통일의 쪽 맞춤은 원래 기본 꺼짐이며, 이제 카드에도 그대로 보입니다. 처리 결과는 이전과 같습니다.
