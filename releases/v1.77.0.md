# HWP AutoDocFit v1.77.0

## 변경 사항

- 표/다이어그램 편집기에서 **조직표**와 **장식표** 메뉴를 제거했습니다.
- **표 서식 모음**은 알파 UI에서 비활성화했습니다. 이전 기능 데이터와 내부 구현은 보존하되 목록 조회·복사·내보내기 요청은 거부합니다.
- 흐름표와 기본 표 편집·복사 기능은 유지합니다.
- 파일포맷 변환기의 HTML 변환과 Pandoc 기반 변환 구성은 유지합니다.

## 릴리즈 기준 검증

- 사용자가 지정한 테스트예시 폴더의 HWPX 예시 3건을 한/글 PC 시험으로 처리하고 원본과 비교했습니다. 서식·구조 불일치 **0건(100% 일치)**.
- 지정한 「보고서 예시 파일(한번에 적용).txt」를 기본 서식으로 실제 처리했습니다. 상세 검수를 시험 실행에서 켜고 확인했으며, 결과 HWPX 생성, 3쪽 저장, 처리 점수 **100/100**, 작업 실패·검수 오류 **0건**으로 통과했습니다. 사용자 설정 파일은 변경하지 않았습니다.
- Python 단위 테스트: **1,281건 통과, 1건 제외**.
- Flutter 테스트: **80건 통과, 1건 제외**. Dart 분석: 오류 없음.
- 다이어그램 편집기 테스트: **22건 통과**, 프로덕션 번들 빌드 및 브라우저 검증 통과.

## 요구 환경

- Windows 10/11 64비트
- 한/글 2020 설치

EXE 체크섬은 GitHub 릴리즈의 `SHA256SUMS`에서 확인할 수 있습니다.
