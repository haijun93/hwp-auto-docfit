# v1.80.9 — 2026-10-24

1.80.8에서 발생한 실행 오류 3건을 해결하고 표 템플릿과 PDF 합치기를 개선한 버전입니다.

## 새로 된 점

- **표그림판·다이어그램·마인드맵 오류 해결**: 「표 서식 모음 HWPX 파일을 찾을 수 없음」과 다이어그램·마인드맵 404 오류를 고쳤습니다. 런처가 사용 중인 캐시를 지우던 것이 원인이었습니다. 실행 중인 캐시와 새 버전 캐시를 보존하고, 정리할 캐시는 옮긴 뒤 삭제합니다.
- **표 템플릿 열·행 단위 최대 50개**: 반복 단위를 최대 50개까지 늘립니다. 실제 한/글 조판에서 깨지는 축은 실측으로 확인한 30개·15개 등의 상한을 따릅니다.
- **일정표 날짜 자동 계산**: 연간 일정표는 분기를 1·2·3·4 순서로 반복하고 날짜 칸은 실제 달력에 따라 증가합니다. 주간 일정표는 첫 날짜(기본 4.26.)부터 주 단위 기간을 자동으로 채웁니다.
- **사진첨부용 모양 1·2 아래로 덧붙이기**: 사진과 설명 묶음을 아래로 늘립니다.
- **표 이름을 한눈에**: 이름 막대를 자판형으로 배치해 모든 이름을 노출합니다. 내장 템플릿 미리보기 그림을 동봉해 처음부터 그림을 볼 수 있습니다.

- **PDF 하나로 합치기 순서 정하기**: 파일을 끌거나 ↑/↓ 버튼으로 순서를 정한 뒤 합칩니다.
- **내장 표 그림 표시 수정**: 다른 기능을 먼저 쓴 뒤에도 내장 표 그림이 보이도록 고쳤습니다.

## 바뀐 점

- **개발자 모드의 문서 도구 삭제**: 문서 검토·공공언어 교정·문서 구조 편집·작성 도우미·Markdown 내보내기·고급 문서 도구를 삭제했습니다. 「텍스트 입력」의 텍스트 변환 기능은 유지합니다.
- **tldraw 도형 편집기 삭제(다이어그램·마인드맵은 그대로)**.
