# v2.0.8 — 2026-11-01

HWP AutoDocFit 2.0.8 릴리즈 안내입니다.
**'파일이름' 탭을 새로 만들었습니다.** 여러 파일의 이름을 규칙으로 한꺼번에 바꾸고, 바뀔 이름을 먼저 보여 줍니다. **복사한 것을 모아 두었다가 다시 붙여 넣는 K클립보드**도 더했습니다(기본 꺼짐).

---

## 바뀐 점

### 1. 파일이름 탭 (새 탭)
- 그림판 다음, 파일변환 앞에 **'파일이름'** 탭이 생겼습니다. 파일변환은 그대로 맨 끝입니다.
- 사용 순서
  1. 파일을 끌어다 놓거나 [파일 추가]·[폴더 추가](하위 폴더 포함 선택)를 누릅니다. 모든 종류의 파일을 넣을 수 있습니다.
  2. 오른쪽에서 규칙을 쌓습니다. 규칙은 위에서 아래로 차례로 적용됩니다.
  3. 표에 **원래 이름 → 새 이름**과 상태(바뀜·그대로·충돌·오류)가 바로 보입니다.
  4. [변경 적용](Ctrl+S)을 눌러야 실제로 바뀝니다.
- 규칙 18가지
  - 문자열 바꾸기(정규식·대소문자 구분 선택), 앞/뒤에 추가(`{folder}`·`{orig}`·`{date}`)
  - 번호 붙이기(시작값·간격·자리수, **폴더마다 따로 세기**), 번호 늘리기/줄이기(예: 1589 → 1588), 자리수 맞추기
  - 날짜·시각 넣기: 수정한 날, 만든 날, 오늘, **사진 촬영일**(없으면 수정한 날). 형식은 `YYYYMMDD`, `YY.MM.DD.` 등
  - 위치 지우기, 괄호처럼 묶인 곳 지우기(바깥/안쪽), 숫자만 남기기·숫자 지우기, 이름 지우기
  - 앱 결과 접미사 지우기: `(자간조정)`, `(서식통일)` 등
  - 공백·밑줄 정리, 대소문자, 확장자 바꾸기·덧붙이기·지우기·대소문자
- 규칙 세트를 저장하고 불러옵니다. 기본으로 '사진 촬영일+번호', '결과 접미사 정리', '공문 파일명(날짜_이름)'이 들어 있습니다.
- 한 파일만 따로 고치려면 새 이름을 **두 번 누릅니다**.

#### 안전 장치
- 같은 폴더에 같은 이름이 생기거나, 목록 안에서 새 이름이 겹치면 **충돌**로 표시하고 적용하지 않습니다.
- Windows에서 쓸 수 없는 이름(`\ / : * ? " < > |`, CON·NUL 같은 예약 이름, 끝의 마침표·공백)은 **오류**로 표시합니다.
- 서로 이름을 맞바꾸는 경우(A↔B)와 대소문자만 바꾸는 경우도 안전하게 처리합니다.
- 이미 있는 파일을 **덮어쓰지 않습니다**. 파일 내용과 수정 시각도 바꾸지 않습니다.
- 미리 본 뒤 파일이 바뀌었으면 하나도 바꾸지 않고 다시 확인하라고 알립니다.
- 실행 파일(.exe·.bat 등) 이름을 바꿀 때는 한 번 더 묻습니다.
- **되돌리기**(Ctrl+Z)와 '이름 바꾼 기록'에서 예전 작업을 골라 되돌릴 수 있습니다. 앱을 다시 켜도 됩니다. 기록은 30일·1,000건까지 보관합니다.

### 2. K클립보드 (기본 꺼짐)
- 복사(Ctrl+C)한 **글·그림·파일 경로**와 **화면 캡처**(PrtScn, Win+Shift+S, 스크린샷 폴더에 저장된 캡처)를 모아 둡니다.
- **아무 창에서나 Ctrl+Shift+V**를 누르면 최근 항목이 마우스 옆에 바로 뜹니다.
  - 숫자 1~9나 ↑↓·Enter로 고르면 원래 창에 바로 붙여 넣습니다.
  - 글자를 치면 바로 찾습니다(한글 포함). Del은 지우기, Esc는 닫기입니다.
- 글자 서식(HTML·RTF)도 함께 보관해 붙여 넣을 때 되살립니다.
- 켜는 법: 상단 오른쪽 **K클립보드 단추** → 안내를 읽고 동의 → [K클립보드 켜기]. 로그인할 때 자동으로 켜기(30초 뒤)는 고를 수 있습니다.
- 관리 화면에서 찾기·고정(지워지지 않음)·지우기·다시 클립보드에 올리기·일시정지·끄기를 할 수 있습니다.
- 보관 한도 기본값: 50개(고정 제외), 항목당 10MB, 전체 200MB, 30일. 설정에서 바꿀 수 있습니다.
- **가볍게 만들었습니다**: 앱과 따로 도는 아주 작은 프로그램 `kagent.exe`(약 0.7MB)가 맡습니다. 쉴 때 CPU 0%, 메모리 약 2MB를 씁니다.

#### 개인정보·보안
- 내용은 이 PC의 사용자 폴더에 **Windows 사용자 계정으로 암호화**해 저장하고, 밖으로 보내지 않습니다. 네트워크 기능이 없습니다.
- 암호 관리자(KeePass, 1Password, Bitwarden 등)가 보내는 '기록 제외' 신호를 따르고, 이 프로그램들에서 복사한 것은 기록하지 않습니다.
- 파일·폴더는 **경로만** 보관합니다(파일 복사본을 만들지 않음).
- 트레이 아이콘에서 기록 중/일시정지를 늘 볼 수 있습니다.

### 3. 기타
- 작업한 문서를 시간 순으로 보는 '타임머신'의 색인 기능을 준비했습니다(화면은 다음 버전).

## 확인 사항
- K클립보드 프로그램은 아직 코드 서명이 없어, 일부 PC에서 백신이나 Windows가 처음 실행 때 경고할 수 있습니다.
- 파일이름 탭은 한/글이 열어 둔 문서 이름은 바꾸지 못하고 '열려 있거나 권한 없음'으로 건너뜁니다.
