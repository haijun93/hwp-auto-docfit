# v1.80.3 — 2026-10-22

1.80.2 사용자 보고(파일포맷 변경 오류·멈춘 작업을 끝낼 수 없음)를 고치고, 준말 관리와 옵션 설명을 바꾼 버전입니다.

## 고친 점

- **파일포맷 변경을 시작하면 바로 오류**(`'HwpAutoDocFitGUI' object has no attribute 'profile_combo'`)가 나던 문제를 고쳤습니다. 설정 화면을 한 번도 열지 않은 상태에서 HWPX→PDF 등을 실행하면 HWPX 1개만으로도 났습니다. 작업 시작 전에 화면 잠금에 필요한 설정 위젯을 준비하고, 위젯이 없어도 화면 잠금·풀기가 멈추지 않게 했습니다.
- **작업 중단이 먹지 않던 문제**: 한/글이 응답하지 않으면 「작업 중단」 10초 뒤 앱이 띄운 한/글만 강제로 끝내 작업을 마칩니다. 사용자가 따로 연 한/글은 건드리지 않습니다(앱이 만든 한/글의 프로세스 번호만 기억해 둡니다).
- **창이 닫히지 않던 문제**: 작업 중 창을 닫으면 10초 안에 끝나지 않을 때 앱이 띄운 한/글을 정리하고, 15초가 지나면 앱을 강제로 닫습니다. 기다리는 중 한 번 더 닫으면 「지금 강제로 종료」를 고를 수 있습니다.
- 종료 확인 문구가 작업과 상관없이 "자간 조정 작업"으로 나오던 것을 지금 하는 작업 이름(파일포맷 변경·자간 정리·서식 적용·한 번에 적용·서식 통일)으로 바꾸고, 버튼을 「작업 중단하고 종료 / 계속 진행」으로 바꿨습니다.

## 새로 된 점

- **준말 관리를 한/글 문서로**: `C:\HWP_AUTODOCFIT\준말관리\준말관리.hwpx`를 한/글에서 열어 `#준말` 문단 아래에 본말을 씁니다.
  - 본말이 여러 문단이면 빈칸 하나로 이어 한 줄이 됩니다. `※` 문단과 첫 `#` 앞 문단은 설명으로 보고 읽지 않습니다.
  - 서식 표 준말은 본말에 `[서식:제목1]` `[서식:제목2]` `[서식:개요]` `[서식:중제목]` `[서식:붙임1]` `[서식:붙임2]` `[서식:표]` 중 하나를 씁니다.
  - '서식 적용'·'한 번에 적용'을 시작할 때마다 문서를 다시 읽습니다. 잘못 쓴 항목(빈 본말·중복·12자 초과·모르는 서식)은 그 항목만 빼고 이유를 준말 관리 화면과 작업 기록에 보여 줍니다.
  - 처음 문서를 만들 때 기본 준말과 지금까지 앱에 등록한 준말을 옮겨 적습니다. 앱 설정의 준말은 지우지 않으며, 준말 관리 화면에서 「앱 설정 사용」으로 되돌릴 수 있습니다.
- **옵션 설명을 적용 전·후 그림으로**: 작업 방식 카드의 옵션, 세부 작업 목록, 설정 화면에서 rhwp 조판 미리보기 대신 README와 같은 전·후 비교 그림을 보여 줍니다. 그림을 누르면 크게 볼 수 있습니다.
  - rhwp 조판 엔진(자산 약 12MB)을 앱에서 뺐고 그림 18장(1.4MB)을 넣었습니다.
  - 아직 그림이 없는 옵션: 붙임 글꼴(`attachment_font`), 표 제외·페이지 맞춤 제외 카드 옵션 — 「예시 이미지 준비 중」으로 표시합니다.
