# v2.2.8 릴리스

HWP AutoDocFit 2.2.8 릴리스 안내입니다.

## 바뀐 점

### 화면 복구

- 절전이나 오랜 유휴 뒤 돌아오면 화면을 다시 그립니다.
- 화면을 그리는 프로세스가 끊기면 페이지를 다시 불러옵니다. 계속 끊기면 1분에 3회까지만 시도합니다.

### 엑셀 표를 한/글 표로

- 괄호 음수와 통화 기호가 붙은 음수를 숫자로 알아보고 오른쪽 정렬합니다.
- 열이 아주 많아도 표 폭이 본문을 넘지 않습니다.

Python 3.14 기반으로 빌드합니다.

---

## 배포 검증

- CI 실행 41538643857 통과(Python 3.14, Python 회귀 2054건, Flutter 256건).
- 배포 exe 시험: 내려받은 Portable·Setup의 SHA-256이 릴리스 값과 일치, 화면 내용 시험 통과(화면 오류 0건, 첫 화면 11,896ms), 새 실행과 실행 중 앱으로의 파일 전달 확인.
- 화면 복구: 배포 exe의 화면 프로세스를 실제로 끊어 시험. 1~3회는 4~9초 안에 다시 그렸고, 1분 안의 4회째는 횟수 제한으로 다시 불러오지 않았습니다.
- 엑셀 표 경계 사례 시험 통과. 실제 Excel·한/글 왕복은 이번 수정분에 다시 하지 않았습니다.

## 알려진 문제

- 절전 복귀 뒤 다시 그리기는 실제 절전으로 시험하지 않았습니다.
- 4회째 뒤에는 화면이 비어 있을 수 있어 앱을 다시 켜야 합니다.
- 서식 복사 재연의 표 높이(8082→5982)와 쪽 여백 차이가 남아 있습니다(사용자 수정 파일 대기).
