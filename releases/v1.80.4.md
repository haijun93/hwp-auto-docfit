# v1.80.4 — 2026-10-22

v1.80.3 배포 직후 사용자 보고를 고치고, 파일포맷 변경에 「PDF 하나로 합치기」를 더한 버전입니다.

## 고친 점

- **「실행 준비」 창의 글자 겹침**: 포터블 exe를 처음 실행할 때 뜨는 창에서 아래 안내 두 문장이 겹쳐 읽을 수 없었고, 버전 글자가 고양이 그림을 가렸습니다.
  - 원인: 배경 그림(`resources/splash.png`)에 옛 버전(v1.77.0)·진행 막대·"프로그램을 시작하는 중입니다…" 문구가 그림으로 들어 있었고, 런처가 그 위에 새 문구를 투명 배경으로 겹쳐 썼습니다.
  - 배경 그림에서 바뀌는 글자를 지우고, 버전은 제목 아래, 진행 상황은 막대 아래 제자리에 흰 바탕으로 씁니다.
- **GitLab에서 바로 받기**: 공공기관 PC에서는 GitHub 접속이 막혀 README의 다운로드 링크가 열리지 않았습니다. 이제 README의 「받기」 링크는 GitLab 저장소의 `downloads` 브랜치 파일로 연결됩니다(로그인 없이 내려받기 확인).
  - 기관망 밖에서는 GitHub 릴리스에서도 같은 파일(같은 SHA-256)을 받을 수 있습니다.

## 새로 된 점

- **PDF 하나로 합치기**(파일포맷 변경의 새 선택지): 여러 PDF·HWPX·HWP·그림(PNG·JPG 등) 파일을 넣은 순서대로 PDF 한 개로 묶습니다.
  - PDF·그림은 그대로 붙이고, HWP·HWPX는 한/글이 PDF로 저장한 뒤 붙입니다. 파일마다 책갈피가 달립니다.
  - 결과는 첫 파일 폴더에 `<첫 파일> 외 N개(합친 PDF).pdf`로 저장하며 원본은 그대로입니다.
  - 한 파일이라도 PDF로 바꾸지 못하면 쪽이 빠진 합본을 만들지 않고 알립니다. 암호·보안이 걸린 PDF는 보호가 풀린 사본을 만들지 않도록 합치지 않습니다.
  - 파일이 2개 이상일 때 고를 수 있습니다. PDF·그림만 넣으면 한/글 없이도 합칩니다.
- **같은 형식으로는 바꾸지 않기**: 넣은 파일이 모두 이미 그 형식이면 그 결과 형식을 고를 수 없습니다(예: PDF만 넣으면 「PDF」가 꺼짐, 「PDF 압축」·「PDF 하나로 합치기」는 그대로). 형식이 섞여 있으면 이미 같은 형식인 파일은 건너뛰고 이유를 보여 줍니다.
