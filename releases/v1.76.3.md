# HWP AutoDocFit v1.76.3 베타

□ 이미지 파일 OCR 변환
ㅇ PNG·JPG·JPEG·WEBP·BMP·TIF·TIFF·GIF → 편집 가능한 HWPX 지원.
ㅇ kordoc 파싱 및 PP-OCRv5 한국어 모델을 EXE에 내장. 사용 PC에서 모델·패키지 추가 다운로드 불필요.
ㅇ PDF·PNG·JPG 출력은 OCR로 생성한 HWPX를 한/글로 렌더링. DOCX·EPUB 출력에는 Pandoc 필요.
ㅇ 다중 TIFF·GIF 프레임은 순서대로 변환. 파일 64MB, 100프레임, 프레임 3천만 화소·합계 1억 2천만 화소 제한.
ㅇ OCR은 텍스트 재구성이며 원본 스캔의 서식·표·도형을 완전히 복원하지 않음. 인식 결과 확인 필요.

□ 마인드맵 편집
ㅇ 도형 자유 이동, 수동 위치 저장·재열기·PNG 출력, 연결점으로 부모 변경 지원.
ㅇ 선택 가지 아래에 단계 제한 없이 하위 가지 생성, 같은 단계 추가, 수정·하위 트리 삭제 지원.
ㅇ 연결선 설명·색상·굵기·선 모양·화살표 편집 및 연결선 삭제·복원 지원.
ㅇ 순환 계층 방지. 문서당 300개 가지 제한. 자동 정렬로 수동 위치 초기화 가능.

□ 자간 정리 오류 수정
ㅇ ‘서식 통일 → 자간 정리 제외’ OFF 시 서식이 이미 같은 문장도 본문 전체 자간 검사에 포함.
ㅇ 기존에는 서식 변경 문장에만 자간 작업을 예약하여 정상 서식 문장의 어절 분리가 남을 수 있었음.
ㅇ 표 제외·자간 제외 및 쪽 범위 조건 유지. 원본 문서 미변경.

□ 이전 버전 대비 개선 효과
ㅇ 고정 마인드맵을 수동 이동·크기 변경·부모 재연결이 가능한 편집기로 개선. 위치·크기·선 모양의 저장/복원 및 PNG 반영 회귀 시험 통과.
ㅇ 서식이 같은 문장의 자간 함수 미실행을 전체 본문 실행으로 변경. 제외 ON/OFF 및 표 포함/제외 네 가지 조합 회귀 시험 통과.
ㅇ OCR 미포함에 따른 이미지 변환 비활성화를 내장 한국어 OCR 변환으로 개선. 처리 시간·인식 정확도의 일반적인 개선율은 측정하지 않았으므로 제시하지 않음.
