# 한글편집 후처리 v1.72 Beta 7

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **부연설명(`*`·`**`·`※`) 내어쓰기**: 둘째 줄 이후를 부연설명 자기 글 시작 위치(기호와 뒤 빈칸 바로 다음)에 맞춥니다. 콜론·괄호 라벨이 붙은 문장도 같습니다.
- **`부연설명 들여쓰기` 단계 기본 켜짐**: 부연설명 첫 줄을 앞 문장(ㅁ·ㅇ·-)의 글 시작 위치에 맞춥니다. `*`와 `**`이 묶음이면 `**`의 두 번째 `*`가 `*`와 세로로 같은 위치에 오고, 이때 앞 빈칸을 지우면 내어쓰기도 새 위치에 맞게 다시 맞춥니다. 서식 복사 프로필은 기존대로 이 단계를 끕니다.
- 문두기호 `ㅇ` 1칸·`-` 3칸 규칙과 붙임 번호 세로 정렬은 Beta 6과 같습니다.
- 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.
