# v1.80.5 — 2026-10-22

자주 쓰는 표를 **모양을 보고 고르고**, 정보단위(여러 칸으로 된 반복 묶음) 개수만 정해 **한/글에 바로 붙여넣는** 「표 템플릿」을 더한 버전입니다.

## 새로 된 점

- **표 템플릿**(상단 표 버튼 → 「표 템플릿」):
  - 표 서식 모음 36종을 한/글이 실제로 그린 모양 그림(스냅샷)으로 보고 고릅니다. 분류별로 거를 수 있습니다.
  - 표마다 정보단위를 분석했습니다. 예: 분야별과제표는 과제 묶음 3개(묶음 1개 = 내용 3칸 + 간격 1칸), 추진절차(가로)는 상자 + 화살표,
    행사시간표는 시간 줄, 일정표(일간)는 날짜로 묶인 2줄, 행사표(1일)는 하루 묶음 8줄, 일정표(연간·월별·주간)는 기간 열과 할 일 줄 두 방향.
  - [−][+]로 정보단위를 줄이거나 늘리면 바로 미리보기에 반영됩니다. 머리 행·구분 칸·전체를 덮는 병합 칸(예: 화살표 열, '추진 내용' 머리)은 알맞게 따라갑니다.
  - 가로 단위를 늘려도 표 전체 폭은 그대로이고, 칸 안의 글상자 표도 같은 비율로 맞춥니다.
  - 「한/글에 붙여넣기용 복사」를 누른 뒤 한/글에서 Ctrl+V 하면 테두리·색·글꼴이 그대로 붙습니다(숨긴 한/글로 복사, 사용자가 연 한/글은 건드리지 않음).
  - 라벨·부연설명처럼 반복 단위가 없는 표는 「고정 표」로 그대로 복사합니다.
  - `C:\HWP_AUTODOCFIT\표서식모음\표 서식모음.hwpx`를 고치면 그 파일을 쓰고 모양 그림도 새로 만듭니다(없으면 앱 내장본).
- 작업 카드 이름 「파일포맷 변경」을 **「파일 변환」**으로 바꿨습니다(사용자 요청). 진행 화면·작업 기록·종료 확인 문구도 같습니다.
- 상단의 표 버튼은 메뉴로 바뀌었습니다(「표 템플릿」, 「표/다이어그램 편집기」). 좁은 창에서 도구 줄이 넘치지 않습니다.
