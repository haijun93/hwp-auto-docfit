# v2.2.16 릴리스

HWP AutoDocFit 2.2.16 릴리스 안내입니다.

## 바뀐 점

### 타임머신

- 이름이 `#IEeEE`로 시작하는 파일이 타임라인에 계속 보이던 문제를 고쳤습니다. 대소문자·따옴표·확장자와 관계없이 제외하고, 이미 저장된 색인·썸네일·시간대 집계·검색 결과에서도 걸러 냅니다.
- 빈 파일 표 보기에서도 타임라인 항목이 보입니다.
- 본문검색 결과를 Markdown으로 내보낼 수 있고, 미리보기 안에서 이전·다음 일치 위치로 이동할 수 있습니다.

### 사이드메뉴(개발자 모드)

- 사이드메뉴 모드에서 '왼쪽↔오른쪽' 버튼으로 붙는 쪽을 바로 바꿀 수 있습니다. 고른 쪽은 저장되어 다음에 켤 때 그대로 적용됩니다.

### 자료함(개발자 모드)

- 자료함 화면의 파일 끌어 놓기·붙여넣기 시험을 복구했습니다.

Python 3.14 기반으로 빌드합니다.
