# v2.0.6 — 2026-10-30

HWP AutoDocFit 2.0.6 릴리즈 안내입니다.
2.0.5의 **한/글 복사 오류를 고쳤습니다**. 표 템플릿에 **화살표 고르기**를 더했고, 미리보기가 실제 표 모양과 같아졌습니다.

---

## 바뀐 점

### 1. 한/글 복사 오류 수정
- 2.0.5에서 표 템플릿·표그림판의 '한/글에 붙여넣기용 복사'가 모두 실패했습니다. 오류 문구는 `type object 'PendingGui' has no attribute '파일포맷_변경_시작'`이었습니다.
- 원인: 2.0.5에서 시작을 빠르게 하려고 쓴 임시 화면 객체에서 한/글을 띄우는 기능을 찾았기 때문입니다.
- 이제 실제 화면에서 찾습니다.

### 2. 표 템플릿 화살표 고르기
- 추진절차·신구대조표처럼 칸 사이에 화살표가 있는 표(10종)에서 화살표 모양을 바꿀 수 있습니다.
  - 기호 화살표 12종: ⇒ ⇔ ➡ ⇨ ⇦ ⇧ ⇩ ▷ ◀ → ➜ ▶
  - 공문서용 그림 화살표 5종: 기본형(파란 원), 강조형, 세련된 디자인 1·2, 이중선
- 그림 화살표는 방향(원래 방향·오른쪽·아래·왼쪽·위)과 크기(작게·보통·크게)를 고릅니다. 한/글 문서에 그림으로 들어갑니다.
- 오른쪽·아래 화살표가 섞인 표는 칸마다 원래 방향에 맞춰 돌립니다. 예를 들어 ⇨를 고르면 아래 칸은 ⇩가 됩니다.
- 정보단위를 늘려 생긴 칸에도 같은 화살표가 들어갑니다.

### 3. 표그림판에서 Ctrl+V로 한/글 표 붙여넣기
- 한/글 문서의 표를 복사(Ctrl+C)한 뒤 표그림판에서 **Ctrl+V**만 누르면 표가 선·글로 들어옵니다. 지금까지는 '한/글 표 붙여넣기' 단추로만 됐습니다.
- 표그림판 안에서 선을 복사한 뒤에는 Ctrl+V가 그 선을 붙여 넣습니다. 그 사이에 한/글에서 새로 복사했으면 한/글 표를 붙입니다(클립보드 바뀜 번호로 가림).

### 4. 표 템플릿 미리보기를 실제 모양과 같게
- 실제 표에 없는 검은 바깥 테두리를 그리지 않습니다.
- 라벨 서식처럼 가로로 긴 표가 실제 비율로 보입니다.
- 이중선·파선·점선을 실제처럼 그립니다.
- 부연설명의 여러 줄 글이 줄바꿈대로 보입니다.
- 여러 도형을 묶어 만든 화살표(추진절차 모양 3)는 한/글로 그린 그림에서 잘라 보여 줍니다.

### 5. 표 템플릿 정보단위
- 추가 서식 45개(사업개요표 모양 1~인력 현황표 모양 2) 모두 열 단위로 늘리고 줄일 수 있습니다.
  - 첫 열과 끝의 비고·계 열은 그대로 둡니다.
  - 월별 실적표는 12개월까지 늘어납니다.
- '2026. 1. ~ 2026. 12.' 같은 연·월 날짜를 늘리면 다음 해 '2027. 1. ~ 2027. 12.'처럼 달력대로 이어집니다.
- 조직도 모양 1의 팀 수 조절(2~9팀)을 되살렸습니다. 1.80.15부터 막혀 있었습니다.
- 목록에서 라벨 서식을 맨 뒤에 둡니다.

### 6. 원본·결과 비교
- '원본·결과 비교'를 누르면 '준비 중' 오류 대신 비교 화면이 기본 브라우저로 열립니다.
  - 원본과 결과의 글을 나란히 보여 주고, 바뀐 줄을 색으로 표시합니다.
  - HWPX·PDF·MD·TXT 문서를 비교합니다. 글꼴·간격 같은 서식 차이는 보이지 않습니다.

### 7. 보안 보완
- 사용자 문서를 여는 두 곳에 압축 폭탄 방어를 더했습니다.
- 업데이트 스크립트를 파일로 쓰지 않고 바로 실행합니다. 실행 직전에 파일이 바뀌치기될 틈을 없앴습니다.
- 한/글 보안 모듈 DLL의 해시를 SECURITY.md에 적고, 시험으로 고정했습니다.

## 알려진 점

- 그림판을 한/글에 붙여 넣으면 지금은 그림 한 장으로 들어갑니다. 한/글에서 고칠 수 있는 묶음 개체로 붙이는 기능은 다음 버전에서 넣습니다.
- 한/글 표 붙여넣기는 칸 바탕색을 아직 가져오지 않습니다. 다음 버전에서 넣습니다.

## 시험

- Python 단위 시험, Flutter 위젯 시험, 편집기 모델 시험(`diagram_editor`) 모두 통과.
- 한/글 실제 시험(COM)
  - 화살표: 그림·기호 화살표를 넣은 표 5종을 한/글로 열어 그림으로 확인
  - 조직도: 2·3·4·6·7팀
  - 열 단위: 늘린 표
- 실제 앱 화면 시험
  - 표 템플릿 화살표 고르기(그림 화살표를 고르면 미리보기에 반영)
  - 한/글에서 월별 실적표를 복사해 표그림판에서 Ctrl+V(4행×8열)
  - 라벨 서식·부연설명·현황표·추진절차 미리보기
- 2.0.5 복사 오류는 같은 상황을 만든 시험으로 재현한 뒤 수정을 확인했습니다.
- 배포 exe 재연 시험
  - CI가 만든 포터블 exe를 내려받아 SHA-256이 일치하는지 확인했습니다.
  - 실행 뒤 다음을 확인했습니다. 화면 오류는 0건입니다.
    - **표그림판·표 템플릿(화살표 그림 포함)의 '한/글 복사' 3가지 모두 성공**(2.0.5 오류 수정 확인)
    - 한/글에서 복사한 월별 실적표(4행×8열)를 표그림판으로 가져오기
    - 그림판 사진 배경·개체·레이어
- 시작 속도(CI)
  - 첫 실행 스플래시 95.5ms(목표 100ms 이내)
  - 재실행 화면 1.31·1.27초(목표 1.5초 이내)
  - 캐시 실행 0.56초
