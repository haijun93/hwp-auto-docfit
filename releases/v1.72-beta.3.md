# 한글편집 후처리 v1.72 Beta 3

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **문두기호 `*`·`**` 내어쓰기와 정렬 개선**
  - `**` 전용 규칙이 없을 때 `*`에 설정된 예시 서식의 내어쓰기 규칙을 이어받습니다.
  - 일반 내어쓰기와 부연설명 들여쓰기를 마친 뒤 별표 위치를 최종 보정해 후속 단계가 정렬을 덮어쓰지 않게 했습니다.
  - 한/글 2020에서 실제 문서를 처리해 `*`와 `**`의 기준 위치가 일치하는지 확인했습니다.
- **`□`와 `ㅁ` 문두기호 통일**: 계층 분석과 표준 서식에서 같은 기호로 인식하고 같은 규칙을 적용합니다.
- **페이지 맞춤 보완**: 표 셀 세로 여백을 반영해 쪽 맞춤 후 원래 값으로 정확히 복구하며, 설치 상태를 복원하는 도구를 추가했습니다. 단, 복원 도구 실행 파일은 이번 배포에 포함하지 않습니다.
- **실행 편의 개선**: 시작 스크립트가 가상환경이 없을 때 시스템 Python을 찾도록 보완했습니다.

다운로드:
- `HWP_AutoDocFit.exe` (메인 프로그램, Windows 64비트)
- `HWP_AutoDocFit-v1.72-beta.3.zip` (메인 프로그램과 한 번에 적용 시험용 예시 텍스트)
- 설정 초기화 실행 파일은 이번 릴리스에서 제외했습니다.
