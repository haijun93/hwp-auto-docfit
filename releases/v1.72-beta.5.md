# 한글편집 후처리 v1.72 Beta 5

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **문두기호별 내어쓰기 빈칸 규칙**
  - 여러 줄 문장의 둘째 줄을 `기호 끝 + 빈칸 N칸` 위치에 맞춥니다. `ㅇ`은 1칸, `-`는 3칸, `*`·`**`·`※`는 5칸입니다.
  - 서식 복사로 정한 내어쓰기 규칙이 있거나 괄호·콜론 라벨이 붙은 문장, 기호 뒤 빈칸이 없는 문장은 기존 기준을 따릅니다.
- **붙임 번호 세로 정렬**: 문서 끝의 `붙임`~`끝.` 번호 목록은 모든 번호(`1.`, `2.`, `3.` …)를 첫 번호와 세로로 같은 위치에 맞춥니다. Beta 4의 항목별 2타 계단식 들여쓰기는 폐지했습니다. 항목이 꺾인 줄은 기존대로 내용 시작 위치에 맞춥니다.
- 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.
