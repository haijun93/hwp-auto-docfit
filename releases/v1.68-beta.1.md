# 한글문서 후처리 도구 v1.68 Beta 1

Windows 64비트용 테스트 베타 릴리스입니다. 1.68 Alpha 1~6에서 시험한 개선을 모두 반영했습니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

## 새 기능
- **작성 도우미**(파일 목록 옆 버튼): 금액 한글 병기(`금1,500,000원(금일백오십만원)`)·쉼표·천원 단위, 날짜 요일 붙이기·고치기와 이번/다음 달 금요일·기간·날짜 차이, 붙여넣은 표의 열 합계·평균·행 합계·구성비, 만 나이·주민번호 가리기, 번호 다시 매기기, 회신공문 본문 만들기.
- **기관 서식**: 기관 문서의 스타일 요소(글꼴·문자/문단 모양·표·위첨자·글자색·음영 등)를 전수 분석해 보고서와 예시 서식 HWPX를 만들고, 기관 이름을 붙여 문서 서식으로 등록합니다. 서식 목록은 `[기관] 이름`으로 묶여 보입니다.
- **라벨 입력 모드와 AI 프롬프트**: `제목: / 네모: / 원: / 바: / 표:` 같은 라벨 텍스트를 추론 없이 개조식으로 바꾸고, 텍스트 붙여넣기로 추가하면 제목·개요·참고 상자와 표를 만들어 줍니다. 생성형 AI에게 이 형식으로 답하게 하는 공문서 프롬프트를 복사할 수 있습니다(앱은 AI에 아무것도 보내지 않음).
- **서식통일**과 빠른 선택(기본후처리·전문후처리): 여러 사람이 쓴 문서를 문두기호별 대표 글꼴·크기·장평으로 맞춥니다.
- **아웃라이너 강화**: 접기·확대·항목 이동·완료·메모·검색, 닫을 때 자동 저장하고 이어 쓰기.
- **서식 예시 직접 편집**: 한/글에서 예시 문서를 직접 써서 서식으로 추가하고, 서식 이름을 바꿀 수 있습니다.
- **최종검수 숫자 대조**: 원본과 결과의 숫자 데이터가 달라지지 않았는지 검사합니다.
- 설정에 표 머리글·본문 글꼴·크기 항목 추가.

## 개선
- 표 머리글·본문 서식을 표 단위로 한 번에 적용해 표가 많은 문서가 크게 빨라졌습니다(수출입동향 14분 → 97초).
- 부연설명 들여쓰기를 계산 대신 한/글 실측으로 맞춥니다.
- 표 구조 정밀 조정(셀 여백·열 너비·테두리)을 실제 한/글로 검증해 고쳤습니다(기본 꺼짐).
- 자간 조정: 열거의 마지막 항목, `단어 + 빈칸 + 숫자 + 쉼표`를 한 어절로 취급하고, 넓은 표 칸은 본문 자간 한도를, 숫자·기호만 있는 칸은 건너뜁니다. 좁은 칸보다 긴 단어는 조정·검수에서 제외합니다.
- 쪽 배치: 실제 쪽 순서로 판단하고, 한 쪽보다 긴 묶음은 규칙에서 빼며 줄간격으로 못 옮긴 묶음은 쪽을 나눕니다. 문서 끝 빈 쪽을 지웁니다.
- 처리 중 PC 절전을 막고, 자간 단계 탐색·쪽 수 재확인 측정 횟수를 줄였습니다.

## 고친 문제
- 빈 줄 삭제가 표·그림 문단을 지우던 문제. 표·이미지·컨트롤 손실은 무결성 오류로 판정합니다.
- 표 셀 마지막 줄을 두 번 처리하던 문제, 최종 단어 검수가 한 문단에서 멈추던 문제.
- 이름만 `.hwpx`인 HWP 문서를 열지 못하던 문제.
- 서식 확인에 실패하면 문서 전체를 중단하던 문제(반대 방향으로 계속 진행).
- 텍스트를 HWPX로 바꾸다 실패하면 한/글 '저장할까요?' 창에서 멈추던 문제.
