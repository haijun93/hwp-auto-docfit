# v2.2.4 릴리스

HWP AutoDocFit 2.2.4 릴리스 안내입니다.

## 바뀐 점

### 표그림판

- 사각형을 선으로 나눈 칸마다 배경색을 칠합니다.
- 좌·우·상·하 방향 화살표 도형을 넣고 옮기고 크기를 바꿉니다. 한/글에 붙여도 표와 함께 움직이는 도형으로 들어갑니다.

### 타임머신

- 파일명 검색과 문서 본문 키워드 검색을 전환해 씁니다. 본문 색인은 진행률을 보며 취소할 수 있습니다.
- 적용 확장자(hwpx, hwp, docx, pptx, xlsx, pdf, txt)와 조사 폴더를 화면에서 바꿉니다.

### 몽땅클립보드

- 「모두 지우기」 전에 확인 창을 띄웁니다. 고정한 항목은 남습니다.
- 스티커 모드 창의 위치와 크기를 기억합니다.

Python 3.14 기반으로 빌드합니다.

## 배포 검증

- CI 실행 41459660291 통과(Python 3.14, Python 회귀 2023건, Flutter 247건). 스플래시 56.65ms, 웜 시작 1,623·1,685ms(기록만).
- 배포 exe 시험: 내려받은 Portable·Setup의 SHA-256이 릴리스 값과 일치, 화면 내용 시험 통과(화면 오류 0건), 실행 중 파일 이름 변경 전달 확인.
- 표그림판 화살표: 실제 한/글에서 직접 열기와 복사·붙여넣기 모두 지정 위치와 0.31칸 이내로 일치.

## 알려진 문제

- 화살표가 있는 표는 첫 칸의 글자가 위쪽 정렬이 됩니다.
- 스티커 창 위치 복원과 표그림판 화살표 그리기는 실제 앱 창에서 조작해 시험하지 않았습니다.
- 연관 문서 찾기는 코어만 들어 있고 화면이 없어 아직 쓸 수 없습니다.
- 서식 복사 재연의 표 높이(8082→5982)와 쪽 여백 차이가 남아 있습니다(사용자 수정 파일 대기).
