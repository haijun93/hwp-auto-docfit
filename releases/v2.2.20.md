# v2.2.20 릴리스

HWP AutoDocFit 2.2.20 릴리스 안내입니다.

## 바뀐 점

### 노트북(개발자 모드, 1차)

여러 문서를 한곳에 모아 읽고, 근거를 찾고, 근거를 인용한 노트를 쓰는 기능입니다. AI 없이 이 PC 안에서만 처리합니다.

- 사이드메뉴의 '노트북' 버튼으로 엽니다. 화면은 세 칸입니다: 출처(문서 목록) · 근거 찾기와 미리보기 · 노트.
- 근거 찾기: 질문이나 검색어를 넣으면 출처 문서에서 관련 문단을 점수순으로 보여 줍니다(출처·쪽 표시).
- 근거 문단을 노트에 인용으로 붙일 수 있고, 인용 원문은 사본으로 보관되어 원본이 바뀌어도 남습니다.
- 변환: 개요·표·숫자 문장·핵심어를 규칙에 따라 정리해 보여 줍니다.
- 노트를 Markdown으로 내보낼 수 있습니다.

### 쪽 맞춤

- `※`, `*`, `**`로 시작하는 부연설명 문단은 들여쓰기와 관계없이 바로 앞 항목과 한 묶음으로 같은 쪽에 배치합니다.

Python 3.14 기반으로 빌드합니다.

## 배포 검증

- GitHub CI(42076820520): Python 회귀 시험, Flutter 분석·시험, K에이전트·위계 엔진·자료함·노트북 엔진(Rust) 시험 통과(배포 파일 화면 시험 1단계는 연결 타이밍 문제로 한 번 재실행 후 통과).
