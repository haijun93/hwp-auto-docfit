# 한글편집 후처리 v1.75.2

Windows용 정식 버전입니다. 중요한 문서는 원본 대신 사본으로 먼저 처리하고 결과를 확인해 주세요.

## 주요 변경

- Flutter 화면에서 작업 로그를 열어 조회·새로 고침·복사할 수 있습니다. 작업 중에는 로그 지우기를 제한합니다.
- Flutter 설정 화면에서 작업로그, 무결성검사, 최종검수 파일 생성 옵션과 서식 통일 결과 창·항상 위 표시 옵션을 조정할 수 있습니다.
- Codex 등 MCP 호스트가 MCP 서버를 자동 시작해도 기본적으로 비활성 상태입니다. 사용자가 의도적으로 연결할 때만 `DOCFIT_MCP_ENABLED=1`로 명시해 활성화합니다.
- 기존 작업 처리 기능은 유지했습니다. 상세 설정과 일부 문서 도구는 아직 기존 Tk 창을 사용하므로, 이 릴리스는 UI의 100% Flutter 전환을 의미하지 않습니다.

- Python 전체 단위 테스트 958개 통과.

- MCP 자동 비활성 및 명시적 활성화 프로토콜 시험 통과.
