# v2.2.0 릴리스

HWP AutoDocFit 2.2.0 릴리스 안내입니다.

## 바뀐 점

### 타임머신

- 같은 시간대에 파일이 5개를 넘으면 묶음 카드로 접어 보여 줍니다.
- 시간대별 활동 막대를 표시합니다.
- 카드 메뉴에서 파일을 파일명 일괄변경·파일변환·문서편집 목록으로 보낼 수 있습니다.
- 묶음으로 목록이 짧아져도 '더 불러오기'로 다음 파일을 받습니다.

### 서식 처리

- 쪽 맞춤에서 들여쓰기가 더 깊은 부연설명과 연속 줄을 앞 항목과 같은 쪽에 묶습니다.
- 작업 방식 카드에 '표 셀 내 그림을 배경으로 변경' 옵션을 더했습니다(기본 꺼짐).

### 보안

- CI 액션을 커밋 SHA로 고정했습니다.
- PDF 합치기 중간 폴더가 오류·취소 뒤에도 남지 않게 했습니다.

Python 3.14 기반으로 빌드합니다.

## 배포 검증

- CI 실행 41306468520 통과(Python 3.14). 소스 시험: Python 2,003건(추진절차 재설계를 되돌리기 전 통합본, 되돌린 뒤 표 단위 시험 45건 재실행), Flutter 243건·analyze 오류 0건.
- 시작 속도(CI): 스플래시 59ms, 캐시 실행 812ms, 다시 켤 때 화면 1,688ms·1,675ms. **기준 1,500ms를 넘었고, 이번 릴리스만 사용자 결정으로 예외 처리했습니다.**
- 배포 exe 시험: 내려받은 Portable의 SHA-256 일치, 화면 내용 시험 통과(화면 오류 0건), 왼쪽 메뉴 표시, 탐색기 보내기 인자(`--rename`)가 새로 켤 때와 이미 켜져 있을 때 모두 파일명 일괄변경 목록에 들어감을 격리 환경에서 확인했습니다.
- 서식 복사 재연 시험(실제 한/글, 예시 7건): **불합격.** 1건은 불일치 0건, 6건은 불일치 2~6건입니다. 이번 변경 전 코드에서도 6건 모두 불일치가 글자까지 같아 이번 변경으로 나빠지지는 않았습니다. 앞 들여쓰기가 사라지는 문단과 표 크기·내어쓰기 값 차이 등은 다음 버전에서 원인을 찾습니다.
- 표 셀 그림→배경: 실제 한/글에서 변환·열기를 확인했습니다. 그림은 셀 크기에 맞춰 늘어나 비율이 달라질 수 있습니다(기본 꺼짐).
- 확인하지 못한 것: 부연설명이 실제 쪽 경계에서 앞 항목과 같은 쪽에 놓이는지, 실제 탐색기 '보내기' 메뉴 클릭, 타임머신 묶음 카드를 실제 문서로 보는 화면, K클립보드 실제 복사 기록. K에이전트 누수 측정은 18시간 53분에 중단해 추이 자료가 없습니다(종료 시점 전용 메모리 4.28MB, 핸들 214).
