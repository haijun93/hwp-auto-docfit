# 한글편집 후처리 v1.72 Beta 15 (핫픽스)

Windows 64비트용 테스트 베타 릴리스입니다. 자동 업데이트 오류와 표 날짜 줄바꿈을 고친 핫픽스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **자동 업데이트 오류 수정**: 업데이트 뒤 새 버전이 `Failed to load Python DLL … _MEI…\python312.dll` 오류로 켜지지 않던 문제를 고쳤습니다. 구버전이 넘긴 실행 파일 내부 환경 변수 때문에 새 버전이 이미 지워진 구버전 임시 폴더를 찾던 것이 원인입니다. 이제 새 버전을 실행하기 전에 이 변수를 지웁니다.
  - **안내**: 업데이트는 설치돼 있던 구버전의 업데이트 기능이 수행합니다. Beta 13·14에서 이 버전으로 올릴 때 같은 오류가 나면, 아래 `HWP_AutoDocFit.exe`를 직접 내려받아 기존 실행 파일과 바꿔 주세요. Beta 15부터는 다음 업데이트가 정상으로 동작합니다.
- **표 칸 안 날짜 한 줄 표기(새 규칙)**: 표 칸에 날짜(`’26. 10. 10.(토)`, `2026. 10. 10.`, `10. 6.(화) 14:00` 등)가 주로 들어 있으면 그 칸을 "한 줄로 입력"으로 두어 칸 폭이 좁아도 날짜가 두 줄로 나뉘지 않습니다. 제목 서식 표의 날짜 칸(A2)도 서식 적용 첫 단계에서 한 줄로 둡니다. 날짜가 들어간 긴 설명 문장 칸은 바꾸지 않습니다.
- 그 밖의 기능은 Beta 14와 같습니다(기본 글꼴은 휴먼명조).
- 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.

- `HWP_AutoDocFit-v1.72-beta.15.zip` (메인 프로그램과 한 번에 적용 시험용 예시 텍스트)
