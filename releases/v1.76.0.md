# 한글편집 후처리 v1.76.0

Windows 64비트용 베타입니다. 새 화면(Flutter)과 함께 파일포맷 변경, 표/다이어그램 만들기, 상용구 관리, 한/글 조판 미리보기를 담았습니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

## 새 기능
- **한/글 붙여넣기 복사**: 표는 편집 가능한 HTML 표, 자유 도형·마인드맵은 그림으로 복사해 한/글 2020에서 Ctrl+V로 붙여넣습니다.
- **HWP→HWPX 직접 변환**: 한/글 내장 저장 사용, 원본 보존 및 기존 결과 덮어쓰기 방지.
- **tldraw 제외**: 메뉴·설정·SDK 자산을 배포에서 제외합니다. 일반 표/다이어그램은 유지합니다.
- **파일포맷 변경**: 결과 형식(HWPX·PDF·DOCX·EPUB·JPG·PNG)을 고르면 바로 변환합니다. 문서를 끌어다 놓으면 작업 방식 단계로 자동으로 넘어갑니다.
  HWP·HWPX → PDF·그림은 한/글 내장 저장을 씁니다(독자 조판 엔진 rhwp 방식과 실제 문서 7종 비교 후 채택, `docs/PDF_ENGINE_BENCHMARK_2026-10-16.md`).
- **표/다이어그램**(구 업무 흐름도): PPT 같은 도형 40여 종·선·화살표 머리 모양·테두리/바탕색, 가로·세로 시작 서식, 마인드맵, 흐름표(2~6칸, 세로 확장), 기본 표(행·열 늘리기·줄이기, 한/글과 같은 테두리 12종), 조직표·장식표. 결과는 한/글 문서로 저장합니다.
- **설정**: 글자 상용구·본문 상용구 추가·수정·삭제(매번 백업), 개발자 정보(도토리만두) 표시.
- **한/글 조판 미리보기(rhwp)**: 설정·서식 요소를 바꾸면 실제 한/글 조판 방식으로 다시 그립니다. 작업 방식의 **세부 작업**은 설정 화면과 같은 분류·카드 구성으로 바뀌었고, 단계마다 적용 전·후 조판 모습을 보여 줍니다.
- **한/글 글꼴 폴더 자동 인식**: 한/글이 설치한 글꼴(휴먼명조·한컴돋움 등)을 앱 화면과 미리보기에서 그대로 씁니다.
- **기능별 맞춤 진행 화면**: 네 가지 작업마다 단계·안내가 다른 동적 진행 화면.
- **AI 답변·Markdown → 개조식 문서**, 로마자 중제목, 범정부오피스 라벨 입력.
- **폐쇄망 모드(기본)**: 앱이 스스로 외부에 접속하지 않습니다. kordoc 꾸러미를 같은 폴더에 두면 인터넷 없이 문서를 변환합니다.

## 문서 처리 변경
- **사용자가 꾸민 표 보호**: 장식 막대 표·`(단위: …)` 캡션 표·조직도·흐름표는 모든 서식 작업에서 그대로 둡니다(기관 문서 30개·표 461개 조사, 데이터 표 오판 0건).
- **쪽 맞춤 마지막 수단** 줄 간격 최솟값 160% → **140%**(예전 기본값이 저장된 설정은 자동 이전).
