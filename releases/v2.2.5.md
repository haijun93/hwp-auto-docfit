# v2.2.5 릴리스

HWP AutoDocFit 2.2.5 릴리스 안내입니다.

## 바뀐 점

### 파일명 일괄변경

- 처음 쓰는 분도 바로 쓰도록 화면을 새로 만들었습니다. 맨 앞 글자, 맨 뒤 글자, 글자 바꾸기 중 적은 항목만 적용합니다.
- 오늘 날짜를 `2026.11.03.` 또는 `261103` 형식으로 맨 앞이나 맨 뒤에 넣습니다.
- 세부 규칙은 「고급 기능」으로 옮겼고, 사진 촬영일 규칙을 더했습니다.

### 타임머신

- 종류 필터 이름을 hwpx, docx, xlsx, ppt로 바꿨습니다.
- 파일명과 본문 검색 결과에서 검색어 바탕을 노란색으로 표시합니다.

### 몽땅클립보드

- 빠른 목록 창에 항상 위와 닫기(✕) 단추를 넣었습니다.

### 보안

- 내려받기 공급망과 문서 파일 열기를 더 엄격하게 제한했습니다(S2·S3·S6).

Python 3.14 기반으로 빌드합니다.

## 배포 검증

- CI 실행 41471929629 통과(Python 3.14, Python 회귀 2032건, Flutter 250건). 스플래시 69.24ms, 웜 시작 1,669·1,689ms(기록만).
- 배포 exe 시험: 내려받은 Portable·Setup의 SHA-256이 릴리스 값과 일치, 화면 내용 시험 통과(화면 오류 0건), 실행 중 파일 이름 변경 전달 확인. 다른 작업이 몰린 첫 시험에서 값이 흔들려 부하가 줄어든 뒤 다시 재서 정상(첫 화면 13,078ms)을 확인했습니다.
- 파일명 규칙: 접두사·접미사·글자 바꾸기·날짜를 실제 코어로 적용해 결과 파일명을 시험했습니다.

## 알려진 문제

- 파일명 쉬운 화면과 몽땅클립보드 항상 위·닫기 단추는 위젯·코어 시험만 거쳤고 실제 앱 창에서 눌러 보지 않았습니다.
- 파일명 일괄변경 화면의 구분선은 아직 고정입니다. 다음 버전에서 고칩니다.
- 서식 복사 재연의 표 높이(8082→5982)와 쪽 여백 차이가 남아 있습니다(사용자 수정 파일 대기).
