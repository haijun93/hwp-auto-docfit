# v2.2.7 릴리스

HWP AutoDocFit 2.2.7 릴리스 안내입니다.

## 바뀐 점

### 타임머신

- 문서를 오른쪽 클릭해 「연관 문서 찾기」로 내용이 비슷한 문서를 점수와 근거와 함께 봅니다. 관계없는 문서는 「연관 아님」으로 뺄 수 있습니다.
- 본문 색인을 쓴 적이 있으면 훑기가 끝날 때 추가·변경된 문서를 다시 색인하고 지워진 문서를 뺍니다. 연결이 끊긴 드라이브의 문서는 지우지 않습니다.

### 표그림판

- 화살표가 있어도 표 첫 칸 글자의 세로 정렬이 바뀌지 않습니다. 빈 칸이 없는 표는 전과 같이 첫 칸이 위쪽 정렬됩니다.

### 사용 안내서

- 파일명 일괄변경, 타임머신, 표그림판, 몽땅클립보드 설명을 넣었습니다.

Python 3.14 기반으로 빌드합니다.

## 배포 검증

- CI 실행 41532624330 통과(Python 3.14, Python 회귀 2046건, Flutter 256건).
- 배포 exe 시험: 내려받은 Portable·Setup의 SHA-256이 릴리스 값과 일치, 화면 내용 시험 통과(화면 오류 0건), 새 실행과 실행 중 앱으로의 파일 전달 확인. 첫 화면 측정값 27,850ms는 워커가 함께 돌 때의 값입니다.
- 표그림판 화살표: 실제 한/글에 붙여 위치 오차 최대 0.31칸 이내 확인.
- 타임머신: 서비스 시험 44건, 화면 시험 21건 통과.

## 알려진 문제

- 연관 문서 화면과 본문 색인 자동 갱신은 코드 시험만 거쳤고 실제 앱에서 조작해 보지 않았습니다.
- 몽땅클립보드의 스티커 창 조작, 캡처 단추, 연결 프로그램은 실제 창 판정이 끝나지 않았습니다.
- 서식 복사 재연의 표 높이(8082→5982)와 쪽 여백 차이가 남아 있습니다(사용자 수정 파일 대기).
