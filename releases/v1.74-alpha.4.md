# 1.74 Alpha 4

공개 배포선은 1.74 Beta 1을 유지한다. Flutter/WebView2와 기존 Python·한/글 COM 문서 처리 경로를 유지한다.

- Linux 시험 실행기에서 실제 Tk·TkDND·pywebview·defusedxml을 사용한다. Windows 전용 모듈만 대체하며 레지스트리 미존재를 올바른 예외로 표현한다.
- GUI 시험에 디스플레이 가용성 확인과 임시 작업 폴더를 적용한다. 화면 시험은 Xvfb에서 실제 위젯으로 실행한다.
- 결과 파일과 서식예시/DLL 경로 시험의 Windows 구분자 가정을 플랫폼 독립적으로 수정한다.
- Gemini 붙여넣기의 공백 포함 강조·이스케이프·HTML 문자 참조·출처와 강조 접합을 정리하고 날짜 및 번호형 위계 처리를 보완한다.

기존 실패·오류 22시험 전부 통과(skip 0), 전체 986시험은 983통과·실패/오류 0·기존 skip 3이다. 자세한 시험 결과는 `docs/TEST_FAILURES_22_ASSESSMENT_2026-10-13.md`의 Alpha 4 기록을 참조한다. Linux GUI 검증은 Windows WebView2·한/글 COM·EXE 실기기 검증을 대신하지 않는다. Flutter 전체 이전, 코드/수식 보호 범위, 직함·이름 자간 규칙과 MCP 전용 오메가는 별도 잔여 작업이다.
