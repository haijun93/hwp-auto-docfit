# 한글편집 후처리 v1.72 Beta 14 (핫픽스)

Windows 64비트용 테스트 베타 릴리스입니다. 내어쓰기 기준을 고친 핫픽스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **내어쓰기 기준 수정(괄호 라벨)**: `ㅇ (개요) 본문`처럼 괄호 라벨 `( )`이 있는 문장의 둘째 줄을 라벨 뒤 본문이 아니라 **문두기호 뒤 첫 글자(`(`)**에 맞춥니다. 콜론 `:` 라벨(`- 추진부서 : …`, `- (운영방식) : …`)은 이전과 같이 콜론 뒤 본문에 맞춥니다. 대괄호 `[ ]`는 이전부터 기호 뒤 기준입니다.
- **콜론 공백 규칙 추가**: 글자와 `:` 사이의 빈칸은 없애고, `:` 뒤 글자와는 빈칸 1칸만 둡니다(`추진부서 : 문화경제과` → `추진부서: 문화경제과`, `비고:내용` → `비고: 내용`). 시각·비율(`10:30`, `3 : 1`), 주소·경로(`http://`, `C:\`), `::`는 건드리지 않고, 콜론 문자(반각/전각)는 바꾸지 않습니다. '문장 내 공백 정리' 단계에서 쉼표 규칙과 함께 적용됩니다.
- **기록 파일 기본 꺼짐**: 작업로그 파일, 무결성검사 JSON, 최종검수 JSON은 사용자가 설정 → 기록에서 켜기 전까지 만들지 않습니다. 예전 설정 파일에 켜짐으로 저장돼 있던 값도 처음 실행할 때 한 번만 끕니다(그 뒤 다시 켠 값은 유지).
- 자간·장평 조정이 괄호 라벨 글자를 건드리지 않는 범위는 이전과 같습니다.
- 서식을 복사해 둔 기존 프로필의 내어쓰기 규칙은 그대로 읽습니다.
- 그 밖의 기능은 Beta 13과 같습니다.
- 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.
