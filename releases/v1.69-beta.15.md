# 한글편집 후처리 도구 v1.69 Beta 15

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- **README 사용자 안내 전면 개편**
  - 초보자 중심으로 설치 → 첫 실행 → 작업 선택 → 결과 확인 순서로 재구성하고, 카드별 옵션과 문제 해결 주의사항을 쉽게 설명했습니다.
  - 상세 기능 안내는 `docs/ADVANCED_USAGE.md`, 개발자 실행·빌드 안내는 `docs/DEVELOPMENT.md`로 분리했습니다.
- **서식 복사 전면 복제 일반화·보완**
  - 문두기호 없는 본문 문장(12자 이상 등)의 대표값을 '일반 문장' 서식으로 분리 학습해 적용합니다(제목·날짜 줄 서식 보존).
  - 등가 문두기호(○↔ㅇ, □↔ㅁ)를 인식해 예시에 한쪽 기호만 있어도 반대편 기호를 쓰는 문서에 동일 계층 서식을 복제합니다.
  - 계층별 괄호 안 글자 줄임 크기(`괄호_축소_기호별`)를 독립 적용합니다(예: ㅇ는 줄이고 □는 유지).
  - 서식 프로필의 한/글 내장 HFT 글꼴 형식을 등록해 HFT 글꼴 적용 누락을 방지했습니다.
- **문두보호 줄 건너뜀 안정화**: 줄 단위 자간 자동조정 및 문장부호 줄병합 시 문두기호·라벨만 있는 줄의 한/글 거절을 감지해 안전하게 건너뛰도록 개선했습니다.
- **검수 판정 보완**: 문두기호 문장이 없는 문서에서 서식 검수를 판정 보류('incomplete') 대신 '검사할 문장 없음'(`not_applicable`)으로 정상 보고합니다.
