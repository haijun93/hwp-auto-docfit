# v2.2.10 릴리스

HWP AutoDocFit 2.2.10 릴리스 안내입니다.

## 바뀐 점

### 파일명 일괄변경

- 창이 낮거나 목록 칸을 작게 줄여도 빈 목록 안내가 넘치지 않고 스크롤됩니다.

### 시험 안정성

- 자동 시험이 사용자의 실제 설정 폴더(%APPDATA%)에 쓰지 않도록 격리했습니다. 앱 동작은 바뀌지 않습니다.
- 타임머신 연관 문서·색인 갱신을 배포 파일로 판정하는 시험 도구를 넣었습니다.

Python 3.14 기반으로 빌드합니다.

### 타임머신

- 조사 폴더가 Temp·AppData 아래에 있어도 본문 색인이 됩니다. 깨진 시스템 파일 이름(#IEeEE'.docx 등)은 색인에서 뺍니다.
- 달력이 일요일부터 시작합니다.

### 설치·실행

- 이전 버전 캐시에 읽기 전용 파일이 있어도 정리합니다. 몽땅클립보드 프로그램 파일이 잠겨 있으면 잠시 다시 시도하고, 그래도 안 되면 안내합니다.
- 몽땅클립보드 연결이 바쁠 때 연결 전에만 다시 시도합니다.

- 설치형 권한 오류(Permission denied)는 원인을 하나로 특정하지 못했습니다. 의심 지점 두 곳(읽기 전용 캐시 정리, 몽땅클립보드 파일 교체)을 보강했습니다.
- 서식 복사 재연의 표 높이(8082→5982)와 쪽 여백 차이가 남아 있습니다(사용자 수정 파일 대기).
