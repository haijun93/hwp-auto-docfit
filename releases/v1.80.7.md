# v1.80.7 — 2026-10-23

바둑판에 선을 그어 한/글 표로 바로 붙여 넣는 **「표그림판」**을 새로 더하고, **표 템플릿**의 모양과 칸 수 조절을 대폭 넓힌 버전입니다. 아울러 상단 메뉴 구성과 다이어그램 탭 정돈, 둥근 선택 메뉴 확대, 한/글 글자 상용구 그대로 보존, 업데이트 안정화와 함께 지난 1.80.6의 개선 사항(서식 관리 및 내어쓰기 정상화, 서식예시 자동 등록, 여백 우선 쪽 맞춤, 윈도우 우클릭 변환, 명령줄 도구)을 모두 담았습니다.

## 새로 된 점

- **표그림판(상단 메뉴 「표그림판」)**:
  - 엑셀처럼 점선 바둑판 용지에 가로·세로·대각선(45°) 직선을 그리면 한/글에 붙여 넣을 수 있는 표가 완성됩니다. 선은 격자점에 자석처럼 딱 붙습니다.
  - 사각형·지우개·글·선택 도구를 제공하며, 선 굵기(얇게·굵게·이중)와 종류(실선·파선·점선)를 자유롭게 고르고 실행 취소도 지원합니다.
  - 선으로 둘러싼 직사각형 영역은 칸 하나로 합쳐지고, 선을 그리지 않은 경계는 보이지 않는 테두리로 처리되어 조직도처럼 상자와 선으로 된 서식도 자유롭게 그릴 수 있습니다.
  - 「조직도 예시」 불러오기, 작업 저장·불러오기, 표 모양 미리보기, 「한/글에 붙여넣기용 복사」를 지원합니다.
  - 마우스 휠(가로 이동은 Shift+휠)과 스크롤 막대로 화면을 편하게 움직일 수 있고, Ctrl+휠로 화면을 확대하거나 축소할 수 있습니다.
- **표 템플릿 대폭 보완**:
  - 화면을 T자형으로 바꾸어 위쪽에 모든 표 이름 버튼이 나열되고, 왼쪽 분류 버튼도 잘림 없이 한눈에 보입니다.
  - 화살표가 그림으로 된 표(추진절차·신구대조표)도 미리보기에 화살표가 그대로 보입니다.
  - [−][+]로 칸 수를 늘리고 줄이는 정보단위 표를 대폭 추가했습니다:
    - 현황표(가로): 행 단위 조절
    - 추진절차(가로) 모양1~5: 행 단위 조절
    - 추진절차(가로세로): 행과 열 두 방향 모두 조절
    - 신구대조표 모양1: 행 단위 조절
    - 신구대조표 모양3: 빈 행과 정보 행 한 쌍을 묶음으로 조절
    - 일정표(일간)·행사시간표·행사표(1일) 모양1: 열 단위 조절
    - 사진첨부용 모양1·2: 사진 행과 설명 행 묶음을 아래로 하나 더 추가
  - 표 서식 모음 36종을 한/글이 실제로 그린 모양 그림(스냅샷)으로 보고 고르며, 검색·즐겨찾기·최근 사용으로 원하는 표를 빠르게 찾을 수 있습니다.
  - 기존 정보단위 지원(분야별과제표 과제 묶음, 추진절차 상자+화살표, 행사시간표 시간 줄, 일정표 일간·연간·월별·주간 등)도 함께 제공됩니다.
  - 늘린 칸 글은 기본으로 「연도·번호 +1」이 적용됩니다(예: 2026 → 2027, 1. → 2.).
  - 미리보기에서 칸을 눌러 글을 바로 입력하거나 고칠 수 있습니다.
  - 가로 단위를 늘려도 표 전체 폭은 그대로 유지되며, 칸 안의 글상자 표도 비율에 맞춰 미리보기에 표시됩니다.
  - 라벨·부연설명처럼 반복 단위가 없는 고정 표도 단위를 표시해 알아보기 쉽게 했습니다.
  - 「한/글에 붙여넣기용 복사」를 누르면 불필요한 빈 문단 없이 표만 복사되고, 한/글 창이 맨 앞으로 올라와 바로 Ctrl+V로 붙여넣을 수 있습니다(테두리·색·글꼴 유지, 사용자가 작업 중인 한/글 문서는 건드리지 않음).
  - `C:\HWP_AUTODOCFIT\표서식모음\표 서식모음.hwpx`를 고치면 그 파일을 쓰고 모양 그림도 새로 만듭니다(없으면 앱 내장본).
- **상단 메뉴 나열 개선**:
  - 서식 관리, 다이어그램, 마인드맵, 표 템플릿, 표그림판 메뉴를 프로그램 상단에 나란히 배치했습니다.
  - 「서식 관리」를 누르면 썸네일로 선택, 서식예시 확인, 서식예시 폴더, 서식관리 하위 메뉴가 펼쳐집니다.
  - 창 폭이 좁아지면 글자 대신 아이콘만 표시해 화면을 넓게 씁니다.
- **다이어그램 편집기 탭 정돈**:
  - 편집기 탭을 다이어그램, 마인드맵, 표 템플릿으로 정돈했습니다.
  - 흐름표와 기본 표는 목록에서 제외되었으며, 예전에 만든 문서는 내용이 지워지지 않고 다이어그램으로 안전하게 열립니다.
- **원형 옵션 1.5배 확대**:
  - 파일 변환의 둥근 형식 선택 메뉴와 첫 화면 작업 방식 카드의 선택 원·아이콘을 1.5배로 키워 글자와 단추를 더 또렷하고 누르기 쉽게 개선했습니다.
- **한/글 글자 상용구 복원 및 호환**:
  - 한/글 상용구 파일(`HWP.IDO`)의 같은 준말 여러 개와 세부 속성까지 상용구 설정 문서에 담고, 그대로 한/글 파일로 되돌립니다(실제 상용구 180개 왕복 일치 확인).
- **업데이트 검증 안정화**:
  - 새 버전 검증 단계가 일부 PC의 파워셸(PowerShell) 환경에서 멈추던 문제를 고쳤습니다.
- **서식 관리 및 내어쓰기 옵션 정상화**:
  - 서식 관리에서 「적용할 서식」을 바꿔도 처음 서식에 고정되던 문제를 고쳤습니다(1.80.0부터 있던 문제로, 설정 창을 한 번도 열지 않았을 때 발생).
  - 서식을 바꿀 때 그 서식의 옵션(내어쓰기·부연설명 들여쓰기 등)이 함께 바뀌지 않아, 다른 서식으로 한 번에 적용해도 항목기호별 내어쓰기와 붙임 번호 내어쓰기가 빠지던 문제를 고쳤습니다.
- **서식예시 폴더 자동 등록**:
  - 서식예시 폴더(`C:\HWP_AUTODOCFIT\서식예시`)에 HWP/HWPX 예시를 넣어 두면 앱을 켤 때·서식 관리 창을 열 때 자동으로 찾아 서식으로 등록합니다. 넣은 파일은 그대로 두고, 지금 고른 서식은 바꾸지 않습니다.
- **쪽 맞춤 여백 우선 조정**:
  - 줄간격을 권장 160%보다 낮추기 전에 위·아래 쪽 여백을 최소 5mm까지 먼저 줄입니다(줄간격 140%는 읽기 어렵기 때문).
  - 한 번에 적용에서만, 서식이 위·아래 여백을 따로 정하지 않은(기본값) 경우에만, 보고서가 하나인 문서에서만 씁니다(취합보고서는 여백을 바꾸면 모든 보고서의 쪽 맞춤이 무너지므로 제외).
- **서식 세부 수정의 쪽 여백을 한/글 「편집 용지」처럼**: 종이 그림을 가운데 두고 위쪽·머리말·왼쪽·제본·오른쪽·꼬리말·아래쪽 칸을 한/글과 같은 자리에 놓았습니다. 0.1mm씩 올리고 내릴 수 있고, 값을 바꾸면 그림도 함께 바뀝니다.
- **업데이트(설정 → 프로그램)**:
  - 「지금 확인」으로 바로 새 버전을 확인하고, 진행률을 보며 내려받아 바꿉니다. 바뀐 점도 함께 보여 줍니다.
  - 공공기관 PC에서도 되도록 GitLab에서 먼저 확인합니다(GitHub가 막혀 있어도 됨). 설치본은 설치 파일로 조용히 설치한 뒤 다시 켜지고, 포터블은 실행 파일을 바꿔 끼웁니다.
  - 내려받은 파일은 크기와 SHA-256으로 확인하고, 30초 동안 응답이 없으면 멈춥니다. 앱을 켜 둔 동안 6시간마다 새 버전을 확인합니다.
  - 폐쇄망 모드에서는 인터넷에 접속하지 않고, 새 설치 파일을 실행하거나 포터블 파일을 복사해 바꾸는 방법을 안내합니다. 새 버전으로 바뀐 뒤 처음 켤 때 알려 드립니다.
  - 지난 버전의 자동 업데이트가 설치 파일·포터블 파일이 함께 있는 릴리스에서 새 버전을 찾지 못하던 문제도 고쳤습니다.

- **명령줄(CLI) 변환 도구**:
  - 터미널이나 배치 파일에서 파일을 바로 변환할 수 있는 명령줄 도구를 지원합니다:
    `HWP_AutoDocFit.exe convert 파일·폴더·*.hwp --to pdf|hwpx|hwp|docx|pdfm|pdfz …`

## 검수

- 표그림판: 조직도 그림을 한/글에 붙여 넣어 4행·8열·28칸·병합 4칸이 미리보기와 같음.
- 글자 상용구: HWP.IDO 180개 → 설정 문서 → 다시 만든 HWP.IDO가 원본과 바이트 단위로 같음, 한/글 2020에서 열림 확인.
- 업데이트: GitHub 조회·204MB 내려받기 45초·SHA-256 일치·재사용 1초.
- 표 템플릿 전체 실측: 각 표를 정보단위 1개 늘려 복사 → 한/글 새 문서에 붙여넣기 → 표 구조·테두리 대조 46/46 합격, 빈 문단 0.
- 조직도 실제 붙여넣기 3·4·6·8팀 확인.
- 우클릭 메뉴 실측(레지스트리에 실제 등록 → 탐색기와 같은 명령 실행 → 해제): HWPX→PDF, HWP 3개→HWPX 3개(20.6초), HWP 3개→PDF 3개(18.8초), PDF 2+HWP 1+그림 1→PDF 하나(25.4초), 스캔 PDF 압축(6.9초) 모두 성공. 시험 뒤 메뉴 등록 흔적 없음.
- 실측에서 찾아 고친 결함 2건: 사용자 폴더 밖 파일을 버리던 문제, 처리 도중 강제 종료되면 이후 우클릭 요청이 멈추던 문제.
- 서식 선택·내어쓰기 실측: 내어쓰기 테스트2를 기본 보고서 서식·1장 보고서 서식으로 한 번에 적용 → 항목기호별 내어쓰기·붙임 번호 정렬 정상.
- 쪽 맞춤 여백 실측: 1장 보고서 서식에서 위·아래 여백 12.7→5mm가 줄간격 축소보다 먼저 적용, 줄간격 145%→150%로 가독성 개선.
- 서식예시 자동 감지 실측: 폴더의 1장 보고서.hwpx가 30초 만에 서식으로 등록, 원본 파일 변화 없음·중복 등록 없음.

- Flutter 화면 시험: 129개 통과(1개 건너뜀), 분석 오류 0.
- 서식 예시 3종 재연(scripts/format_fidelity_pc.py): 불일치 0/0/0, 합격.
- 작업 분담: 정보단위 엔진·명령줄 Codex, 표 템플릿 화면·메뉴 재구성·여러 파일 모으기 Gemini, 판정표·실측·통합 Claude.
