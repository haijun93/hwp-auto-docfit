# 한글편집 후처리 도구 v1.69 Beta 6

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- **작업 카드를 3장으로 정리**: 자간 정리 · 서식 통일 · 한 번에 적용
  - 예전 '서식 적용'은 '한 번에 적용' 카드의 **자간 조정 포함**을 끄면 됩니다. 기존 자간은 그대로 두고 서식만 입히며, 결과는 `문서이름(서식적용).hwpx`입니다.
  - 고른 값은 다음 실행에도 기억합니다.
- **서식통일을 함께 켰을 때 서식이 되돌려지던 문제 수정**(한 번에 적용·서식 적용): 부연설명 괄호의 2pt 축소와 최종 내어쓰기가 원래대로 돌아가던 문제를 고쳤습니다.
- **쪽 범위 작업 수정**: 문서를 고치기 전에 쪽 범위를 확정하고, 범위 안 빈 줄을 지운 뒤 다음 쪽 문단까지 고치던 문제를 고쳤습니다.
- **처리 시간 단축**: 별표 위첨자·붙임 글꼴·제목·개요·붙임·기본 표 서식을 이어서 한 번에 처리해 문서 저장·다시 열기를 줄였습니다(시험 문서에서 약 10~17% 단축). 저장 후 검수도 결과 문서를 한 번만 엽니다.
- **여러 문서 처리 중 멈춤 해소**: 서식통일 결과 확인 창이 작업을 멈추지 않습니다. 여러 문서를 한꺼번에 처리할 때는 창 대신 처리 기록과 최종검수 보고서에 남깁니다.
