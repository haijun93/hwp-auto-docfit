# 한글편집 후처리 v1.74 Alpha 3

개발용 알파 소스입니다. 공개 베타는 v1.74 Beta 1이며 새 배포 EXE·태그는 만들지 않습니다.

- 요청 시간 초과 후 명령이 뒤늦게 실행되는 문제를 고쳤습니다. 실행 중인 명령은 중복 실행을 피하도록 안내합니다.
- 종료 시 기다리던 화면 요청을 해제하고, 종료 확인을 취소하면 앱을 계속 사용할 수 있게 합니다.
- 새 문서/새 작업에 이전 쪽 범위가 남거나 오래된 조회가 최신 상태를 덮는 문제를 고쳤습니다.
- Flutter 설정에서 준말 검색·등록·수정·삭제·기본값 선택을 제공합니다. 기존 Tk 화면과 같은 서비스를 쓰며 학습된 표 서식과 다른 설정을 보존합니다.
- 잘못된 준말 서식 값(list/dict)이 있더라도 정상 등록표를 읽을 수 있습니다. 원래 저장값은 임의로 지우지 않습니다.
- Flutter 검사·테스트·웹 빌드·자산 검증에 실패하면 EXE 빌드를 중단합니다. 런타임의 비상 복구 경로는 유지합니다.

## 이전 버전 대비 개선 효과

수정 전 위젯 회귀에서 새 문서/새 작업이 이전 5–7쪽을 다시 보내고 오래된 poll이 새 작업 모드를 덮는 세 실패를 확인했습니다. 수정 후 해당 회귀가 통과합니다. Python 요청 취소/종료 회귀도 추가했습니다. 준말 CRUD·데이터 호환·저장 실패·작업 중 제약은 별도 서비스/화면 시험으로 확인합니다.

Windows 문서 처리 시간·품질·메모리·EXE 성능은 아직 측정하지 않았습니다. 수치를 추정하지 않으며 [시험 보고서](../docs/FLUTTER_TEST_REPORT.md)에 Linux 검증과 미실시 항목을 구분합니다. 전체 Flutter 전환 완료를 의미하지 않습니다.
