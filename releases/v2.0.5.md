# v2.0.5 — 2026-10-30

HWP AutoDocFit 2.0.5 릴리즈 안내입니다.
이번 버전의 변경 사항은 다음과 같습니다.
- 표 템플릿에 공공기관 보고서용 표 45개를 더했습니다.
- 한/글에서 복사한 표를 표그림판에 붙여 넣어 고칠 수 있습니다.
- 표그림판·다이어그램·그림판에 레이어 기능을 넣었습니다.
- 첫 실행 시작 화면을 더 빨리 띄웁니다.

---

## 바뀐 점

### 1. 표 템플릿 45개 추가
- 공공기관 보고서·계획서·검토서에 자주 쓰는 표 18종을 더했습니다.
  - 사업개요표, 추진실적표, 예산집행표, 연도별 추진계획표, 월별 실적표, 문제점·개선방안표
  - 대안비교표, 업무분장표, 성과지표표, 점검표(체크리스트), 참석자 명단, 민원처리 현황표
  - 비상연락망, 위원 명단, 추진경과표, SWOT 분석표, 평가표(심사표), 인력 현황표
- 표마다 디자인을 2~3가지 넣었습니다. 디자인은 상용 문서 서비스의 표 스타일을 참고한 5가지 유형입니다.
  - 청색 머리글
  - 선 강조(세로선 없는 미니멀)
  - 진한 머리글 줄무늬
  - 첫 열 강조
  - 합계 강조
- 행과 열을 정보 단위로 늘리고 줄일 수 있습니다.
  - 행은 본문 한 줄 단위입니다.
  - 열은 연도·월·대안처럼 같은 성격의 열 단위입니다. 예를 들어 연도를 늘리면 2029년, 2030년이 이어서 채워집니다.
  - 합계 행과 계·비고 열은 늘린 뒤에도 끝에 남습니다.
- 사용자가 고쳐 쓰는 표 서식모음과 함께 보입니다. 템플릿마다 한/글로 그린 미리보기 그림이 들어 있습니다.

### 2. 표그림판 '한/글 표 붙여넣기'
- 한/글 문서의 표를 선택해 복사(Ctrl+C)합니다. 그다음 표그림판에서 '한/글 표 붙여넣기'를 누르면 표가 선과 글로 들어옵니다.
- 표에서 다음 정보를 그대로 가져옵니다.
  - 칸 크기, 칸 합치기
  - 테두리 굵기(가는 선·굵은 선·이중선)와 종류(실선·파선·점선)
  - 글, 굵게, 정렬
- 표그림판에서 고친 뒤 '한/글에 붙여넣기용 복사'로 다시 한/글에 넣을 수 있습니다. 이미 있는 문서의 표를 쉽게 다시 쓸 수 있습니다.
- 칸 바탕색은 아직 가져오지 않습니다.

### 3. 레이어(표그림판·다이어그램·그림판)
- 포토샵처럼 개체를 레이어로 나눕니다.
- 레이어마다 다음을 할 수 있습니다.
  - 보이기·숨기기
  - 잠그기
  - 이름 바꾸기(두 번 누르기)
  - 위·아래 순서 바꾸기
  - 레이어 삭제(안의 개체도 함께)
- 고른 개체는 다른 레이어로 옮길 수 있습니다.
- 숨긴 레이어의 개체는 한/글 표·그림 복사·PNG 내보내기에 넣지 않습니다. 잠근 레이어는 보이지만 고를 수 없습니다.
- 새로 그린 개체는 지금 고른 레이어에 들어갑니다. 레이어가 없던 예전 문서는 레이어 하나로 열립니다.

### 4. 첫 실행 시작 화면 더 빨리
- 첫 실행 때 뜨는 시작 화면(스플래시)을 가벼운 Windows 기본 창으로 바꿨습니다.
- 같은 PC에서 시작 화면이 보이기까지 걸리는 시간이 280~440ms에서 140~160ms로 줄었습니다.
- 시작 화면에는 제목 줄이 없습니다. 그림과 진행 막대는 그대로입니다.

### 5. 고친 점
- 표그림판 칸 글의 일부 한글과 ○ 같은 기호가 □로 보이던 문제를 고쳤습니다. 이제 앱에 든 한글 글꼴로 그립니다.

## 알려진 점

- 그림판을 한/글에 붙여 넣으면 지금은 그림 한 장으로 들어갑니다. 한/글 안에서 고칠 수 있는 묶음 개체로 붙이는 기능은 다음 버전에서 넣습니다.
- 재실행 시작 시간(목표 1.5초)은 CI에서 1.4~1.9초로 측정마다 차이가 큽니다.

- Python 단위 시험, Flutter 위젯 시험, 편집기 모델 시험(`diagram_editor`) 모두 통과.
- 한/글 실제 시험(COM)

- 실제 앱 화면 시험
