# v2.2.3 릴리스

HWP AutoDocFit 2.2.3 릴리스 안내입니다.

## 바뀐 점

### 표

- 표 템플릿 「추진절차(가로세로) · 모양 1」: 정보단위를 늘리고 줄이면 상자와 방향 화살표가 함께 움직입니다.
- 표그림판: 「조직도 예시」를 「공룡 예시」로 바꿨습니다. 공룡과 선인장을 칸으로 그린 표입니다.
- 표 셀 그림을 배경으로 바꾸는 카드 옵션이 실제로 적용되도록 연결했습니다.

### 다이어그램

- 한/글로 복사할 때 마름모, 연결선과 화살표가 보이고 도형 글자가 가운데에 놓입니다.
- 다이어그램을 복사할 때 기본 서식 문서의 예시 글이 함께 붙던 오류를 고쳤습니다.
- 글자가 없는 도형 때문에 변환이 멈추던 오류를 고쳤습니다.
- PNG·HWPX로 내보내기 전에 저장 위치를 고릅니다.

### 앱 안정성

- 오래 쉬었다 돌아왔을 때 화면이 하얗게 남던 문제를 막았습니다.
- 백엔드 연결이 끊겨도 다음 상태 조회에서 다시 연결합니다.
- 창을 닫을 때 닫기 처리가 두 번 실행되던 문제를 고쳤습니다.
- 파일변환 화면의 파일 목록에 스크롤 막대를 표시합니다.

### 몽땅클립보드

- K클립보드의 이름을 몽땅클립보드로 바꿨습니다.
- 빠른 목록 창에 스티커 모드와 항상 위 표시 설정을 넣었습니다.

Python 3.14 기반으로 빌드합니다.
