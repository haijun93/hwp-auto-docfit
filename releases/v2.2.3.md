# v2.2.3 개발 중

차기 패치 버전 개발을 시작했습니다. 아직 배포본이나 릴리스 태그는 없습니다.

## 포함할 수정

- 추진절차(가로세로) 모양 1에서 정보단위를 상자와 방향 화살표가 함께 늘고 줄도록 복원합니다.
- 표·다이어그램 PNG/HWPX 내보내기 전에 저장 위치를 선택합니다.
- 표 셀 그림을 배경으로 바꾸는 카드 옵션을 WebView 브리지에 연결합니다.
- WebView2가 유휴 상태 뒤 흰 화면으로 남지 않도록 합니다.
- 백엔드 연결이 끊긴 뒤 다음 상태 조회에서 안전하게 재연결합니다.
- 사용자 표시 이름을 몽땅클립보드로 통일합니다.

## 배포 전 확인

- Python 회귀 시험과 Flutter 시험을 실행합니다.
- Windows CI에서 설치형·포터블 실행 파일의 빌드, 시작, 기능 검증을 확인합니다.
- 실제 Windows에서 장시간 유휴 화면 복구, PNG 저장, 옵션 토글, 재연결을 확인합니다.
- 릴리스 자산의 SHA-256과 최신 다운로드 링크를 확인합니다.
