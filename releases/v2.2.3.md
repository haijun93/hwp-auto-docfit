# v2.2.3 릴리스

HWP AutoDocFit 2.2.3 릴리스 안내입니다.

## 바뀐 점

### 표

- 표 템플릿 「추진절차(가로세로) · 모양 1」: 정보단위를 늘리고 줄이면 상자와 방향 화살표가 함께 움직입니다.
- 표그림판: 「조직도 예시」를 「공룡 예시」로 바꿨습니다. 공룡과 선인장을 칸으로 그린 표입니다.
- 표 셀 그림을 배경으로 바꾸는 카드 옵션이 실제로 적용되도록 연결했습니다.

### 다이어그램

- 한/글로 복사할 때 마름모, 연결선과 화살표가 보이고 도형 글자가 가운데에 놓입니다.
- 다이어그램을 복사할 때 기본 서식 문서의 예시 글이 함께 붙던 오류를 고쳤습니다.
- 글자가 없는 도형 때문에 변환이 멈추던 오류를 고쳤습니다.
- PNG·HWPX로 내보내기 전에 저장 위치를 고릅니다.

### 앱 안정성

- 오래 쉬었다 돌아왔을 때 화면이 하얗게 남던 문제를 막았습니다.
- 백엔드 연결이 끊겨도 다음 상태 조회에서 다시 연결합니다.
- 창을 닫을 때 닫기 처리가 두 번 실행되던 문제를 고쳤습니다.
- 파일변환 화면의 파일 목록에 스크롤 막대를 표시합니다.

### 몽땅클립보드

- K클립보드의 이름을 몽땅클립보드로 바꿨습니다.
- 빠른 목록 창에 스티커 모드와 항상 위 표시 설정을 넣었습니다.

### 개발

- 시작 속도는 CI에서 기록만 하고 빌드를 막지 않습니다. 같은 PC 비교에서 v2.2.2 2,721ms, v2.2.3 2,746ms였습니다.

Python 3.14 기반으로 빌드합니다.

## 배포 검증

- CI 실행 41450044952 통과(Python 3.14, Python 회귀 2010건, Flutter 245건). 스플래시 56.64ms, 웜 시작 1,743·1,725ms(기록만, 기준 폐지).
- 시작 속도 비교(같은 PC, 번갈아 6회, 직접 빌드, `kagent.exe` 없음, 캐시 분리): v2.2.2 중앙값 2,721ms, v2.2.3 2,746ms.
- 배포 exe 시험: 내려받은 Portable·Setup의 SHA-256 확인, 화면 내용 시험 통과(화면 오류 0건), 실행 중 파일 이름 변경 전달 확인.
- 표그림판 공룡 예시: 실제 한/글에서 HWPX를 열어 그림으로 확인(27행 54열, 165×67.5mm).
- 다이어그램: 앱과 같은 복사 함수로 격리 한/글에 붙여넣어 타원·사각형·마름모, 연결선 2개, 글자만 들어옴을 확인.

## 알려진 문제

- 실제 창에서 PNG 저장 위치 대화상자, 오래 쉰 뒤 흰 화면 복구, 표 셀 그림 옵션의 화면 저장은 시험하지 않았습니다.
- 다이어그램은 앱 화면의 메뉴 클릭이 아니라 같은 서비스 함수를 호출해 시험했습니다.
- 몽땅클립보드 스티커 창의 위치·크기는 아직 저장되지 않습니다.
- 서식 복사 재연의 표 높이(8082→5982)와 쪽 여백 차이가 남아 있습니다(사용자 수정 파일 대기).
