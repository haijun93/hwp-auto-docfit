# 한글편집 후처리 v1.72 Beta 11

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **서식 적용 시간 단축(XML 일괄 서식)**: 기본 보고서 서식의 단순 본문은 HWPX에서 한 번에 서식을 입힙니다(실측: 서식 단계 37~45% 단축). 복잡한 문단은 기존 방식으로 처리합니다. 새 글꼴은 Windows 글꼴 목록으로 형식(TTF/HFT)을 판정합니다.
- **쪽 수 맞춤 최적화**: 보고서 범위만 훑고 표 칸 목록을 재사용합니다(실측: 14쪽 문서 쪽 맞춤 257초 → 200초).
- **서식 통일 '원본 쪽 구성 유지'**: 켜면 보고서별 쪽 수·시작 쪽을 원본과 같게 맞춥니다(기본 켬). 한 번에 적용·서식 적용은 문서 유형별 쪽 맞춤(1쪽 보고서는 1쪽)만 합니다.
- **표 묶음 쪽 배치**: 줄간격으로 옮기지 못한 표 제목 묶음은 쪽 나누기로 다음 쪽에 옮깁니다. 결과에는 보고서 경계와 이 묶음 이동의 쪽 나누기만 남깁니다.
- **자동 업데이트 개선**: 내려받은 파일의 크기·실행 파일 여부·SHA-256을 확인하고, 구버전을 백업한 뒤 신버전으로 바꿉니다. 실패하면 구버전을 되살립니다. 다음 실행 때 남은 파일을 정리합니다.
- **업데이트 보안 강화**: SHA-256 정보가 없으면 설치하지 않고, 교체 직전에 다시 확인하며, 검증되지 않은 파일은 실행하지 않습니다.
- TXT 등 HWP가 아닌 문서에서 쪽 수 초과를 잘못 판정하던 문제를 고쳤습니다.
- 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.
