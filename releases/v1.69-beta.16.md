# 한글편집 후처리 도구 v1.69 Beta 16

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- **서식 예시 확인**
  - 한 번에 적용 카드의 '서식 기준'에 **서식 예시 확인** 버튼을 추가했습니다. 고른 서식을 예시 보고서에 입혀 한/글로 보여 줍니다.
  - 예시 보고서는 제목(부제 포함)·개요·중제목 Ⅰ~Ⅳ·□/ㅇ/-/*/**/※ 문장·표 2개·붙임으로 구성된 가상 보고서이며, '한 번에 적용'(서식 + 자간 정리)으로 만듭니다.
  - 서식마다 예시 파일을 하나씩 만들어 보관하고, 다시 확인할 때는 바로 엽니다. 서식을 고치거나 앱이 업데이트되면 새로 만들고, 서식을 삭제하면 예시도 지웁니다.
- **공문 띄어쓰기 규정(「2025 행정업무운영 편람」)**
  - 끝 표시는 마침표 뒤 두 칸(`…1부.  끝.`), 붙임 표시문은 '붙임' 뒤 두 칸(`붙임  계획서 1부.`)으로 맞추고, 공백 정리가 이 두 칸을 한 칸으로 줄이지 않습니다.
  - 날짜는 `2021. 12. 12.`처럼 마침표 뒤 한 칸, 앞자리 0 없이 맞춥니다.
  - 서식 적용·한 번에 적용의 공백 정리와 자간 정리 모두에 적용됩니다.
- **로마자 중제목 쪽 배치**
  - 'Ⅱ 추진 계획' 같은 로마자 중제목 + □ + 첫 ㅇ 문장(딸린 -·*)을 쪼갤 수 없는 한 묶음으로 보고 한 쪽에 둡니다. 쪽 끝에 중제목만 홀로 남지 않습니다.
  - 중제목 표를 앞 문장의 표로 잘못 보아 '표 묶음 쪽 분리'로 보고하던 문제를 고쳤습니다.
