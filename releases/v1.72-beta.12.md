# 한글편집 후처리 v1.72 Beta 12

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **처리 시간 단축(문단 글 한 번 읽기)**: 공백 정규화 단계가 문단마다 같은 글을 여러 번 읽던 것을 한 번만 읽도록 바꿨습니다. 결과는 같고 시간이 줄었습니다(실측: 보고서 예시 파일 179.6초 → 168.6초, −6.1%. 14쪽 문서 −4.2%).
- 성능 기준값을 정해 두고 판마다 같은 조건으로 비교합니다.
- 그 밖의 기능은 Beta 11과 같습니다(서식 일괄 적용, 쪽 수 맞춤 최적화, 자동 업데이트 개선·보안 강화 등).
- 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.
