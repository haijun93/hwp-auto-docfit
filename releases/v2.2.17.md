# v2.2.17 릴리스

HWP AutoDocFit 2.2.17 릴리스 안내입니다.

## 바뀐 점

### 사이드메뉴

- 사이드메뉴 버튼이 세 단계로 바뀝니다: 펼치기 → 아이콘만 → 사이드메뉴만(오른쪽 화면 숨김).
- 사이드메뉴 항목에 마우스를 올리면 누르지 않아도 해당 화면이 열립니다(스치듯 지나갈 때는 열리지 않게 잠깐 기다림, 키보드 이동도 지원).
- '새문서'를 '서식 고르기'로 바꾸고, 목록 맨 위에 서식 없이 빈 한/글 문서를 여는 '새문서 작성(서식X)'을 추가했습니다.
- 개발자 모드: 사이드바 아래 '항상 위'·'사이드메뉴 모드' 버튼이 두 번씩 보이던 문제를 고쳤습니다. 두 버튼이 실제 창 기능에 연결되지 않던 문제도 함께 고쳤습니다.

### 표그림판

- 예시 그림에 공룡과 미로(15×15, 입구에서 출구까지 이어지는 길)를 추가했습니다.

### 공문서 위계 분석 엔진(개발 3·4단계)

- 상위 단계 없이 나온 하위 번호와 단계 건너뜀을 찾아내는 진단을 추가했습니다. 아직 앱 동작에는 연결하지 않았습니다.

Python 3.14 기반으로 빌드합니다.
