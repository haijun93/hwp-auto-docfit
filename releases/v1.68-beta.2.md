# 한글문서 후처리 도구 v1.68 Beta 2

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- 작업 유형을 **자간 정리 · 서식 통일 · 서식 적용 · 한 번에 적용** 네 가지로 나눠 각각 따로 실행할 수 있습니다.
- **서식 통일**을 독립 작업으로 분리했습니다. 여러 사람이 쓴 문서를 문두기호(□·ㅇ·-·*·※)별로 이 문서에서 가장 많이 쓴 글꼴·크기·장평으로 맞추고, 자간과 설정한 표준서식은 건드리지 않습니다. 결과는 `(서식통일).hwpx`로 저장합니다.
- 카드 이름을 ‘서식 정리’ → ‘서식 적용’, ‘한 번에 정리’ → ‘한 번에 적용’으로 바꿨습니다. 빠른 선택(기본후처리·전문후처리)은 그대로입니다.

다운로드: `HWP_AutoDocFit.exe` (Windows 64비트)

SHA-256: `SHA256_PLACEHOLDER`
