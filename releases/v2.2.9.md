# v2.2.9 릴리스

HWP AutoDocFit 2.2.9 릴리스 안내입니다.

## 바뀐 점

### 몽땅클립보드

- 「항상 위」 단추로 항상 위를 실제로 켜고 끕니다. 꺼도 창은 닫기 단추를 누를 때까지 그대로 있습니다.
- 접어도 창 폭이 줄지 않고, 접힌 창에서 머리글이 잘리지 않습니다.

### 타임머신

- 확장자 설정에서 뺀 문서와 조사 폴더에서 뺀 문서는 다음 훑기 때 본문 색인에서 지웁니다. 연결이 끊긴 폴더의 색인은 그대로 둡니다.

Python 3.14 기반으로 빌드합니다.

## 배포 검증

- CI 실행 41545607966 통과(Python 3.14, Python 회귀 2060건, Flutter 257건).
- 배포 exe 시험: 내려받은 Portable·Setup의 SHA-256이 릴리스 값과 일치, 화면 내용 시험 통과(화면 오류 0건, 첫 화면 24,842ms), 새 실행과 실행 중 앱으로의 파일 전달 확인. 첫 화면 측정값은 워커가 함께 돌 때의 값입니다.
- 몽땅클립보드: 배포 파일에 든 kagent를 시험 폴더로 격리해 창 판정. 초기 창, 줄 고정, 오른쪽 클릭 메뉴, 접기, 펼치기, 항상 위 합격. Rust 시험 39건 통과.

## 알려진 문제

- 몽땅클립보드의 메뉴 닫기, 테두리 끌어 크기 조절, 캡처 화면은 자동 판정하지 못해 직접 확인이 필요합니다.
- 연관 문서 메뉴와 결과 화면은 위젯 시험까지 확인했습니다. 동작은 v2.2.8 배포 파일의 내부 호출로 확인했습니다.
- 서식 복사 재연의 표 높이(8082→5982)와 쪽 여백 차이가 남아 있습니다(사용자 수정 파일 대기).
