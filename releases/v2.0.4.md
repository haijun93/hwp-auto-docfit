# v2.0.4 — 2026-10-30

HWP AutoDocFit 2.0.4 릴리즈 안내입니다.
탭 메뉴와 앱 메뉴를 상단 한 줄로 합쳤고, 작업 방식에 **페이지 맞춤**을 새로 넣었습니다. 자동 업데이트가 다시 작동하며, 표그림판·다이어그램·그림판 편집 기능을 크게 다듬었습니다.

> 시작 속도 목표(첫 실행 스플래시 100ms·재실행 1.5초)는 이번에도 기록만 했습니다. 시작 속도 개선은 다음 버전에서 이어 갑니다.

## 바뀐 점

### 1. 상단 통합 탭 줄
- 아래쪽에 있던 탭 메뉴를 위로 올리고, 사용 방법·작업 로그·설정 단추와 한 줄로 합쳤습니다.
- 탭은 아이콘과 이름을 한 줄에 둔 낮은 알약 모양입니다. 창이 좁으면 촘촘하게, 더 좁으면 아이콘만 보입니다.
- 탭 순서: 문서편집 · 표템플릿 · 표그림판 · 다이어그램 · 마인드맵 · 그림판 · 파일변환(항상 맨 끝).
- 문서편집 화면 위쪽의 다이어그램·마인드맵·표 템플릿·표그림판 아이콘은 탭과 겹쳐서 없앴습니다.

### 2. 작업 방식에 '페이지 맞춤' 신설
- 내용은 그대로 두고 여백·문단 간격·줄 간격만 다듬어 쪽 수를 맞추는 작업입니다. 결과 파일 이름은 「문서이름(페이지맞춤).hwpx」입니다.
- 작업 방식의 '파일 변환' 카드는 없앴습니다. 파일 변환은 파일변환 탭에서 합니다. 파일변환 탭에 '문서편집 목록의 문서 변환하기' 단추를 더했습니다.

### 3. 자동 업데이트 작동, 폐쇄망 모드 삭제
- 폐쇄망 모드가 기본으로 켜져 있어 업데이트 확인을 하지 않던 문제를 고쳤습니다. 폐쇄망 모드 설정은 없앴고, 앱이 새 버전을 확인해 내려받습니다(GitHub가 막힌 기관 PC는 내부 GitLab에서 받습니다).
- 문서 변환 엔진은 지금처럼 앱에 포함된 것만 쓰고, 인터넷에서 아무것도 내려받지 않습니다.
- 업데이트 안내에 새 버전의 바뀐 점 제목이 제대로 보입니다.

### 4. 표그림판
- **사각형을 다이어그램처럼**: 사각형 도구로 한 번 누르면 기본 크기 사각형이 놓이고(끌면 그 크기), 바로 골라져 손잡이 8개로 크기를 바꿀 수 있습니다.
- **빨간 맞춤 안내선**: 옮기거나 크기를 바꿀 때 다른 선과 가장자리·가운데가 맞으면 빨간 점선이 나타납니다.
- **한 번 클릭으로 모형 고르기**: 사각형 변을 누르면 네 변이, 직선을 누르면 그 직선 전체가 골라져 바로 끌어 옮길 수 있습니다. Shift+클릭으로 여러 개를 고릅니다. 그리기 도구 상태에서도 됩니다.
- **좁은 창에서 메뉴가 가려지지 않음**: 창을 줄이면 도구 줄이 다음 줄로 내려가 모든 도구가 보입니다.

### 5. 다이어그램 도형 회전
- 도형 위 동그라미 손잡이를 끌어 0~359° 돌립니다. Shift를 누르면 15°씩 돌아갑니다.
- 도형 모양 패널에서 각도를 직접 입력하거나 ⟲·⟳ 단추로 90°씩 돌릴 수 있습니다. 연결점도 도형과 함께 돌고, 그림 복사·PNG에도 돌린 모양으로 들어갑니다.

### 6. 그림판 배경 사진은 끌어 놓기로
- 탐색기에서 사진을 그림판에 끌어 놓으면 바로 배경이 됩니다(예전에는 앱이 사진을 문서 목록으로 받았습니다).
- 배경이 없을 때 그림판 가운데에 '배경 사진을 여기에 끌어 놓으세요' 안내가 보입니다.
