# v2.1.0 릴리스

HWP AutoDocFit 2.1.0 릴리스 안내입니다.

## 바뀐 점

### 왼쪽 세로 메뉴

- 왼쪽 메뉴를 접거나 펼쳐 작업 공간을 조절할 수 있습니다.
- Ctrl+1~9 단축키로 원하는 메뉴를 바로 엽니다.

### 파일명 일괄변경 메뉴 다시 열기

- 파일명 일괄변경 화면을 다시 사용할 수 있습니다.
- 탐색기에서 보내기 메뉴로 파일을 전달할 수 있습니다.
- 규칙 세트를 내보내고 가져올 수 있습니다.
- 최근 찾기·바꾸기 입력을 다시 선택할 수 있습니다.

### K클립보드 관리

- 관리 화면에서 저장된 그림을 미리 볼 수 있습니다.
- 고정한 항목을 목록 위쪽에서 확인할 수 있습니다.
- 예약 작업을 일시정지할 수 있습니다.

Python 3.14 기반으로 빌드합니다.

CI, 시작 속도, 실행 파일 스모크, SHA-256은 CI 빌드와 배포 파일 검증을 마친 뒤 기록합니다.
