# HWP AutoDocFit v1.78.0

## 주요 변경 사항

- **글자·본문 상용구를 HWPX 파일로 직접 관리**합니다. `#+준말` 다음 문단에 본말을 두는 방식으로 한/글에서 열어 수정할 수 있으며, 기존 설정 파일은 자동으로 덮어쓰지 않습니다.
- **작업 흐름을 명확히 했습니다.** 파일을 추가해도 자동 실행하지 않고, 작업 방식의 선택지를 모두 표시하며, 작업 종료 후 결과 확인 단계에서 결과와 메시지를 함께 확인합니다.
- 서식 적용의 문단 위 여백을 빈 문단과 글자 크기로 재현하고, 쪽 첫 빈 문단 다음에 항목기호 문장이 오면 불필요한 빈 문단을 정리합니다.
- 앱 시작 중 스플래시와 단일 인스턴스 보호를 제공하고, 내장 런타임 준비를 비동기로 수행합니다.
- **포터블 EXE와 사용자 설치형 Setup EXE**를 함께 제공합니다. 설치형은 사용자 권한으로 설치하며 시작 메뉴·선택형 바탕화면 바로가기를 지원합니다.

## 검증 결과

- Windows CI: v1.78.0 공개용 빌드에서 포터블·설치형 패키지를 각각 빌드하고 실행 검증한 후 게시합니다. 빌드 결과와 체크섬은 GitHub 릴리즈 첨부물에서 확인할 수 있습니다.
- Python: **1,293개 통과, 1개 제외**.
- Flutter: **82개 통과, 1개 제외**. Dart 분석 이상 없음.
- 다이어그램 편집기: **22개 통과**, HWP 미리보기: **6개 통과**. 두 웹 자산 번들 빌드 통과.
- 실제 한/글 PC에서 `보고서 예시 파일(한번에 적용).txt` 사본을 처리: **100/100**, 입력 제목 보존, 결과 HWPX 생성 및 3쪽 확인.
- 테스트 전용 HWPX 예시 3건을 한/글에서 처리해 원본과 비교: 각 예시 **불일치 0건**. 이 비교기의 합격 기준은 지정 비교 항목 불일치 0건이며, 앱 처리 점수와는 별도 지표입니다.
- 포터블·설치형 산출물을 로컬에서 모두 생성. 포터블 EXE의 실행 창·내장 런타임·오프라인 OCR 검증 통과. 최종 공개 여부는 새 공개용 CI와 체크섬 검증 완료 후 확정합니다.

## 다운로드와 설치

- `HWP_AutoDocFit.exe`: 설치 없이 실행하는 포터블 버전.
- `HWP_AutoDocFit_v1.78.0_Setup.exe`: 현재 Windows 사용자 계정에 설치하는 버전.
- 한/글 2020이 필요합니다. 문서와 내장 변환은 기본 폐쇄망 모드로 동작합니다.
