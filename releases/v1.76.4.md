# HWP AutoDocFit v1.76.4 정식

□ 파일포맷 선택 화면 개선
ㅇ 원형 선택창 중앙에 변환 전 원본 파일명 표시.
ㅇ 긴 파일명은 앞부분과 확장자를 남겨 말줄임. 전체 이름은 마우스를 올려 확인.
ㅇ 여러 파일은 첫 파일명과 전체 개수 표시. 선택한 출력 형식은 원 아래 별도 안내.

□ HWP 변환 호환성 보완
ㅇ HWP→HWPX·PDF·PNG·JPG 지원 유지, 한/글 COM 설치 판정을 기본·32비트·64비트 레지스트리 보기에서 확인.
ㅇ 여러 쪽 PNG·JPG 출력 및 원본 파일 보존 회귀 시험 보강.
ㅇ 해당 변환은 설치된 한/글이 필요하며 실제 한/글 2020의 문서별 결과 확인 필요.

□ 기존 기능 포함
ㅇ 이미지 한국어 OCR→HWPX, TXT·MD 변환, HWPX→TXT·MD 및 마인드맵 자유 배치·계층 편집 유지.
ㅇ 오프라인 Node·kordoc·한국어 OCR 런타임을 EXE에 내장. 별도 런타임 ZIP 다운로드 불필요.
ㅇ 첫 실행 C:\HWP_AUTODOCFIT 설치, 권한이 없으면 사용자 폴더로 폴백.
ㅇ tldraw SDK·메뉴 제외. 기본 폐쇄망 모드 유지.

□ 이전 버전 대비 개선 효과
ㅇ 중앙의 출력 형식명만 보이던 화면을 원본 파일명·원본 확장자 표시로 변경해 변환 대상을 식별할 수 있도록 개선.
ㅇ 280px·340px 폭에서 긴 한글 파일명의 말줄임과 확장자 보존, Windows 경로 및 여러 파일 표시를 검증.
ㅇ HWP 네 가지 출력의 원본 바이트 보존과 여러 쪽 이미지 출력을 모의 COM 회귀 시험으로 확인.
ㅇ 처리 시간·조판 품질의 일반적인 개선율은 별도 측정하지 않았으므로 제시하지 않음.
