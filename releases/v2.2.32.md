# v2.2.32

## 바뀐 점
- 자료함(개발자 모드): 개체를 더블클릭하면 Windows 연결 프로그램으로 열림(전에는 '자료 위치' 창에 경로만 표시), Ctrl+클릭으로 여러 개를 골라 한 번에 이동·복사·삭제, 개체가 서로 겹치지 않게 빈 자리에 배치(사용자 요청)
- 파일변환: JPG·PNG 등 그림 파일을 넣을 수 있고, 그림 → PDF는 한/글·글자 인식 없이 바로 만듦(그림 → PNG·JPG는 기존처럼 글자 인식 필요)
- 표그림판: '한/글 문서에서 표 가져오기' — HWPX 문서의 표 목록에서 골라 겹쳐 보고 적용·되돌리기
- 몽땅클립보드 Ctrl+Shift+V 실행창이 접힘 설정 때문에 목록을 그리지 않던 문제 수정
- 업데이트 파일 서명 검증 기능(기본 꺼짐, 공개키·절차는 사용자 결정 후 켬)
