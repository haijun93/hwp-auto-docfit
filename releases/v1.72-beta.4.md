# 한글편집 후처리 v1.72 Beta 4

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서는 반드시 사본으로 먼저 시험하고 결과를 확인해 주세요.

- **붙임 번호 목록 내어쓰기 개선**
  - 문서 끝의 `붙임`부터 `끝.`까지 이어지는 번호 목록만 찾아 편집합니다.
  - 「2025 행정업무운영 편람」 예시대로 `붙임` 표시 뒤 2타, `끝.` 앞 2타를 적용합니다.
  - 첫 항목을 기준으로 다음 번호 항목을 계층별 2타씩 들여쓰고, 항목이 꺾인 줄은 본문 시작 위치에 맞춥니다.
- **작업 단계 안내 개선**: 문서 추가 후 작업 방식 선택, 방식 선택 후 정리 시작, 결과 확인 후 새 작업 시작 버튼을 눈에 띄게 표시합니다.
- **기록 파일 선택**: 개발자 모드에서 작업 로그·무결성 검사 보고서·최종 검수 보고서의 파일 생성을 각각 켜고 끌 수 있습니다.
- 설정 초기화 실행 파일은 이번 릴리스에 포함하지 않습니다.

- `HWP_AutoDocFit-v1.72-beta.4.zip` (메인 프로그램과 한 번에 적용 시험용 예시 텍스트)
