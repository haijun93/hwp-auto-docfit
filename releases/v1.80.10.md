# v1.80.10 — 릴리스 준비 (2026-10-24)

사용자 확인 전 빌드 검증 단계입니다. 태그·릴리스 초안·게시·main 푸시는 하지 않습니다.

## 바뀐 점

- 표 칸 전용 축소 하한: 줄 간격 100%, 자간 −25%. 칸 폭 구분을 폐기했습니다.
- 콜론 뒤 번호·※ 연속 줄의 서식과 본문 위치를 맞추고, ※를 앞 문장과 쪽 묶음으로 처리합니다.
- 제목·개요 표 호스트 병합, ㅇ 괄호 라벨 내어쓰기, ❶~❿ 하위 항목 서식, 본문과 같은 라벨 크기를 보완했습니다.
- 카드 옵션은 ‘줄 간격 적용 제외·페이지 맞춤 제외·기존 자간 초기화 제외’로 표시합니다. 신규 설치는 자간 정리의 페이지 맞춤을 실행하고 기존 자간 초기화는 제외합니다. 기존 사용자 설정은 동작을 유지하도록 이전합니다.
- 셀 안 단독 그림을 셀 배경으로 변경하는 선택 옵션을 추가했습니다. 글자가 함께 있는 셀은 제외합니다.
- 표그림판: 정밀 지우개, 선택·묶음·이동·끝점 편집·되돌리기, 셀 배경색, 선 색·실제 굵기, 한/글 표 붙여넣기와 HWPX 표 가져오기.
- T형 템플릿의 누락된 도형과 셀 배경 상속을 보완했습니다.

## 검증

검증 진행 중. 최종 시험 수·재연 결과·CI run은 C25 결과 확정 후 기록합니다.
산출물은 GitHub Actions artifact로만 보관하며 공개 다운로드 링크·SHA-256은 게시 승인 후 확정합니다.
