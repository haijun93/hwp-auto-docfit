# v2.0.7 — 2026-10-31

HWP AutoDocFit 2.0.7 릴리즈 안내입니다.
**파일변환 화면을 새로 만들었습니다.** 폴더나 드라이브 전체의 HWP를 찾아 **HWPX로 한 번에 바꿀 수 있고, 암호 문서도 바꿉니다.** 표그림판에서는 **선 색과 사각형 배경색**을 고를 수 있습니다.

---

## 바뀐 점

### 1. 파일변환 화면 새 디자인
- 한 화면을 세 칸으로 나눴습니다: 올린 파일 · 변환할 포맷 · 변환 결과.
- 포맷 칸을 누르면 바로 변환합니다. 팝업 창을 거치지 않습니다.
- 올린 파일마다 크기를 보여 줍니다.
- 결과는 파일별로 **열기**, **폴더에서 보기**를 누를 수 있습니다. 결과 폴더 열기, 결과 모두 열기도 있습니다.
- 마우스 오른쪽 단추 메뉴
  - 올린 파일: 열기, 폴더에서 보기, 목록에서 빼기
  - 결과: 열기, 폴더에서 보기, 경로 복사, 원본 열기
  - 빈 곳: 파일 추가, 폴더 추가, 목록 비우기
- 숫자 키로 포맷을 고르던 기능은 없앴습니다. NumLock이 꺼진 숫자패드 키도 같습니다. 포맷 칸의 배치와 모양은 그대로입니다.
- ZIP으로 내려받는 기능은 만들지 않았습니다. 결과는 원본 옆에 저장됩니다.

### 2. HWP 찾아 HWPX로 바꾸기
- 파일변환 화면 왼쪽 아래 **'HWP 찾아 HWPX로 바꾸기'**를 누릅니다.
- 범위는 둘 중에서 고릅니다.
  - 폴더: 하위 폴더까지 찾을지 고릅니다.
  - 드라이브 전체: 이 PC의 고정 디스크(C:, D: 등)
- 파일 하나만 바꿀 때는 지금처럼 파일을 올리고 HWPX를 누릅니다.
- 결과는 원본 옆에 같은 이름의 `.hwpx`로 저장합니다.
  - 같은 이름의 HWPX가 이미 있으면 건너뜁니다.
  - 원본은 고치지 않습니다.
- 다음 폴더는 들어가지 않습니다.
  - Windows, Program Files, ProgramData, AppData, 휴지통 같은 시스템 폴더
  - 바로가기 연결 폴더(정션)
- 진행 상황은 결과 칸에 보입니다. 찾은 수, 변환한 수, 지금 바꾸는 파일이 나오고, 중간에 멈출 수 있습니다.
- 끝나면 결과표(CSV)를 남깁니다. 결과표에는 파일마다 변환·실패·건너뜀과 그 이유가 적힙니다.
  - 저장 위치: `문서\HWP_AutoDocFit\HWPX변환_결과표`
  - '결과표 열기', '결과표 폴더' 단추로 엽니다.

#### 보안 문서
- **열 때 암호를 묻는 문서**
  - 창에 암호를 넣습니다. 여러 개를 넣을 수 있습니다.
  - 앱이 넣은 암호를 차례로 시도합니다. 암호 창이 떠서 작업이 멈추지 않습니다.
  - 결과 HWPX도 **같은 암호로 잠깁니다**(한/글 기본 동작, 보안 유지).
  - 암호는 저장하지 않고, 작업이 끝나면 버립니다.
  - 암호가 틀렸거나 넣지 않았으면 결과표에 이유를 적고 다음 파일로 넘어갑니다.
- **배포용 문서**(편집·인쇄 제한)
  - 한/글이 저장을 허용하면 바꿉니다.
  - 막히면 결과표에 '저장이 막힌 문서'로 적습니다.
- **기관 보안(DRM) 문서**
  - 이 PC의 문서보안 프로그램이 열어 주면 그대로 바꿉니다.
  - 열지 못하면 결과표에 이유를 적습니다. 보안 프로그램에서 해제하거나, 보안 프로그램이 있는 PC에서 바꾸면 됩니다.

#### 기존 변환 보완
- 파일 목록으로 바꿀 때(HWP→HWPX·PDF 등) 암호 문서가 섞여 있으면, 지금까지는 보이지 않는 암호 창에서 변환이 멈출 수 있었습니다.
- 이제 그 파일만 실패로 표시하고 다음 파일로 넘어갑니다.

### 3. 표그림판 선 색 · 사각형 배경색
- 도구 막대에 **선 색**과 **배경** 단추를 더했습니다.
- 색은 그림판·다이어그램과 같은 26색에서 고릅니다. `#RRGGBB`로 직접 넣을 수도 있습니다.
- 선 색
  - 앞으로 그을 선에 적용합니다.
  - 고른 선이나 사각형 테두리가 있으면 그 색도 바꿉니다.
- 배경
  - 고른 사각형(또는 선들이 두른 범위)을 칠합니다.
  - '없음'을 누르면 지웁니다.
  - 사각형을 옮기거나 크기를 바꾸면 배경도 따라갑니다.
- 한/글 표로 바꾸면 테두리 색과 칸 배경색이 그대로 들어갑니다.
- 한/글에서 복사한 표를 표그림판에 붙여 넣으면 테두리 색과 칸 바탕색도 가져옵니다. 2.0.6에서 '다음 버전'으로 남겼던 기능입니다.

### 4. 안내 문서(README)
- 첫 화면에 '주요 기능 한눈에'를 더했습니다. 문서편집·표 템플릿·표그림판·파일변환·다이어그램·마인드맵을 실제 앱 화면과 함께 소개합니다.

## 알려진 점

- 배포용 문서와 기관 보안(DRM) 문서는 실제 표본이 없어 '열기 → 저장, 막히면 이유 기록' 흐름만 시험했습니다. 실제 문서에서 막히면 결과표의 이유를 알려 주세요.
- 그림판을 한/글에 붙여 넣으면 지금은 그림 한 장으로 들어갑니다. 한/글에서 고칠 수 있는 묶음 개체로 붙이는 기능은 다음 버전에서 넣습니다.

## 시험

- Python 단위 시험, Flutter 위젯 시험 모두 통과.
- 한/글 실제 시험(COM, 사본 폴더)
  - 일반 HWP → HWPX
  - 암호 HWP: 틀린 암호 다음에 맞는 암호를 넣으면 열려 HWPX로 저장. 결과도 같은 암호로 잠긴 것을 확인
  - 암호를 넣지 않았거나 틀린 경우: 멈추지 않고 이유 기록
  - 보안 프로그램으로 감싼 파일(흉내): 이유 기록
  - AppData 폴더 안 파일과 이미 HWPX가 있는 파일은 건너뜀
- 실제 앱 화면 시험
  - 파일변환 탭 세 칸 화면과 'HWP 찾아 HWPX로 바꾸기' 창
  - 앱에서 일괄 변환을 끝까지 실행: 변환 2 · 실패 1(보안 파일)과 결과표 단추 확인
