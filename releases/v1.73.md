# 한글편집 후처리 v1.73

Windows 64비트용 정식 릴리스입니다. v1.72 베타(Beta 1~16)에서 다듬은 기능과 알파에서 검증한 새 기능을 모았습니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

## 새 기능
- **썸네일로 서식 선택**: 서식마다 예시 보고서 첫 쪽 그림(썸네일)과 이름을 카드로 보여 주고, 눌러서 고릅니다. 실행창 '적용할 서식' 옆 **「썸네일로 선택」**. 한/글을 열지 않고 예시 HWPX 안의 미리보기 그림을 씁니다.
- **서식예시 폴더와 자동 반영**: `C:\HWP_AUTODOCFIT\서식예시`에 서식마다 예시 HWPX(기본 서식은 `기본 서식.hwpx`, 추가한 서식은 `<서식 이름>.hwpx`)를 둡니다. 예시 파일을 한/글에서 고쳐 저장하면, 다음 '한 번에 적용'을 시작할 때 처음 넣은 사본과 비교해 **바뀐 서식 값만** 서식 설정에 옮깁니다. 기본 서식 예시를 지우면 기본 서식이 처음 값으로 돌아갑니다.
- **보고서 머리 서식 복사**: 예시 보고서의 제목·보고 주체(날짜·부서·담당자 표기)·개요 구성을 복사합니다. 1×1·장식 제목 표도 제목 표로 인정합니다.
- **PDF 예시 서식 복사**: PDF 예시에서 글자색·칸 배경 등 서식을 읽어 서식 분석에 씁니다.
- **연결 부호 정렬**: 점·선·여러 칸 빈칸으로 이은 줄이 여러 줄 이어지면 한/글 목차 점선처럼 오른쪽 글 시작을 세로로 맞춥니다. 한 줄이면 연결 부호를 줄여 줄 경계에 맞춥니다.
- **콜론 라벨 정렬**: 항목기호 뒤 7자 미만 라벨 + 콜론이 2줄 이상 이어지면 콜론 위치를 세로로 맞춥니다(자간과 글자 사이 빈칸 사용).
- **완료창**: 개발자 모드가 꺼져 있으면 고양이 그림과 함께 "당신의 소중한 시간 00분 00초가 절약되었습니다!"만 보입니다. 자세한 완료 안내는 개발자 모드에서 봅니다.

## 바뀐 점
- **장평 줄이기 기본 끔**: 자간 줄이기·늘리기만으로 조정합니다. 설정 > 자간 정리 세부 설정의 '장평 줄이기 사용'으로 켤 수 있습니다.
- **앱 폴더 정리**: 보안 모듈 DLL을 `C:\HWP_AUTODOCFIT\dll\HwpAutoDocFitSecurity.dll`에 두고 레지스트리 값 이름을 `HwpAutoDocFitSecurity`로 바꿨습니다. 예전 `C:\HwpAutomation`의 이 앱 DLL과 예전 값은 실행할 때 정리합니다(다른 파일이 있는 폴더는 남김). 한/글 글자 상용구(`글자상용구\HWP.IDO`)와 본문 상용구(`본문상용구`) 폴더도 이곳에 둡니다.
- 처리 속도: 문단 글 캐시를 넓혀 한/글에 묻는 횟수를 줄였습니다.
- 기본 글꼴은 휴먼명조를 유지합니다.
