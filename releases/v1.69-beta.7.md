# 한글편집 후처리 도구 v1.69 Beta 7

Windows 64비트용 테스트 베타 릴리스입니다. 중요한 문서에 적용하기 전에 결과를 확인해 주세요.

- **예시 서식 문서를 더 자세히 분석**: 서식 복사하기(또는 예시 문서 끌어 놓기)로 서식을 등록하면
  - 문두기호 문장(□·ㅇ·-·※ 등)은 계층별로 글꼴·크기·굵게·기울임·밑줄·글자색·장평·자간·정렬·여백·문단 간격·줄 간격까지 분석합니다.
  - 제목·개요·중제목·붙임 표는 칸별(A1·A2·B2 …)로 글자·문단 서식과 테두리·배경·안 여백까지 분석합니다.
  - 가장 많이 쓴 값을 대표값으로 정하고, 새 **서식 세부사항** 창에서 서식 이름과 대표값을 고쳐 저장합니다. 저장한 뒤에는 '상세 수정…'으로 다시 고칠 수 있습니다.
  - 이 서식으로 정리하면 제목·개요·중제목·붙임 표에 예시 문서의 표 서식(고친 값 포함)을 씁니다.
  - 이미 등록한 서식에는 새 분석 결과가 없습니다. 세부사항 창을 쓰려면 예시 문서를 다시 등록해 주세요.
- **서식 통일이 맞추는 항목 추가**: 기울임·밑줄·취소선, 정렬, 왼쪽·오른쪽 여백이 다른 문장도 문서의 대표값으로 맞춥니다. 이미 맞는 문장은 그대로 둡니다.
- **예시 서식의 여백이 절반으로 들어가던 문제 수정**: 복사한 서식의 문단 여백·간격이 예시 문서의 절반으로 들어갔습니다. 이미 등록한 서식도 이제 예시 문서와 같은 여백으로 적용됩니다.
- **자간 정리에 '기존 자간 초기화' 선택 추가**: 끄면 문서에 이미 있는 자간을 0%로 되돌리지 않고 그 위에서 정리합니다. 기본은 켜짐이며 고른 값을 기억합니다.
- **회의 자료 정리 오류 수정**
  - 쪽 나눔으로 다음 쪽에서 시작하는 표(다음 보고서의 제목 표 등)를 앞 문장과 한 쪽에 모으려던 문제
  - '일    시:'처럼 글자 사이를 띄워 폭을 맞춘 라벨의 빈칸이 줄어 콜론 위치가 어긋나던 문제
  - 기본 표 서식이 칸 배경 그림(사진)을 지우던 문제
