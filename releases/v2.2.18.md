# v2.2.18 릴리스

HWP AutoDocFit 2.2.18 릴리스 안내입니다.

## 바뀐 점

### 자료함(개발자 모드) — 4.0 가상 관계형 자료함 완성

자료함은 실제 폴더가 아니라 자료의 위치와 관계만 기억하는 가상 보관함입니다. 원본 파일은 옮기거나 바꾸지 않습니다.

- 화면을 4분면(핵심자료·기초자료·참고자료·임시저장소)으로 나누고, 공간 안에서 자유롭게 배치하거나 다른 공간으로 끌어 옮길 수 있습니다.
- 핵심자료 공간에서는 카드 두 개를 차례로 눌러 관계선을 잇고, 이름표를 붙이거나 지울 수 있습니다.
- 파일·폴더 끌어 놓기, Ctrl+V(글·서식 글·그림) 붙여넣기로 자료를 담습니다.
- 자료함 만들기·이름 바꾸기·삭제, 자료 이름 바꾸기·삭제·공간 이동, 더블클릭으로 열기(링크는 http/https만 기본 브라우저로)를 지원합니다.
- 자료함에 담긴 문서의 본문만 골라 검색합니다(2글자 조각·초성·오타 검색, 이 PC 안에서만 처리).
- '물리 폴더로 전환': 고른 폴더에 1_핵심자료~4_임시저장소를 만들고 자료를 복사해 저장합니다(원본은 그대로, 링크는 .url, 글은 .txt, 그림은 .png).

Python 3.14 기반으로 빌드합니다.

### 오류 수정

- v2.2.17에서 자료함 버튼을 누르면 'DesktopWebBridge' 속성 없음 오류가 나던 문제를 고쳤습니다.
- 자료함 연결 때 '현재 사용자 SID를 확인하지 못했습니다' 오류가 나던 문제(64비트 Windows)를 고쳤습니다.
