# v3.0.0-rc.1 시험판

HWP AutoDocFit 3.0 사용자 시험용 출시 후보입니다. 자동 업데이트로 배포하지 않습니다.

## 3.0에 들어가는 것

- 한/글 창 옆에 붙는 도우미 패널
- 단축키와 알림 영역(트레이) 상주
- 열려 있는 문서의 커서 위치에 표 템플릿·표그림판 표·그림 바로 넣기(넣은 뒤 Ctrl+Z 한 번으로 되돌림)
- 대화상자가 떠 있거나 문서가 바뀌면 넣지 않고 멈춤, 넣기 전 클립보드 보관·복원

## 3.0에서 뺀 것

- 표 정보단위 −/+, 선택한 글 자간 정리: 실제 한/글 시험에서 되돌리기(Ctrl+Z)로 원문이 돌아오지 않아 기본으로 꺼 두었습니다.

시험 순서는 docs/V3_USER_TEST.md에 있습니다. 반드시 문서 사본으로 시험하세요.
