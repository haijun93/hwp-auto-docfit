# v1.80.13 — 2026-10-26

표 템플릿 UI의 중복되고 과도했던 버튼들을 제거하고, PowerPoint(PPT)의 '표 디자인 리본' 및 '표 스타일 갤러리' UI를 벤치마킹하여 직관적이고 미려한 오피스 표준 UX로 전면 개편한 릴리즈 버전입니다.

## 새로 된 점

- **PPT 표 스타일 리본 갤러리 탑재 (상단 가로 1줄 단정화)**:
  - 기존 34개 템플릿 이름이 화면 상단을 여러 줄로 가득 채우며 낭비하던 비효율적 배치를 전면 철거했습니다.
  - PowerPoint의 '표 스타일 갤러리'와 동일하게 **가로 1줄로 단정하게 스크롤되는 리본 바**(`Icons.chevron_left`/`chevron_right` 내비게이션 화살표 탑재, 높이 36px)로 전환하여 수직 공간 낭비를 0으로 줄였습니다.
- **PPT 스타일 분류 드롭다운 & 서식 통계 바**:
  - 좌측 상단에 PowerPoint 메뉴 스타일의 **분류 드롭다운(Dropdown Menu)**을 탑재하여 17개 이상의 상세 서식 분류를 1클릭으로 즉시 선택·이동할 수 있도록 했습니다.
  - 현재 분류와 템플릿 개수가 직관적인 뱃지(`총 N개 서식`)로 실시간 표시됩니다.
- **정돈된 PPT 스타일 분류 팔레트 (중복·크기 최적화)**:
  - 흩어져 있던 20개 분류 버튼을 구조화된 카드 컨테이너 안에 깔끔하게 정돈(높이 28px, 텍스트 글자수 비례, 4px 간격)하여 카드가 가려지지 않도록 화면 공간 효율을 극대화했습니다.
- **우측 표 도구 및 실시간 미리보기 캔버스 고도화**:
  - 선택된 템플릿 이름·카테고리 뱃지 옆에 대형 `[ 한/글로 복사 (Ctrl+V) ]` 액션 버튼을 즉시 배치하여 접근성을 높였습니다.
  - 표 단위 조절(행/열 스텝퍼), 글 처리 방식(번호 자동 증가/비우기)을 PPT '표 도구' 패널 형식으로 체계화했습니다.
  - 실시간 미리보기 캔버스는 PPT 슬라이드/문서 시트 형태(화이트 배경 및 부드러운 그림자)로 시각적 완성도를 높였습니다.
