# v1.80.14 — 2026-10-26

사용자 사용성 및 화면 효율성을 위해 표 템플릿 UI의 중복·비효율 요소를 전면 정돈하고, PowerPoint(PPT) 표준 메뉴 리본 형태로 단정화한 릴리즈 버전입니다.

## 새로 된 점

- **중복 상단 메뉴 전면 삭제 (화면 수직 공간 극대화)**:
  - 좌측 갤러리의 템플릿 카드 목록과 완전히 중복되던 화면 최상단의 가로 템플릿 이름 바(`templateNameBar`)를 전면 삭제했습니다.
  - 불필요한 상단 리본을 걷어냄으로써 표 미리보기 및 템플릿 탐색을 위한 세로 작업 캔버스를 최대로 확보했습니다.
- **좌측 메뉴 중복 요소 정돈 및 전폭 검색 바**:
  - 분류 선택이 리본과 드롭다운 양쪽에 중복되어 있던 구조를 단일화했습니다.
  - 검색창을 전폭(Full-width, 높이 36px)으로 확장하여 검색어 입력 편의성을 극대화하고, 원클릭 내용 삭제(`clear`) 버튼을 적용했습니다.
- **PPT 스타일 가로 1줄 분류 리본 (Single-Row Category Ribbon)**:
  - 이전 버전에서 최대 6줄을 차지하던 20개의 거대한 분류 버튼들을 **가로 1줄 단정형 리본**(높이 36px, 좌우 `<` `>` 내비게이션 스크롤 버튼 탑재)으로 전면 교체했습니다.
  - 칩 높이를 28px의 컴팩트한 규격으로 통일하고 `[✓ 전체]`, `[★ 즐겨찾기]`, `[🕒 최근 사용]` 등 주요 필터에 시각적 아이콘을 적용하여 직관성을 높였습니다.
  - 현재 분류 서식 개수 뱃지(`총 N개`)를 연동하여 필터 결과를 한눈에 파악할 수 있습니다.
- **우측 상세창 상단 즉시 복사 버튼 탑재**:
  - 템플릿 선택 즉시 복사할 수 있도록 상세창 상단 타이틀 우측에 `[ 📋 한/글로 복사 (Ctrl+V) ]` 주 액션 버튼을 전면 배치했습니다.
  - 하단 도구 패널까지 스크롤할 필요 없이 1클릭으로 한/글에 즉시 붙여넣을 수 있습니다.
- **유연한 좌우 분할창 리사이징 및 독립 스크롤**:
  - 좌측 갤러리와 우측 상세 미리보기 사이의 경계선을 드래그하여 자유롭게 폭을 조정할 수 있으며, 더블 클릭 시 기본 최적 비율(42%)로 자동 복원됩니다.
  - 양쪽 영역 모두 독립된 부드러운 스크롤바가 적용되어 긴 표나 다수의 서식을 쾌적하게 열람할 수 있습니다.
