자주 묻는 질문

시작하기 전에
확인해 보세요.

원본 문서가 변경되나요?

아니요. 결과는 원본과 같은 폴더에 새 파일로 저장되어 원본을 안전하게 보존합니다.

어떤 파일을 지원하나요?

한글의 HWP 및 HWPX 문서를 지원하며 여러 파일과 폴더 단위 일괄 처리가 가능합니다.

업데이트는 어떻게 하나요?

기본적으로 앱 시작 시 최신 릴리스를 확인합니다. 설정 화면에서 자동 확인을 끄거나 직접 확인할 수도 있습니다.

macOS에서도 사용할 수 있나요?

현재는 한글 COM 자동화를 사용하는 Windows 전용 프로그램입니다.
