자주 묻는 질문

시작하기 전에
확인해 보세요.

원본 문서가 변경되나요?

아니요. 원본은 그대로 유지하며 결과는 같은 폴더에 새 HWPX 파일로 저장합니다.

어떤 파일을 지원하나요?

HWP 및 HWPX 입력을 지원합니다. HWP는 작업용 HWPX로 변환되고 최종 결과는 모두 HWPX로 저장됩니다.

업데이트는 어떻게 하나요?

기본적으로 앱 시작 시 최신 릴리스를 확인합니다. 설정 화면에서 자동 확인을 끄거나 직접 확인할 수도 있습니다.

macOS에서도 사용할 수 있나요?

현재는 한글 COM 자동화를 사용하는 Windows 전용 프로그램입니다.
