# README 기능 비교 이미지

안내 기준: **1.72 Beta 13**. 이 폴더의 PNG 30개는 기능을 설명하기 위한
가상 문서 도해이며, 한/글 처리 화면·실측 결과·성공률을 나타내지 않습니다.
제품의 동작은 `hwp-auto-docfit.py`, `docfit_core/stage_selection.py`,
`docfit_core/writing_aids.py`와 Beta 13 릴리스 노트를 기준으로 확인했습니다.
사용자 문서나 개인정보는 사용하지 않았습니다.

- 왼쪽은 전, 오른쪽은 후입니다.
- 빨간 글자는 바뀌는 내용·서식·위치입니다. 검토·내보내기·저장 기능에서는
  새로 표시되거나 생성되는 정보를 뜻합니다.
- 검은 글자는 유지되는 부분입니다. 설명용 빨간색을 결과 문서에 넣는 기능이 아닙니다.
- 공백 정리 그림의 빨간 `·`는 삭제되는 빈칸을 눈에 보이게 하는 표기입니다.
- 쪽 수 맞춤은 성공하는 경우의 도해입니다. 원본 쪽 구성 유지와 목표가 다릅니다.
- 짧은 마지막 줄 그림은 기준을 4글자 이하로 설정한 예시입니다.
- 문서 구조·가독성 검토는 원문 수정이 없는 읽기 전용 기능으로 표현했습니다.
- 기존 `../samchein/` 영상·실제 결과는 **1.69 Beta 18**의 별도 자료입니다.

## 재생성

저장소 루트에서 Windows의 맑은 고딕 글꼴과 Pillow를 사용합니다.

```powershell
.venv\Scripts\python.exe scripts\build_readme_comparisons.py
```

사용자 문서를 열지 않고 고정된 예시 문구만 렌더링합니다.
이미지는 1440×760 PNG이며 README에서 누르면 원본 크기로 열립니다.
예시 문구와 빨간 표시 범위는 생성 스크립트의 `CARDS`에서 수정합니다.
텍스트와 표 칸의 경계 초과를 검사하고, 생성 후 그림과 README의 링크를 확인합니다.
