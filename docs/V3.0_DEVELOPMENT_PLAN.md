# v3.0 개발 착수안

상태: 개발 중 (사용자 범위 선택: 2.2.10 미완료 오류·표 기능 묶음)  
기준 브랜치: `release/2.2.10`  
작업 브랜치: `release/3.0.0`

## 개발 경계

- v3.0은 기존 문서 후처리 앱의 주요 기능 개선 트랙으로 둔다.
- 폐쇄망 자료함·본문 검색 등 별도 작업 중인 v4.0 기능은 이 브랜치에 섞지 않는다.
- v2.2.10의 오류 수정과 실기기 검증은 해당 패치 브랜치에서 계속 관리한다.
- 사용자 범위가 확정되기 전에는 앱 버전 문자열을 3.0.0으로 올리거나 호환성을 깨는 변경을 하지 않는다.

## 확정 범위 및 진행

- [x] **표 템플릿 교체**: 제공된 `추진절차(가로세로)모양1`을 5×3 표와 화살표가 포함된 첨부 HWPX로 교체 노출했다. 원래 카탈로그의 같은 이름 항목은 숨기고 새 템플릿 미리보기·확장 크기 계산을 시험했다.
- [ ] **몽땅클립보드 표 붙여넣기 개선**: Excel 표를 한/글에 붙여넣을 때 표 구조·글자·테두리는 보존하면서 셀 배경 음영만 제거하는 전용 경로를 검토한다. 불가능한 형식은 원래 붙여넣기로 폴백한다.
- [ ] **설치·실행 안정성**: v2.2.8에서 보고된 `[Errno 13] Permission denied`의 실제 Windows 재현과 원인 규명을 진행한다.

## 검증 게이트

- 사용자 원본 카탈로그와 문서는 바꾸지 않는다. 새 템플릿은 앱에 별도 자원으로 동봉한다.
- 각 기능은 원본 문서 무변경, 폐쇄망 동작, 취소·실패 시 복구를 기본 검증한다.
- Windows/한글 실기기 확인 전에는 완료나 배포 가능으로 표시하지 않는다.
