# 3.0 설계 — 한/글 플러그인처럼 동작하는 '한글편집 도우미'

2026-10-30 · 브랜치 `dev/3.0` · 근거: [LIVELINK_POC.md](../../livelink/docs/LIVELINK_POC.md)(C28, 10-29 실측)

## 1. 목표

지금(2.x)은 문서를 앱에 **넣고 → 처리하고 → 새 파일로 받는** 방식이다. 3.0은 사용자가 **한/글에서 문서를 쓰는 그 자리에서**
앱 기능을 바로 쓰게 한다. 한/글의 플러그인처럼 보이고 동작하는 것이 목표다.

- 한/글 창 옆에 붙는 **도우미 패널**(폭 약 360px). 한/글을 옮기거나 줄이면 따라간다.
- **단축키**(예: Ctrl+Alt+J 패널 열기·닫기, Ctrl+Alt+T 표 템플릿)와 **알림 영역(트레이) 상주**.
- 열려 있는 문서의 **커서 위치에 바로 넣기**: 표 템플릿, 표그림판 표, 다이어그램·마인드맵·그림판 그림.
- 커서가 있는 표를 알아보고 **정보단위 −/+**, 선택한 글의 **자간 정리**.
- 저장·다시 열기 없음. 사용자 문서를 앱이 **자동 저장하지 않는다**.
- 지금의 문서 단위 처리(정리·페이지 맞춤·파일변환)는 그대로 둔다(문서 사본으로 처리).

## 2. 구조

```
┌ 한/글(사용자 창) ─────────────┐   ┌ 도우미 패널(pywebview, 테두리 없는 창) ┐
│  문서 편집 중                 │◀──│  지금 문서·커서 문맥 / 표 템플릿 / 표그림판 │
│  (COM: ROT로 연결)            │   │  / 그림 넣기 / 자간 정리 / 상태           │
└───────────────────────────────┘   └───────────────┬──────────────────────┘
                                                    │ 명령(JSON)
                               ┌────────────────────▼────────────────────┐
                               │ LiveLink 서비스(전용 STA 스레드 1개)     │
                               │ - 연결: ROT에서 실행 중 한/글 찾기        │
                               │ - 문맥 읽기: 커서·선택·표 안 여부·문서     │
                               │ - 쓰기 명령 큐(FIFO, 한 번에 하나)        │
                               │ - 쓰기 직전 문맥 재확인(다르면 중단)      │
                               └──────────────────────────────────────────┘
```

- **연결**: `GetRunningObjectTable → EnumRunning → GetObject`(PoC 0.055초). `GetActiveObject`·`Dispatch`로 대체하지 않는다
  (새 한/글이 생김). 여러 한/글이 떠 있으면 **앞에 있는 창의 문서 이름**과 각 연결의 열린 문서 경로를 맞춰 고른다.
- **문맥**: `GetPos`·`GetSelectedPosBySet`·`ParentCtrl`·`KeyIndicator`(PoC 0.01~0.16초).
- **COM 소유**: 한/글 객체는 서비스 스레드만 만진다. 패널은 명령만 보낸다.

## 3. 되돌리기(Ctrl+Z) 원칙 — PoC의 미충족 항목을 피하는 설계

PoC: **한 번의 블록 삽입은 Ctrl+Z 한 번으로 되돌아가지만, 여러 편집을 한 번에 묶는 API는 없다.**
그래서 3.0의 쓰기 명령은 모두 **'한 번의 삽입'으로 끝나게** 만든다.

| 명령 | 방법 | Ctrl+Z |
|---|---|---|
| 표 템플릿·표그림판 표 넣기 | 앱이 숨은 한/글로 표를 만들어 클립보드에 담고(지금의 '한/글 복사'와 같음), 사용자 한/글에서 커서 위치에 `Paste` 한 번 | 1번 |
| 그림(다이어그램·마인드맵·그림판) 넣기 | PNG를 클립보드에 담고 `Paste` 한 번 | 1번 |
| 커서 표 정보단위 −/+ | 표를 블록으로 꺼냄 → 앱이 사본에서 바꿈 → 표 선택 후 바뀐 표로 **한 번에 교체**(붙여넣기) | 실측 후 결정(게이트) |
| 선택 자간 정리 | 선택 블록을 꺼냄 → 숨은 한/글 사본에서 기존 자간 엔진 실행 → 선택 범위를 **한 번에 교체** | 실측 후 결정(게이트) |

- 교체가 Ctrl+Z 한 번으로 되돌아가지 않는 빌드에서는 해당 명령을 **사용하지 않게** 하고 이유를 보인다.
- 앱이 Undo를 여러 번 대신 눌러 되돌리는 방식은 쓰지 않는다(사용자가 이어서 쓴 글까지 되돌릴 위험).
- 클립보드: 넣기 전에 사용자 클립보드를 보관하고 넣은 뒤 되돌려 놓는다(글·그림 형식만, 복원 실패는 알림).

## 4. 안전 원칙

- 사용자 한/글을 **강제 종료하지 않는다**. 문서를 **저장하지 않는다**.
- 쓰기 직전에 대상 문서(경로·DocumentID)와 커서 문맥을 다시 확인한다. 다르면 `STALE_CONTEXT`로 멈춘다.
- 대화상자(글자 모양 창 등)가 열려 있으면 `DOCUMENT_BUSY`로 기다리게 한다.
- 시험은 앱이 직접 띄운 시험용 한/글과 **사본**에서만 한다(`C:\HWP_AUTODOCFIT\.com-test.lock`).

## 5. 단계

| 단계 | 내용 | 출시 |
|---|---|---|
| 3.0-α1 | LiveLink 서비스(연결·문맥·넣기 명령), 앱 안 '한/글에 바로 넣기' 단추(표 템플릿·표그림판·그림) | alpha |
| 3.0-α2 | 도우미 패널(한/글 옆 따라붙기), 단축키, 트레이 상주 | alpha |
| 3.0-α3 | 커서 표 정보단위 −/+, 선택 자간 정리(Ctrl+Z 게이트 통과 시) | alpha |
| 3.0 | 실제 한/글 2020·NEO 재연 시험, 사용자 시험 뒤 배포 | main |

## 6. 2.x와의 관계

- 3.0도 지금 앱(탭 화면)을 그대로 포함한다. 도우미 패널은 같은 Flutter 화면의 '좁은 패널 모드'로 만든다.
- 3.0 개발은 `dev/3.0`에서 하고, 2.0.x 수정은 alpha·main에서 계속한다. 2.0.x 변경은 `dev/3.0`에 주기적으로 합친다.
