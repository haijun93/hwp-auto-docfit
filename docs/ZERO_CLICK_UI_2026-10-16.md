# 최소 개입 UI 1~3단계 구현 기록

□ 적용 범위
ㅇ 알파 소스의 Python 지문 진단기·WebView 브리지·Flutter 및 반응형 웹에 반영.
ㅇ 공개 v1.76.4 EXE는 변경하지 않음. 다음 Windows EXE 배포에 포함할 변경임.

□ 1단계 — 선택지 축약
ㅇ 작업 카드의 세부 옵션을 기본 설정 요약 칩으로 접고 탭할 때만 바텀시트로 노출.
ㅇ 표 없는 것이 확인된 문서는 표 제외 옵션 숨김. 불명 문서는 옵션 유지.
ㅇ 짧은 문서는 쪽 범위 입력을 접고 쪽 범위 지정 칩으로 수동 확장 가능.
ㅇ 기존 자간/페이지 맞춤 독립 스위치·설정 키·세부 작업 연동은 유지.

□ 2단계 — 문서 지문 추천
ㅇ `docfit_core/doc_inspector.py`에서 COM 없이 TXT·MD·HWPX를 진단.
ㅇ TXT·MD 및 평문 HWPX 초안은 한 번에 적용, 동일 문두 역할의 글꼴/크기 혼재는 서식 통일, 정돈된 문서는 자간 정리 추천.
ㅇ 표 셀의 별도 글꼴은 본문 서식 혼재 판정에서 제외. 글꼴 ID가 달라도 같은 한글 글꼴명은 같은 서식으로 비교.
ㅇ 다중 문서는 텍스트 초안 우선, 그 외에는 대표 모드 다수결 적용.
ㅇ 수동 카드 선택은 파일 추가로 덮어쓰지 않으며 전체 목록을 비우면 추천 재활성화.
ㅇ HWP·손상 문서·검사 한도 초과는 표/쪽 옵션을 유지하는 보수적인 기본값 사용.
ㅇ 진단 시간 예산 80ms, 입력 100개, HWPX 파일 64MiB·중앙 디렉터리 1MiB/2,048항목·XML 개별 4MiB/합계 8MiB 제한. XML은 defusedxml 사용.
ㅇ 기본 서식 HWPX의 최종 개발 환경 3회 실측은 30.49·21.66·29.11ms. 회귀 검사를 병렬 실행한 부하 상태에서는 107~172ms도 관찰됨. 파일 시스템·문서 복잡도·부하에 따라 달라지므로 모든 파일의 0.1초 처리를 보장하지 않음.

□ 3단계 — Drop-to-Run 및 서식 원드롭
ㅇ 빈 목록에 문서 파일 한 개를 드롭했을 때만 2.5초 유예 바 표시. 파일 선택 대화상자·폴더·다중/추가 드롭은 자동 실행하지 않음.
ㅇ 일시정지·옵션 변경·카드 선택·설정 변경·새 드롭은 예약 토큰 취소. 옵션 창·문서 도구가 열린 동안의 일반 드롭도 수동 대기로 처리.
ㅇ 실행 시 서버에서 토큰·마감 시각·문서 목록·모드·작업/분석 상태·자동 실행 설정을 재검증하고 실행 전 토큰을 소모함.
ㅇ 늦은 응답·중복 호출로 다시 실행하지 않으며, 유예 종료 후 5초가 지난 미사용 토큰은 만료함.
ㅇ 드롭 완료 이벤트로 즉시 상태 갱신. 진행 중 조회의 세대 번호를 무효화해 오래된 폴링 응답을 차단.
ㅇ `instant_run_on_drop=True`·`auto_open_result=True`를 설정에 저장. 성공한 단일 HWPX 결과만 한 번 자동 열기.
ㅇ 상단 서식 배지의 화면 좌표와 네이티브 전체 경로를 연결. 파일명에서 공백/밑줄을 정리한 이름으로 비동기 서식 분석·등록·활성화하고 토스트 표시.
ㅇ 서식 분석 완료가 그 사이 사용자가 선택한 작업 모드를 덮어쓰지 않도록 방어.

□ 검증
ㅇ Python 전체 1,247개(통과 1,242·기존 조건부 제외 5), Flutter 전체 80개 및 정적 분석 통과.
ㅇ 초안·표 없는 문서·서식 혼재·정돈된 문서·장문·손상/엔터티 XML·ZIP 메타데이터 한도 사례 회귀 시험 추가.
ㅇ 수동 선택 유지·목록 초기화·자동 실행 기한/중복/취소/만료·다중 드롭·분석 중 차단·결과 자동 열기 1회 시험 추가.
ㅇ 실제 Tk GUI의 비동기 서식 등록 완료·활성화·수동 모드 유지 시험 통과(한/글 분석 함수는 모의).
ㅇ 파일명 기관 접두어(구·시·군·청·공사·공단·연구원)를 기관 정보로 보조 추출하고 서식명에는 전체 이름을 유지함.
ㅇ Flutter의 옵션 접기·표 옵션 숨김·카운트다운 취소/1회 실행·수동 카드 선택 시험 추가.
ㅇ `scripts/verify_zero_click_web.py`의 Chromium 420/1280px 시험에서 가로 넘침 없음, 문맥 옵션·배지 하이라이트·취소/1회 실행 확인(모의 브리지).
ㅇ Flutter Release 웹 번들·오프라인 자산 검증 통과. 컴파일된 Flutter 웹의 Chromium 420/1280px 실행에서 네이티브 드롭 갱신 이벤트 수신·배지 좌표 등록·자동 실행 1회 확인(모의 브리지).
ㅇ 실제 한/글 2020 COM 처리·Windows 네이티브 드롭·실문서 조판은 해당 환경에서 추가 검증 필요.
