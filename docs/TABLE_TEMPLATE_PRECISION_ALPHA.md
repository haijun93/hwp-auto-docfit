# 알파 표 서식 템플릿 정밀도·UX 개선

## 적용 사항
- 표 서식 학습·적용과 너비 계산이 공통 `header_row_count`를 사용한다.
  첫 행의 rowSpan을 기준으로 다단 머리글을 제외한다. 전체 높이 구분 칸을
  머리글로 오인하지 않는 기존 보호 규칙은 유지한다.
- 가로 병합 칸의 글자 수는 걸친 열 수로 나누는 기존 계산을 유지·검증했다.
  본문이 빈 간트형 일정표는 하위 머리글을 보조 기준으로 쓰는 기존 동작을 유지한다.
- 서로 다른 charPrIDRef가 섞인 문단은 각 Run을 따로 복제해 글꼴·크기만 맞춘다.
  색상·굵기·밑줄·첨자 및 언어별 장평·자간 차이를 보존한다.
- borderFill 원본 서브트리를 복제하고 대상 ID를 재할당한다.
  그러데이션 0/90도와 명시적 흰색/none의 구별을 학습→적용 시험으로 확인했다.
- 정밀 표 매칭에서 동일 구조 후보의 점수가 동률이거나 순번 보너스 범위인
  10점 이내이면 자동 선택하지 않는다. 데이터 표는 기본 표 서식으로 폴백하고
  제목·설명 상자 등 특수 표는 원형을 유지한다. 결과의 fallbacks와 작업 로그에 기록한다.
- 정밀 복제의 입력·출력 경로가 같으면 원본 덮어쓰기를 거부한다.

## Flutter·브리지
- `table_template(action, payload)` JSON API: get/learn/reset.
- Tk 호스트와 독립 네이티브 백엔드가 공통 TableTemplateService를 사용한다.
- 학습·초기화는 기존 준말 `표`의 format/table 저장 계약을 그대로 사용하고
  다른 준말·설정을 보존한다. 작업 중 변경은 거부한다.
- Flutter 서식 관리에 문단 계층 / 제목·개요 서식 표 / 기본 데이터 표 영역을 추가했다.
  기존 프로파일 검토 경로를 유지하면서 데이터 표 학습·구조 미리보기·초기화를 통합했다.
- 데스크톱 파일 선택과 네이티브 file_selector를 연결했다. 경로 직접 입력도 지원한다.
- 선택 프로파일에 자체 table_style이 있으면 그것이 준말 기본 표보다 우선하는 정책을 유지한다.
- 미리보기는 템플릿 구조·서식 요약이며 실제 한/글 출력 미리보기가 아니다.
  기존 문단·제목 표 상세 편집의 Tk 경로 완전 제거는 별도 리팩터링 Phase 4의 잔여 작업이다.

- Linux 전체 Python: 1,058개 실행, 통과 1,055개, 실패·오류 0개, 건너뜀 3개.
  저장소 .venv 및 UTF-8, Windows 전용 모듈 대체 + 실제 Tk/Xvfb 사용.
- Flutter 전체 화면·단위 시험: 35개 통과, 네이티브 연결 1개는 경로 미지정으로 건너뜀.
  이후 DOCFIT_TEST_PYTHON을 저장소 .venv로 지정해 네이티브 연결 시험 1개 별도 통과.
- Flutter analyze: 문제 0개. 웹 Release 및 로컬 CanvasKit·글꼴·라이선스 번들 검증 통과.
- JSON 브리지 조회/초기화/작업 중 변경 차단, py_compile, 본체 CRLF 유지 확인.
- 실제 Windows 한/글 COM 조판 및 Windows 네이티브 파일 선택은 이 환경에서 미검증.
- 공개 EXE 배포 없이 알파 소스에 반영한다.
