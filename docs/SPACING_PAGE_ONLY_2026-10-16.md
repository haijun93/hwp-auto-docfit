# 자간 정리 카드의 페이지 맞춤 독립 실행

알파 소스 변경이며 공개 v1.76.4 EXE에는 포함되지 않는다.

## 사용 방법

작업 방식 → 자간 정리 카드에서 두 옵션을 각각 선택한다.

| 자간 정리 | 페이지 맞춤 | 실행 내용 |
|---|---|---|
| ON | OFF | 기존 자간 정리 작업만 실행(기본값) |
| ON | ON | 자간 정리 후 페이지 맞춤 |
| OFF | ON | 자간 변경 없이 페이지 맞춤만 실행 |
| OFF | OFF | 실행 버튼 비활성화, 백엔드에서도 시작 거부 |

자간 정리를 끄면 기존 자간 초기화·본문/표/글상자 자간 조정·장평 조정·짧은 줄 병합·단어 분리 검사·연결 부호 맞춤·선택형 서식 통일을 실행하지 않는다. 기존 자간 초기화와 표 제외의 하위 스위치도 비활성화한다.

페이지 맞춤은 기존 한/글 실측 기반 문단 간격·줄간격·표 셀 세로 여백 및 관련 문단 배치 알고리즘을 사용한다. 페이지 맞춤 내부의 최후 수단인 자간 축소·어절 당김도 자간 OFF에서는 차단한다. 세로 간격과 페이지 배치는 바뀔 수 있다.

## 상태 및 호환성

- `spacing_enabled` 기본 True, `spacing_page_fit` 기본 False. 다른 작업 카드에는 적용하지 않는다.
- 카드 옵션과 세부 작업 `page_fit`·`page_group` 및 자간 단계 목록을 양방향 연동한다.
- 설정 JSON에 저장하고 다음 실행 때 복원한다. 페이지 맞춤만 선택한 상태도 유지한다.
- 기존 입력 원본 보존·쪽 범위·중단·결과 저장 경로를 유지한다.
- 페이지 맞춤 OFF의 자간 모드에서는 페이지 보호·쪽 나누기 정리도 생략한다.

## 검증 범위

- Python 전체 1,231개(통과 1,226·조건부 제외 5), Flutter 전체 76개 및 정적 분석 통과.
- 실행 버튼 활성/비활성 검증을 추가한 Flutter 회귀 시험도 별도로 통과.
- 네 가지 옵션 조합, 초기화/서식 보정 차단, 표 제외 및 세부 페이지 단계 선택을 시험한다.
- 실제 파이프라인 함수에서 페이지 맞춤→관련 문단 배치 순서와 자간/서식 함수 미호출을 확인한다.
- 실측 쪽 맞춤의 어절 당김 보조 함수가 자간 OFF에서 실행되지 않음을 확인한다.
- 실제 Tk GUI의 설정 저장·다시 열기·세부 작업 연동, Flutter 스위치·하위 옵션 비활성화·안내 문구를 시험한다.
- Linux 시험에서는 Windows COM 모듈을 대체한다. 실제 한/글 2020 문서의 조판 결과와 자간 값 보존은 Windows 실기기에서 추가 확인해야 한다.
