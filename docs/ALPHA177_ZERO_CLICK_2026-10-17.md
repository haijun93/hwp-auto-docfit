# 1.77 Alpha 1 — Zero-Click 로컬 시험판

## 통합 및 긴급 수정

- v1.76.5 핫픽스를 기준으로 alpha의 최소 개입 UI와 자간/페이지 독립 스위치를 병합했다. 공개 main·태그는 변경하지 않는다.
- 빈 목록에 문서 하나를 드롭하면 2.5초 유예 후 실행한다. 일시정지·옵션 변경·다중/추가 드롭은 자동 실행을 취소한다.
- 옵션 요약 칩, 문서 지문 추천, 수동 선택 유지, 결과 자동 열기, 상단 서식 원드롭 등록을 포함한다.
- XLSX·XLS·PPTX·HML이 추가는 되지만 후처리에서 거부되던 연결 누락을 고쳤다. 기존 검증·원본 보존을 수행하는 kordoc 변환 함수를 재사용한다.
- 외부 오피스·PDF·이미지는 변환 초안으로 보고 `all`을 추천한다. 구조를 읽지 않은 파일은 `scan_complete=False`이며 표 옵션은 보수적으로 유지한다.
- PowerShell 5.1의 npm 안내문(stderr)이 빌드를 중단시키던 문제를 고쳤다. npm 비정상 종료 코드는 계속 빌드 실패로 처리한다.

## 범위와 한계

이번 로컬 빌드는 우선순위의 첫 단계인 처리 연결 오류 및 Zero-Click UI 통합본이다. 유니버셜 변환 엔진 전체 구현 완료를 뜻하지 않는다.
통합 IR, Node 없는 DOCX/XLSX 폴백, 신규 변환 표의 공통 안전 여백 게이트, HTML/HWP 일반 출력 및 결과별 다중 내보내기 UI는 후속 단계다.
DOCX·EPUB 출력에는 현재 Pandoc이 필요하다. 한/글 COM과 OCR 등의 환경별 제약도 유지한다.
사용자 원본을 시험 대상으로 직접 수정하지 않으며, 실제 서식 재연 시험도 사본으로 수행한다.
