# 1.74 알파 안정화 및 Flutter 전환 계획

기준일 2026-10-13. 기존 alpha 이력을 보존하고 Alpha 3에서 진행한다. 공개 베타는 1.74 Beta 1이다. 사용자 확인에 따라 Flutter UI 제거 및 MCP 테스트 기능 확대·자동 활성화는 제외한다.

| 순서 | 작업 | 이번 상태 | 완료 조건 |
|---|---|---|---|
| P0 | Beta 1/Alpha 2 기능 조사·기준선·원본/설정 보호 | 조사표·기준선 확보 | 새 회귀 실패와 플랫폼 한계를 구분 |
| P0 | `_tk` 요청 취소·종료 경쟁·실행 중 시간 초과 | 구현 | 늦은 callback 실행 방지, indefinite wait 해제, 종료 취소 시 서비스 유지 |
| P0 | 새 작업 범위와 오래된 poll 응답 | 구현 | 새 문서/새 작업은 전체 범위, 입력 draft 보존, 명령 뒤 오래된 응답 무시 |
| P1 | 준말 관리 Flutter 모듈·공통 서비스 | 구현 | CRUD/검색/기본값/저장 오류/데이터 호환, 420/1024 화면 시험 |
| P1 | 전체 설정을 스키마 기반 Flutter 폼으로 이전 | 다음 | 79개 키+단계별 수치·기존 마이그레이션/기본값 복원·저장 실패·상호 제약 동등성 |
| P1 | 서식 요소·복사 범위·준말 표 학습 | 다음 | 예시 분석/편집 취소/서식 저장 구조·COM 오류 보존 |
| P1 | 문서 검토·교정·원본/결과 비교·보조 도구 | 다음 | 먼저 읽기 전용 결과 표시, 이후 수정 승인/취소별 회귀 시험 |
| P2 | 상태/파일/프로필/작업/로그 서비스로 Tk 의존 제거 | 부분 시작(준말/저장) | Flutter와 Tk 모두 같은 독립 서비스 이용; COM worker 소유권 유지 |
| P2 | 상태 revision·진행 이벤트·재연결·중복 시작 | 후속 | poll은 fallback, 변경 이벤트만 전송; shutdown/취소/재시도 계약 검증 |
| P3 | Windows native/IPC/패키징 기술 검증 | 미실시 | 같은 PC에서 Web/native 시간·메모리·안정성·업데이트·오프라인 실측 |

각 기능은 alpha에서 구현·테스트·리뷰한다. 기존 main, 배포 태그와 배포 EXE는 바꾸지 않는다. 전체 Tk 화면을 한꺼번에 삭제하지 않는다. native 전환은 WebView2와 기능 동등성·실측 이득이 확인된 후 제안한다.

이번 산출물은 준말 관리와 요청/범위 안정화다. 주요 작업 전체를 Tk 화면 없이 완료한다는 최종 기준은 아직 충족하지 않았다. 후속 작업은 전체 설정의 타입·제약 스키마를 확정하고 모드별로 옮기는 것이다.
