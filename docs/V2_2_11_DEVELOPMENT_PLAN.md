# 2.2.11 개발 계획

상태: 개발 중
기준 브랜치: `release/2.2.10`
작업 브랜치: `release/2.2.11`

## 범위

- [x] 앱 버전을 2.2.11로 올리고 2.2.10에서 분기했다.
- [x] 제공된 HWPX 기반 “추진절차(가로세로) · 모양 1” 템플릿 교체를 이식했다.
- [x] 표그림판 작업 자동 저장·복구의 첫 수직 경로를 구현했다. 원자적 복구 초안 파일, 재실행 시 복구/폐기 선택, 격자 이미지 가져오기 기반 기능을 추가했다.
- [ ] 자동 저장·복구를 다이어그램·마인드맵에도 연결하고 강제 종료 시나리오를 검증한다.
- [ ] 손그림 이미지 인식에서 불완전한 선, 기울기, 조명·배경 잡음, 잘못된 인식의 미리보기·수정 흐름을 보강한다.
- [ ] 몽땅클립보드 Excel 표 붙여넣기 시 한/글 표 구조·내용·테두리는 보존하고 음영만 제거하는 경로를 구현한다.
- [ ] v2.2.8의 `[Errno 13] Permission denied`를 Windows에서 재현하고 접근 파일·잠금·권한 원인을 특정해 조치한다.
- [ ] Windows/한글 실기기 설치·실행, 템플릿 삽입·저장, 복구 및 클립보드 동작을 검증한다.

## 복구 저장 원칙

- 복구 초안은 일반 사용자 템플릿 저장물과 분리된 설정 폴더에 둔다.
- 임시 파일 기록 후 원자 교체하며, 원본 작업 파일은 덮어쓰지 않는다.
- 자동 저장 실패는 편집을 막지 않고 다음 변경 때 재시도한다.
- 복구는 사용자 선택을 거치며, 데이터가 없거나 손상된 경우 편집기 시작을 막지 않는다.

## 검증 게이트

- Python 서비스 시험과 Flutter 시험·정적 분석을 통과한다.
- 종료/재시작 복구, 손상된 초안, 저장 취소·권한 오류, 큰 이미지 입력을 확인한다.
- Windows/한글 실기기 검증 전에는 배포 가능으로 표시하지 않는다.
