# 작업 결과 보고서 (2026-10-10)

대상: 알파 브랜치(`alpha`, 1.73 Alpha 1) / 비교 기준: 베타(`main`, 1.72 Beta 13)
측정 파일: `보고서 예시 파일(한번에 적용).txt`(기준 파일), `10월 확대간부회의 자료문화경제국.hwp`(14쪽, 표 제외)
측정 방법: 같은 시간대에 끄기/켜기를 번갈아 실행해 중앙값 비교, 점수·쪽수·단어 분리 결과가 같아야 합격

## 2. F2 줄 경계 사전 검사 (본문 자간·단어 분리)

캐시된 문단 글만 보고 "단어 중간 끊김·괄호 안 끊김·짧은 다음 어절"이 없는 줄은 한/글 측정을 건너뛰는 방식.

| | 끄기 | 켜기 |
|---|---|---|
| 기준 파일 전체(3회) | 207.0 / 213.9 / 219.7초, 중앙값 213.9 | 147.7* / 207.2 / 208.6초, 중앙값 207.2 |
| 본문 자간 단계 | 18.4~21.3초 | 18.5~18.8초(*회차 제외) |
| 건너뛴 줄 | - | 기준 파일 9줄 중 4줄, 14쪽 문서 2~24줄 중 2~9줄 |
| 14쪽 문서 점수 | 100 | **98.2 (저장 결과 단어 분리 1건 '10. 19.~11. 18.')** |

\* 147.7초 회차는 모든 단계가 함께 빨라진 PC 상태 흔들림으로 판단해 제외.
판정: 건너뛸 줄이 너무 적고(이미 한 줄 문단 건너뛰기가 대부분을 거름), 품질이 떨어져 미반영.

## 3. F3 짧은 마지막 줄 병합 사전 검사

문단 글자 수와 마지막 줄 시작 위치만으로 "한 줄 문단·마지막 줄이 기준보다 긴 문단"은 줄마다 글을 읽지 않고 건너뜀.

| | 끄기 | 켜기 |
|---|---|---|
| 기준 파일 전체(3회) | 214.0 / 211.8 / 211.3초, 중앙값 211.8 | 212.8 / 212.4 / 211.4초, 중앙값 212.4 |
| 짧은 마지막 줄 병합 단계 | 7.8~7.9초 | 7.8~7.9초 |
| 14쪽 문서 | 307.8초, 100점 | 306.7초, 100점 |
| 건너뛴 문단 | - | 기준 파일 4개 중 1개, 14쪽 9개 중 5개 |

판정: 결과는 같지만 시간 차이가 측정 오차 안(0.3% 이내)이라 미반영.

## 4. 줄 사전 거르기 방향의 결론

- 이미 들어간 "한 줄 문단 건너뛰기"와 "문단 글 캐시"가 거를 수 있는 줄을 대부분 거르고 있어, 추가 사전 검사가 거르는 줄은 몇 개뿐이다.
- 남은 시간은 줄 수가 아니라 단계 자체에 있다. 기준 파일에서 큰 단계: 개별 문단 페이지 배치 약 34초, 저장 후 규칙 검수 약 24초, 본문 자간 약 19초, 보고서 표준서식 약 17초, 표/컨트롤 자간 약 15초.
- 다음 속도 개선 후보는 줄 거르기가 아니라 **개별 문단 페이지 배치**와 **저장 후 규칙 검수**(XML로 읽어 COM 호출 줄이기)다.

## 5. 측정 환경 메모

이번 측정에서는 끄기 쪽도 기준값(Beta 11 중앙값 179.6초)보다 약 30초 느렸다(PC 상태 차이). 그래서 기준값과 직접 비교하지 않고 같은 시간대의 끄기/켜기 결과끼리만 비교했다.
