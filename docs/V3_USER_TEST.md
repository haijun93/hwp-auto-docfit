# 한/글 편집 도우미 3.0 사용자 시험 안내

이 안내는 공무원 사용자가 한/글에서 기본 동작을 확인하는 절차입니다. 원본 문서에는 시험하지 말고, 시험용 문서를 복사한 **사본**으로 진행하세요. 저장하지 않은 내용은 앱이 자동 저장하지 않습니다. 시험 중 저장 여부는 직접 판단하세요.

## 준비

1. 시험할 한/글 문서를 복사하고, 복사본을 한/글에서 엽니다. 표와 그림을 넣을 빈 줄, 정보단위 조정용 표, 자간을 확인할 문장을 준비하면 좋습니다.
2. 한/글 창이 보이고 문서가 편집 가능한지 확인합니다. 글자 모양 같은 대화상자가 열려 있으면 먼저 닫습니다.
3. 한/글 도우미를 실행합니다. 문서가 여러 개 열려 있다면 시험할 문서가 앞에 보이게 둡니다.
4. 넣기 직전까지 시험 대상 문서와 커서가 유지되어야 합니다. 대화상자나 다른 창이 앞에 있거나 대상 문서·커서가 바뀌면 넣기는 `DOCUMENT_BUSY` 또는 문맥 변경 안내로 중단되고 문서 내용은 바뀌지 않아야 합니다.

## 시험 순서

### 1. 도우미 패널과 단축키

1. 도우미 패널을 엽니다. 패널 제목이 **한/글 도우미**인지 확인합니다.
2. 화면의 단축키 항목에서 기본값을 확인합니다: 패널 열기·닫기 `Ctrl+Alt+J`, 표 템플릿 `Ctrl+Alt+T`, 표그림판 `Ctrl+Alt+S`.
3. 필요하면 저장 버튼으로 단축키 설정을 저장합니다. 이미 다른 프로그램이 쓰는 조합이면 충돌 안내가 표시되는지 봅니다.
4. `Ctrl+Alt+J`를 눌러 패널이 열리고 다시 눌러 닫히는지 확인합니다. `Ctrl+Alt+T`와 `Ctrl+Alt+S`는 표 템플릿·표그림판 기능을 여는 단축키입니다. 화면에 연결된 기능이 있는 빌드에서만 이어서 확인하고, 동작하지 않으면 빌드/버전과 함께 기록합니다.

### 2. 트레이

1. 도우미를 실행한 뒤 Windows 알림 영역(시계 옆 숨겨진 아이콘 포함)에 **한글 문서 편집 도우미** 아이콘이 있는지 확인합니다.
2. 아이콘을 오른쪽 클릭합니다. **도우미 패널 열기**, **앱 창 복원**, **종료** 메뉴가 보이는지 확인합니다.
3. 패널 열기를 선택해 패널이 나타나는지 확인합니다. 앱 창 복원은 앱 창이 최소화된 경우 확인합니다. 시험 중에는 종료를 선택하지 않습니다.

### 3. 커서 위치에 표·그림 넣기

1. 사본 문서의 빈 문단을 클릭해 커서를 둡니다.
2. 표 템플릿을 열어 표 하나를 선택해 넣습니다. 커서가 있던 위치에 표가 생기는지 확인합니다.
3. 다시 빈 문단에 커서를 두고 표그림판으로 작은 표를 만들어 넣습니다.
4. 다이어그램·마인드맵·그림판 기능이 화면에 제공되는 빌드라면 하나를 골라 커서 위치에 그림을 넣습니다. 해당 기능이 화면에 없으면 이 항목은 **아직 구현/연결되지 않음**으로 기록하고 건너뜁니다.

### 4. 되돌리기

1. 각 삽입 직후 다른 내용을 입력하지 말고 한/글에서 `Ctrl+Z`를 한 번 누릅니다.
2. 방금 넣은 표 또는 그림만 사라지고, 그 전 문서 내용은 남는지 확인합니다.
3. 필요하면 `Ctrl+Y`로 다시 실행합니다. 되돌리기 결과가 다르면 추가 편집을 멈추고 문제 내용을 기록합니다.

### 5. 표 정보단위 −/+

1. 정보단위가 있는 표 안의 셀을 클릭합니다.
2. 도우미 화면에 정보단위 `−`와 `+` 조정 기능이 있는 경우 각각 한 번씩 사용하고, 표의 단위가 의도대로 줄거나 늘어나는지 확인합니다.
3. 현재 확인한 화면/코드에는 이 조정 기능의 사용자 조작 연결이 없습니다. 기능이 보이지 않으면 **구현 전/연결 전**으로 표시하고 시험하지 않습니다. 설계상 Ctrl+Z 동작도 실측 통과 전 게이트 항목입니다.

### 6. 자간 정리

1. 사본 문서에서 자간을 확인할 문장을 선택합니다.
2. 도우미에 선택 자간 정리 기능이 있는 경우 실행하고, 선택한 문장만 정리되는지 확인합니다.
3. 현재 확인한 화면/코드에는 자간 정리 조작 연결이 없습니다. 기능이 보이지 않으면 **구현 전/연결 전**으로 기록합니다. 구현되어 보이는 빌드에서는 실행 전 사본인지 확인하고, 결과가 이상하면 즉시 `Ctrl+Z` 한 번으로 원래 선택 내용이 돌아오는지 확인합니다. 설계상 이 동작은 실측 게이트입니다.

## 합격 기준

- 패널이 열리고 닫히며, 표시된 전역 단축키가 저장됩니다. 충돌 조합은 안내됩니다.
- 트레이 아이콘과 메뉴가 나타나고 패널 열기·앱 창 복원이 동작합니다.
- 제공되는 표 템플릿·표그림판·그림 넣기는 커서 위치에 삽입됩니다.
- 표/그림 삽입은 각각 `Ctrl+Z` 한 번으로 되돌아가고, 삽입 전 내용이 보존됩니다.
- 클립보드 보관에 실패하면 넣기 작업과 문서 변경이 발생하지 않고 기존 클립보드가 유지됩니다. 복원에 실패하면 삽입 결과와 함께 복원 실패 안내가 표시됩니다.
- 저장 명령은 LiveLink 실행 경로에서 허용되지 않습니다. 도우미가 사용자 문서를 자동 저장하지 않습니다.
- 정보단위와 자간 정리는 기능이 실제 화면에 제공되는 빌드에서만 판정합니다. 설계 문서의 단계 계획상 α3 항목이며, `Ctrl+Z` 게이트를 통과하지 않은 기능은 사용 가능하다고 판정하지 않습니다.
- 패널이 한/글 창을 따라붙는 동작은 설계 목표입니다. 시험 화면에서 동작하지 않으면 실패로 기록합니다. 패널 화면 자체도 Windows 확인이 필요한 상태로 표시되어 있습니다.

## 문제가 있으면 알릴 내용

문제가 난 단계와 누른 순서, 기대한 결과와 실제 결과, 화면에 나온 오류 문구, 앱 버전, Windows/한글 버전, 열려 있던 문서 수, 커서가 문서/표/선택 글 중 어디에 있었는지를 알려 주세요. 가능하면 개인정보·민감정보를 가린 화면 캡처를 첨부하고, 원본이 아닌 사본에서 재현되는지 함께 적어 주세요. 문서 내용 자체는 보내지 않아도 됩니다.
