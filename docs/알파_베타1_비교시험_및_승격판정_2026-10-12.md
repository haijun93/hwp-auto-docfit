# 알파 개선사항과 v1.74 Beta 1 비교 시험 및 승격 판정

작성일: 2026-10-12  
비교 기준: `v1.74-beta.1` (`731a520`)  
알파 기준: `github/alpha` 기반 보안·퀵모드 작업 커밋 `75ef7a7` 및 그 후속 시험 보완  
범위: MCP 제외. AI Markdown 답변 변환, 서식 통일 퀵모드, HWPX 입력 경계·경로 검증, kordoc 실행 정책.

## 설계·구현 결과

- 로컬 MCP 서버 구현은 범위에서 제외했다.
- 퀵모드는 서식 통일 비교값을 글꼴 종류와 크기로 제한하고, 기존 `unify_full_format` 설정을 역호환한다. 전체 서식 모드는 기존 비교 필드를 유지한다.
- ChatGPT·Gemini·Claude 형식 답변에 Markdown 구조 변환 경로를 적용하고, GFM 체크박스는 완료/미완료로 표시한다. 일반 Markdown에는 기존 정리 경로를 둔다.
- HWPX 읽기 전에 공용 안전 검사를 적용하고, kordoc npx 자동 다운로드는 기본 차단한다. 파일 브리지 입력에는 경로 개수·길이·심볼릭 링크 검사를 둔다.
- 보안 검토 S1·S4·S5·S6·S9는 해결 완료가 아니다. 상세 범위와 잔여 위험은 `보안성_검토_알파_개선_2026-10-12.md`에 기록했다.

| 항목 | v1.74 Beta 1 | 알파 | 판정 |

| AI Markdown 전처리 | ChatGPT/Claude/Gemini 인식·구조화 경로 없음 | 합성 6종 전부 예상 경로로 분기, 체크박스 표시 및 주요 Markdown 구문 잔여 없음 | 기능 범위 개선. 실제 HWPX/COM 완성은 미측정 |

Markdown 시간은 Python 전처리만 측정했다. 한/글 실행, XML 일괄 서식, COM 내어쓰기·쪽 맞춤, 저장·재열기 검증은 포함하지 않았다. 임의 Markdown 표와 YAML frontmatter 등은 원래 의미를 완전 보존한다고 보장하지 않으며, 표는 텍스트 형태로 평탄화될 수 있다.

## 승격 판정

**v1.74 Beta 2 릴리즈 보류.** 알파의 기능 범위는 개선됐지만, 베타에서 통과하던 XML 서식 통일 시험이 알파에서 실패한다. 더구나 한/글 2020 실문서 COM 조판과 출력 HWPX 비교를 이 환경에서 확인하지 못했다. 성능 개선도 전처리 시간만으로는 베타 대비 입증되지 않았다.

다음 승격 조건:

1. COM 읽기 횟수 초과 원인을 수정하고 `XmlSurveyFlowTest`를 베타 기준과 동등 이상으로 통과.
2. `webview` 포함 프로젝트 가상환경에서 전체 회귀 테스트 실행, 실패·오류 0건 또는 원인·허용 여부 승인.
3. 한/글 2020 PC에서 대표 문서 코퍼스로 베타/알파를 동일 조건 3회씩 처리하고, HWPX 유효성·본문/표 내용·서식·내어쓰기·처리시간·실패율을 비교.
4. 미해결 고위험 보안 항목의 수용 여부를 기록하고, 베타 배포 산출물·서명·해시 검증을 통과.

현재는 개선 개발용 알파로 유지하고 베타 태그·릴리즈는 만들지 않는다.
