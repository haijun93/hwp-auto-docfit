# 1.73 Alpha 1 — HWPX 일괄 서식

기본 보고서 서식의 항목기호별 글자·문단 모양을 HWPX에서 묶어 적용합니다.
한/글에서 문단마다 글꼴·크기·장평·줄간격을 다시 쓰는 호출을 줄이고,
내어쓰기·줄 끝 단어·쪽 배치는 실제 한/글 조판을 기준으로 처리합니다.

## 사용하기

`alpha` 브랜치에서 소스로 실행하면 앱 버전은 **1.73 Alpha 1**입니다.
Windows와 편집 가능한 한/글 2020, 기존 보안 모듈·Python 의존성이 필요합니다.

```powershell
.\.venv\Scripts\python.exe hwp-auto-docfit.py
```

**기본 보고서 서식 → 한 번에 적용** 또는 자간 조정을 끈 서식 적용에서
새 경로를 사용합니다. 원본 대신 문서 사본으로 먼저 시험하세요.
처리 기록의 `[알파 일괄 서식]`에서 XML 적용 문단 수와 기존 경로 문단 수를 확인합니다.

GitHub의 `Build Windows exe` 작업은 `alpha` 푸시에도 실행됩니다.
Windows 테스트와 빌드가 통과하면 작업의 **HWP_AutoDocFit-alpha** 아티팩트에
`HWP_AutoDocFit.exe`가 생성됩니다. 알파 빌드는 공식 베타 릴리스 자산을 덮어쓰지 않습니다.
빌드 완료 여부는 해당 작업 결과에서 확인해야 합니다.

## 적용 범위

- 단순 본문: 문두 공백·점 기호 정리, 글꼴·크기·장평·줄간격·문단 위 여백,
  항목기호 및 라벨 굵게를 XML에서 적용합니다. 기호별 글꼴/크기 선택과 굵게 설정을 따릅니다.
- 같은 모양은 새 서식 ID 하나를 공유합니다. 원본 서식 ID와 기존 강조·색·밑줄·위첨자는 보존합니다.
- 준말·제목 폭 처리와 같은 HWPX 처리 묶음에 이어 붙여 결과를 한 번만 엽니다.
- 내어쓰기는 글꼴 폭을 추측하지 않고 기존 한/글 실측 경로를 사용합니다.
- 자간·짧은 마지막 줄 보정은 현재 실제 한 줄인 본문만 생략합니다.
  여러 줄·표/컨트롤·측정 실패 문단은 기존 조정과 최종 검수를 유지합니다.

이번 알파의 빠른 경로는 **기본 보고서 서식**을 대상으로 합니다.
사용자 서식의 복사 문단 모양·계층 추가 속성·간격 규칙, 쪽 범위 지정,
복잡한 필드·컨트롤·특수 텍스트 요소·중복 본문은 기존 COM 경로로 처리합니다.
이 경우에도 선택한 서식을 적용하지만 같은 속도 개선을 기대해서는 안 됩니다.
원본과 같은 출력 경로는 거절하며, 수정하지 않은 ZIP 항목은 압축 바이트도 보존합니다.

## 검증

새 회귀 검사는 `tests/test_batch_format.py`에 있습니다. XML 결과의 본문·강조·위첨자·표 보존,
서식 공유·반복 적용, 옵션·중복 문단·다중 구역·네임스페이스·안전 파싱을 검사합니다.
앱 함수의 연결 검사는 Windows 앱 전체를 임포트하지 않고 해당 실제 함수 본문을 실행합니다.
이 검사는 Windows COM이나 한/글 조판 검증을 대신하지 않습니다.

```powershell
.\.venv\Scripts\python.exe -m unittest tests.test_batch_format -v
.\.venv\Scripts\python.exe -m unittest discover -s tests
```

실제 한/글에서 기존 경로와 알파 경로를 비교하려면 다음 도구를 사용합니다.
`--out`에는 아직 없는 새 폴더를 지정합니다. 두 결과와 `comparison.json`을 보관하며,
원본 해시·내용·표·그림 보존과 처리 시간을 비교합니다. 이 도구의 내용 비교는
서식·쪽 배치의 시각적 일치를 증명하지 않으므로 결과를 한/글에서 함께 확인하세요.

```powershell
.\.venv\Scripts\python.exe scripts\smoke_batch_format.py `
  "보고서 사본.hwpx" --out "scratch\alpha-batch-comparison" --mode all
```

실제 문서 전체의 속도 향상과 Windows EXE 동작은 Windows 검증 결과가 필요합니다.
Linux에서 XML 테스트가 통과한 것만으로 처리 시간이나 실제 조판 일치를 보장하지 않습니다.
