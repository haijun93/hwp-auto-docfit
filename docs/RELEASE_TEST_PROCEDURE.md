# 릴리즈 검수 절차

## 서식재연검수절차

최종 검수에서는 **서식 원본과 재연된 검수 결과물의 일치 여부만** 릴리즈 적합 판정 기준으로 삼는다.

릴리즈 후보의 최종 검수는 지정된 서식 원본과 앱이 서식을 재연한 검수 결과물의 일치 여부로 판정한다. 원본 문서는 변경하지 않고 작업용 사본만 사용한다.

1. 릴리즈 후보 빌드에서 지정된 검수 원본을 복사해 작업 사본을 만든다.
2. 후보 앱의 서식 분석·적용 기능으로 원본 서식을 재연하고, 결과 HWPX를 한/글에서 열어 저장한다.
3. 원본과 결과물을 같은 조건으로 렌더링하고, 문서 구조 및 페이지별 시각 결과를 대조한다. 제목·본문·문단·글자·표·쪽 설정 등 검수 대상 서식 요소와 배치가 모두 일치해야 한다.
4. 불일치가 하나라도 있으면 최종 검수 불합격으로 기록하고 릴리즈하지 않는다. 수정 후 동일한 원본 사본 절차로 다시 검수한다.
5. 통과한 경우 검수 원본 식별정보, 후보 버전/커밋, 결과물 경로, 비교 자료, 불일치 0건 결과를 검수 기록에 남긴다.

최종 릴리즈 적합 판정은 위 서식 재연 일치 여부만으로 내린다. 빌드·단위 테스트·보안 검사 등은 별도의 기본 품질 확인으로 계속 수행하지만, 이 결과를 서식 재연 불일치의 대체 합격 근거로 삼지 않는다. 속도나 주관적 UI 선호도도 최종 서식 재연 합격 기준에 포함하지 않는다.

## 검수 도구

HWPX 구조 기반 비교는 다음 도구를 사용할 수 있다. 이 검수는 한/글의 실제 렌더링 결과와 동일한지 반드시 함께 확인한다.

```powershell
.\.venv\Scripts\python.exe scripts\format_fidelity_pc.py "검수 원본.hwpx" --out "검수 결과"
```

도구가 자동으로 판정하지 못하는 요소나 렌더링 차이는 페이지별 대조 결과로 보완 기록한다. 자동 비교 결과만으로 100% 일치를 주장하지 않는다.
