# MD 목차 서식 적용 — Alpha 12

작성일: 2026-10-15.

- .md 파일은 명시적 문서로 해석한다. #~###### 및 공백을 끼워 쓴 # # / # ## 표제를 계층으로 처리한다.
- # 단일 문서 제목과 하위 목차를 구분하며 제목 등장 순서가 바뀌어도 hash 깊이에 따라 계층을 정한다.
- ※ 주석이 있거나 AI 자동 감지를 꺼도 MD 목차 해석은 동작한다. 일반 TXT/붙여넣기 감지 계약은 유지한다.
- 코드 블록의 #는 목차로 승격하지 않는다. 이미지가 있는 MD는 기존 이미지 보존 엔진 경로를 유지한다.
- 연·월 날짜(2026. 10.)를 목록 번호로 오인해 분리하지 않는다.
- 구조화된 라벨은 실제 한/글 표·문단으로 삽입한다. 저장 성공·파일 해제 뒤에만 제목/개요 표식을 후처리한다.
- 사용자 예시의 표 4개(7×2, 8×3, 6×3, 5×3), 날짜·합계·음수 절사액·붙임·확인 필요 문구를 보존했다.
  첨부 원본은 수정하거나 저장소에 게시하지 않았다.
- 신규 회귀 시험 7개 포함 Python 전체 1,153개: 1,150 통과·조건부 제외 3·실패/오류 0.
- COM 삽입 호출/저장 실패/파일 해제 순서는 포트 대체 시험으로 확인했다.
  Windows 한/글 실문서 생성·쪽 배치 완료를 확인한 결과와 구분한다.
