# 1.74 Alpha 5 — 리뷰 반영 및 검증

기준 Alpha 4: `07ceecb`. Flutter/WebView2와 기존 COM 처리 알고리즘을 유지하고 리뷰의 내용 보존·설정 저장·입력 제한 및 독립적으로 검증 가능한 최적화를 반영했다. 공개 main은 변경하지 않았다.

## 반영 내용

| 항목 | 변경 | 검증 |
| --- | --- | --- |
| 버전·소수 손실 | 점으로 연결된 번호는 앞서 확인된 부모 목차가 있을 때 해석. 버전·금액 단어는 보호, 모호한 번호는 보존 | `1.74`/`2.50` 보존과 실제 `1. → 1.1 → 2.` 위계 복귀 |
| 코드 손실 | fenced/inline code 범위를 문자 참조·출처·HTML·강조 정리 전에 보호 | `items[1]`, `2**3**4`, `<strong>내용</strong>` 보존 |
| 문의 문장 삭제 | 공문 본문 보존이 기본. 대화체 인사/후속 제안 삭제는 명시적 `strip_chat_frame=True`에서만 실행 | 기본 보존/명시적 제거 양쪽 시험. 기존 서비스 fixture는 명시적 제거 모드 검사 |
| 굵은 본문 제목 오인 | 문장 종결을 가진 굵은 문장은 제목 분류에서 제외 | 기존 민원 6문단·날짜·공백 강조 회귀 유지 |
| 설정 동시 갱신 | 정규화된 설정 경로별 공유 RLock. 서비스 경로는 생성 시 고정. 기존 앱 저장도 같은 원자 갱신 서비스 사용 | 두 독립 서비스 동시 갱신에서 두 변경 모두 보존. 교체 실패 시 기존 바이트 유지·다른 필드/준말 보존 |
| 설정 저장 오류 | 기존 앱도 저장 실패를 GUI 로그 큐에 전달 | 저장 오류 반환 및 원본 보존 시험 |
| snapshot 제한 | 파일/항목/총 해제 크기·개수·압축률 제한. 제한 길이로 inflate하고 선언 크기/EOF 확인 | 고압축, 항목 크기 초과, 허위 작은 크기로 꾸민 압축 입력 거부 |
| ZIP 중복 검사 | 매 항목의 집합 재생성 대신 `seen` 집합 사용 | 기존 fidelity/batch 결과 회귀 및 합성 ZIP 측정 |
| 중복 CRC 검사 | style inventory와 sample 함수의 즉시 중복 validate 호출 제거. 안전 open의 검사는 유지 | style inventory 전체 회귀. 새 출력 검증 유지 |
| GUI CI | 실제 TkDND root 사전 검사 + `--require-gui`에서 GUI skip을 실패 처리 | DISPLAY 없는 GUI 시험이 의도대로 exit 1. 최종 전체 시험은 GUI skip 없이 실행 |
| 직함·이름 의미단위 | 공통 `semantic_units` 범위를 기존 HWP 의미단위/줄 나눔 검사·붙임 단위 검수에 연결 | 과(동)장/팀장/주무관과 콜론·이름/○○○ 내부의 각 줄 경계, 쉼표·전화·일반 장소/부서 제외 |

직함·이름은 확인된 직함 목록과 한글/한자 이름·○○○ 자리표시자를 인식한다. 의미단위에 공백·콜론을 포함하고 실제 텍스트를 NBSP로 바꾸지 않는다. 실제 COM 조판 결과는 Windows 검증이 필요하다. 코드 내용은 공문서 내 텍스트로 전달하며 실행하지 않는다. 복사 과정에서 이미 사라진 구조를 복원하거나 문체/사실을 재작성하지 않는다.

| 파서 | 중앙값 |
| --- | --- |

새 파서에는 크기·압축률 검사도 포함된다. 이 수치는 작은 합성 ZIP의 load/구조 파싱 결과로, 실제 HWP 문서 처리 속도나 메모리 개선율을 의미하지 않는다. 실제 문서 코퍼스·COM 측정은 별도 작업이다.

## 남은 범위

설정 잠금은 동일 앱 프로세스 내부에 적용된다. 외부 프로그램/다른 프로세스의 동시 파일 변경까지 조정하지 않는다. 숫자/출처/제목 판별은 복사된 텍스트의 문맥에 따른 보수적 규칙이며 모든 소실 구조를 추정하지 않는다.

전체 Flutter 설정·프로필 상세·문서 검토 이관, 진행 이벤트/조회량 축소, Windows native 시제품은 기존 전환 계획의 잔여 작업이다. 이번 변경을 전체 UI 전환 완료로 보고하지 않는다. MCP 전용 오메가는 TODO의 별도 예정 항목을 유지한다.
