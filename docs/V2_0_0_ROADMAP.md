## 2.0.0의 목표

1. **화면을 Flutter로 100% 전환** — 사용자가 보는 Tk 창 0개. Tk는 숨은 한/글 연동·파일 대화상자 펌프로만 남긴다.
2. **작업 ID·취소·진행 이벤트 통신 규약** — 화면이 상태를 주기적으로 묻는 대신, 작업마다 ID가 있고 진행·완료·실패·취소 사건을 받는다.
3. **소스 재구조화** — `docfit_ui/legacy.py`(7,204줄), `docfit_engine/formatter.py`(10,316줄), `flutter_ui/lib/main.dart`(3,411줄)를 기능별 모듈로 나눈다.
4. **시작 속도 목표**(CI가 1.81부터 강제) — 스플래시 100ms 이하, 재실행 1.5초 이하.
5. **1.80.5 기능 포함** — 표 템플릿(정보단위·조직도·검색·즐겨찾기·칸 글 입력), 명령줄·탐색기 우클릭 메뉴(여러 파일 합치기·일괄 변환).
6. **Windows 실기기 검증** — WebView2 포커스·파일 선택·드래그, 고해상도(125·150%), 장시간 실행, 설치판·포터블.

## 작업 규칙

- 단계마다 작은 커밋, `dev/2.0.0`에만 푸시(배포 없음). 1.80.x 핫픽스는 `main`에서 하고 `dev/2.0.0`에 병합.
- 이관한 화면은 기존 Tk 동작을 끄는 설정 플래그(`ui_tk_fallback`)로 한동안 되돌릴 수 있게 둔다(알파=베타 상위 집합 원칙).
- 사용자 원본 문서는 사본으로만. 한/글 COM 시험은 `com_test_lock`.
