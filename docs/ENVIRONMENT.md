# 개발 환경

- 기준 버전: Python 3.15, Flutter 3.47.9, Node.js 24 LTS, Rust 1.99.1.
- Windows: Python 3.15 설치, Flutter 공식 Windows 설치 절차 후 `flutter`를 PATH에 추가하고 Rust는 rustup으로 설치합니다.
- Windows: Node.js 24 LTS는 공식 설치 프로그램으로 설치합니다.
- macOS: `brew install python@3.15 node@24 rustup` 후 rustup으로 Rust 1.99.1을 설치합니다.
- macOS: Flutter 공식 macOS 설치 절차에 따라 Flutter 3.47.9를 설치하고 PATH에 추가합니다.
