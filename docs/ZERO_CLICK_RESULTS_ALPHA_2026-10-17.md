# 1.77 Alpha 2 — Zero-Click 화면 흐름 수정 — 2026-10-17

사용자 요청에 따라 파일 추가부터 결과 확인까지의 자동 흐름을 사용자가 직접 제어하도록 변경했다.

## 반영 내용

- 파일 선택·드롭은 파일 목록에 등록만 한다. 카운트다운과 자동 작업 시작을 제거했다.
- 이전 UI에서 지연 전달될 수 있는 자동 시작 토큰도 백엔드에서 실행하지 않는다.
- 작업 완료 후 HWPX를 자동으로 열지 않는다. 결과 탭의 수동 열기 동작은 유지한다.
- 작업 방식 선택 화면에서 선택한 카드의 옵션을 바로 펼쳐 보인다. 문서 추정 결과에 따라 숨기던 표 옵션과 쪽 범위도 계속 표시한다.
- 세부 작업 목록을 접힌 상태로 시작하지 않도록 펼쳐진 목록으로 바꿨다.
- 처리 종료 시 결과 파일이 0개여도 Flutter의 `4. 결과 확인` 탭으로 이동한다.
- 처리 완료·중단·변환 결과, 세부 작업 합계, 오류, 최종 검수 요약을 결과 탭에 표시한다.
- 서식 통일의 저장 후 검수 결과도 별도 창 대신 결과 탭에 표시한다. 불일치, 판정 보류, 대표값 미확정, 검수 오류를 요약한다.
- Flutter 호스트에서 완료·오류 안내 팝업을 띄우지 않는다. 진행 로그는 기존 로그 화면에서 계속 볼 수 있다.
- 관련 자동실행·자동열기 설정을 앱 설정 목록에서 제거했다. 기존 설정 파일에 값이 남아 있어도 실행 경로에서는 무시한다.

## 사용자 흐름

`파일 추가 → 작업 방식 선택(옵션 전체 표시) → 사용자가 정리 시작 → 진행 → 4. 결과 확인`

이 변경은 알파 소스에 적용했다. 이번 작업에서는 테스트를 실행하지 않았다.
