# 로마자 중제목 예시 반영 — Alpha 13

작성일: 2026-10-15.

## 예시 분석과 반영

- 첨부 HWPX의 적용 전 문단은 로1 추진근거, Ⅰ 추진근거였다.
- 적용 후에는 1행 3열(로마자 번호·빈 간격·제목)의 글자처럼 취급하는 표가 사용됐다.
  번호 칸은 검정 0.5mm 사각 테두리, 제목 칸은 위·아래 검정 0.5mm 선이며 글자 크기는 20pt다.
- 기존 내장 중제목 기준이 이 구조와 일치함을 XML 속성으로 확인했다.
  기존 서식표_생성을 재사용하고 활성 서식 프로필의 우선순위를 유지한다.
- 중제목_hwpx_처리가 기존 중제목 표와 함께 일반 문단의 로1~로12 및 Ⅰ~Ⅻ 제목을 조사·변환한다.
  중제목/선행 서식 선택과 전체 문서 범위라는 기존 파이프라인 조건을 그대로 따른다.
- 일반 준말의 콜론 필수 규칙은 유지한다. 새 처리는 중제목 형식에 한정한 별도 경로다.
- 예시에서 명시한 추진근거는 추진 근거로 맞춘다. 다른 문장은 임의로 교정하지 않는다.
- ASCII I/V·Ⅰ형 같은 제품명·긴 문장·필드/표가 섞인 문단은 추정해서 바꾸지 않는다.
  분석 후 제목이 달라졌으면 중단한다. 재실행 때 기존 표를 중복 생성하지 않는다.
- MD의 명시적 로마자 장 제목은 번호를 지우거나 처음부터 재번호하지 않는다.
  Ⅱ·Ⅳ처럼 일부 장만 있는 경우도 번호를 보존하고 하위 제목/목록은 □·ㅇ·-로 연결한다.

## 검증

- 첨부 원본은 읽기만 했고 별도 사본에 XML 변환을 실행했다.
  적용 전 2문단을 중제목 표로 바꾸고 적용 후 기존 2표는 서식을 처리하여 결과는 4표다.
  원본 SHA-256 불변 및 결과 HWPX 패키지 검사 통과.
- 사용자 MD의 Ⅰ~Ⅴ 장 제목 5개, 본문 표 4개, 날짜·금액·음수 절사액·붙임 내용을 보존했다.
- Python 전체 1,157개: 통과 1,154·조건부 제외 3·실패/오류 0.
- 생산 Python 89개 AST/컴파일, runpy import_check, 소스 --self-test 통과.
  본체 CRLF 3,324줄 유지.
- Windows 한/글 COM 조판·실제 글꼴 렌더링·쪽 배치는 별도 실기기 확인이 필요하다.
  생성한 검증본은 XML 변환 결과이며 미리보기 그림은 원본 캐시일 수 있다.
