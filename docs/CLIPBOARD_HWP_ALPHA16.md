# Alpha 16 — 한/글 붙여넣기 복사 및 HWP→HWPX

작성: 2026-10-16 (한국시간)

□ 적용 사항
ㅇ 일반 표/다이어그램 편집기에 ‘표 복사 (한/글 붙여넣기)’ 및 ‘그림 복사 (한/글 붙여넣기)’ 추가.
ㅇ 흐름표·기본 표·조직표·장식표는 검증된 데이터를 HTML 표와 Unicode 텍스트로 복사함.
ㅇ 자유 도형·마인드맵은 PNG와 Windows DIB 그림으로 복사함. 한/글에서 Ctrl+V로 붙여넣음.
ㅇ 클립보드 사용 중 오류·크기 제한·플랫폼 미지원은 오류로 반환하며 성공 안내를 표시하지 않음.
ㅇ HTML의 한글 바이트 오프셋·본문 이스케이프·Windows 클립보드 닫기·그림 포맷을 회귀 검증함.
ㅇ HWP→HWPX는 작업 스레드가 소유한 한/글 COM으로 직접 저장하며 외부 Node/kordoc 불필요.
ㅇ 결과 HWPX 유효성 검사 후 새 파일로 확정하고 원본·기존 결과를 덮어쓰지 않음.
ㅇ tldraw 메뉴·설정 및 SDK 생성 자산 제외. 동결 EXE에서도 활성화하지 않음.
ㅇ Windows 짧은/긴 임시 경로의 파일 동일성 검사를 보완함.

□ 사용 방법
ㅇ 표/다이어그램 → 결과 작성 → ‘표 복사’ 또는 ‘그림 복사’ → 한/글 2020 커서 위치에서 Ctrl+V.
ㅇ 파일포맷 변경 → HWP 추가 → HWPX 선택 → 시작. 원본 옆에 (HWPX변경) 사본 생성.

□ 검증 및 한계
ㅇ Python 신규 회귀 검사 9개·Flutter 69개·JS 모델 15개·Flutter 정적 분석 통과.
ㅇ 전체 Python 최종 수치 및 웹 번들 검증은 HANDOVER.md에 기록함.
ㅇ 실제 Windows 한/글 2020 클립보드 수용과 COM 조판은 이 Linux 환경에서 실행하지 못함.
ㅇ HTML 붙여넣기의 테두리·배치는 한/글 HTML 해석에 따라 차이가 생길 수 있음.
ㅇ HWPX 저장 기능은 정밀 표 내보내기 경로로 유지함.
