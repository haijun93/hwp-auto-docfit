# HWP 네 가지 출력 형식 점검·개선

ㅇ HWP→HWPX/PDF 및 PDF 중간 산출물→PNG/JPG 경로가 기존 구현되어 있음을 확인함.
ㅇ HWP 입력의 네 가지 출력은 kordoc·Pandoc·OCR 없이 한/글 COM 저장을 사용함.
ㅇ 기존 설치 판정은 기본 레지스트리 보기만 검사하여 32비트 한/글 등록을 놓칠 수 있었음.
ㅇ 기본·32비트·64비트 COM 등록을 순서대로 확인하도록 보완함. 판정 중 한/글 창을 실행하지 않음.
ㅇ 회귀 시험에 등록 보기별 네 가지 메뉴 활성화, 외부 엔진 미호출, 원본 보존, 여러 쪽 PNG/JPG 생성을 추가함.
ㅇ 변환 시험은 가짜 한/글 COM과 실제 PDF 이미지 렌더러를 사용함. 한/글 2020 실문서 조판은 실기기 확인 필요.
ㅇ 공개 v1.76.3 태그·EXE는 변경하지 않음. 이번 개선은 후속 알파 소스 변경임.

ㅇ Python 전체 1,223개 시험 완료: 통과 1,218개, 조건부 제외 5개, 실패 0개.
