# 네이티브 시제품 릴리스 상태

소스 개발판은 alpha, 네이티브 별도 표기는 1.74 Native Prototype 1이다. Windows 정식 바이너리는 생성·검증·게시하지 않았다. 공개 Beta 1과 기존 빌드는 유지한다.

배포 승인 조건: Windows 네이티브 실행과 DPI/크기/파일 선택, 자동 백엔드 시작·버전 확인·종료·복구, HWP2020 실제 COM 문서 처리, 원본 보존·사본 저장·무결성 비교, 전체 화면과 설정 호환성, 장시간 진행·취소, 설치 없는 번들 실행 검증이다. 현재 문서 분석과 설정 서비스 통과만으로 이 조건을 충족하지 않는다.
