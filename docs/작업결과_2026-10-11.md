## 1-a. 자간 초기화를 XML에서 (`알파_자간초기화_XML_사용`, 기본 켬) — 합격

'한 번에 적용'에서 자간 초기화를 한/글 문단별 선택 대신 XML 선행 단계 맨 앞에서 한다(`docfit_core/spacing_reset.py`, `자간초기화_hwpx_처리`).
보호 구간(항목기호·라벨)은 한/글 경로와 같은 함수 `자간보호_글자수`로 정한다. 자간 정리 모드·쪽 범위 작업은 예전 방식 그대로.

test4 예시 파일, 기본 설정, 같은 알파 코드에서 플래그만 끄고 켜서 번갈아 2회:

| | 한/글 방식(끔) | XML 방식(켬) |
|---|---|---|
| 1회차 | 244.8초 | 213.6초 |
| 2회차 | 226.9초 | 214.3초 |
| 평균 | 235.9초 | **214.0초 (−9.3%)** |
| 자간 초기화 단계 | 14.5~16.3초 | 선행 단계 안(1초 미만) |
| 최종 검수 점수 | 100 | 100 |
| 결과 본문 글 | 1,255자 | 같음 |
| 글자별 자간 분포 | 0% 1,501자 · −12% 81자 · −10% 76자 … | **완전히 같음** |

- 시험: `tests/test_spacing_reset_xml.py` 6개(보호 구간 유지·run 나누기·숨은 글자 run 건너뜀·표 안 문단·글 보존·처리기).
- 남은 점: 보호 구간에 걸친 컨트롤 run 1개는 건너뛴다(test4에서 결과 차이 없음).

## 1-b. 문두 라벨 굵게·괄호 축소를 XML에서 (`알파_라벨괄호_XML_사용`) — 효과 미미, 기본 끔

판정을 순수 함수 `라벨괄호_계획`으로 떼고, 지금 열린 문서를 HWPX로 저장 → `라벨괄호_hwpx_처리` → 다시 여는 방식(`현재문서_XML단계_적용`).
run 분할·굵게·크기 줄임은 `docfit_core/char_ranges.py`.
