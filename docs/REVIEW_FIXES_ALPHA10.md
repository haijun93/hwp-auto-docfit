| F3 | 비교 보기 크기 조정이 본체 전역의 한/글 창 핸들을 읽어, 실행 컨텍스트가 연 창을 찾지 못했다(현재 GUI는 비교 보기를 끈 채 실행하므로 잠재 결함) | 실행 중에는 그 실행 컨텍스트의 창 핸들을 읽는다 | 실행 중·종료 후 핸들 선택 |
