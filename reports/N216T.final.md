# N216T 작업 결과

## 변경 사항

- 타임머신 본문 검색 도구막대에 `Markdown 내보내기` 버튼을 연결했다. 현재 검색어로 `content_export_markdown`을 호출하고 결과 메시지를 알림으로 표시한다.
- 본문 미리보기에 찾기 입력칸, 이전·다음 버튼, 일치 번호를 추가했다. 활성 일치를 강조하고 순환 이동하며, 기존 본문 검색어 강조도 유지한다.
- 타임머신 위젯 시험에서 Markdown 내보내기 호출과 미리보기 찾기 이동을 확인한다.
- 자료함 파일 추가 시험에서 불안정한 가상 DragTarget 제스처를 제거하고 `LibraryApi.addItem` 공개 API로 파일 자료 등록을 확인한다. Ctrl+V 시험은 화면 키보드 경로 그대로 유지하고 `skip: true`를 제거했다.
