<h2 align="center">v2.0.3 릴리즈</h2>
<p align="center">그림판 탭을 새로 넣고, 표그림판·마인드맵·다이어그램 편집 기능을 크게 늘렸습니다</p>

### 그림판 탭 (2.0.3)

사진을 끌어 놓거나 붙여 넣어 배경으로 깔고, 그 위에 펜·도형·선·글상자를 올립니다. 올린 것은 모두 따로 옮기고 고칠 수 있으며, PNG로 저장하거나 한/글에 그림으로 붙여 넣습니다.

### 표그림판 올가미·여러 개체 선택·칸 배경 그림 (2.0.3)

올가미로 둘러 고른 선과 글을 함께 옮기고, 복사·복제·삭제합니다. 지우개는 지나간 칸만 지웁니다. 사진을 칸에 끌어 놓으면 칸 배경 그림이 되고, 한/글에 붙여 넣을 때 그림 채우기로 함께 들어갑니다.

### 마인드맵 지도 테마·다이어그램 자석 (2.0.3)

마인드맵 가지 모양 10가지와 지도 테마(모양 5 × 색 8 × 바탕 3)를 고릅니다. 다이어그램은 선이 도형 가까이 가면 붙고, 도형을 옮기면 마주 보는 면으로 따라가며, 정렬 맞춤 점선이 나타납니다.

> 시작 속도 개선은 다음 버전에서 이어 갑니다.

<h2 align="center">v2.0.2 릴리즈</h2>
<p align="center">파일변환 탭을 열고, 다이어그램·마인드맵 탭이 바로 작동하며, 변환 포맷을 숫자 키패드로 고릅니다</p>

### 파일변환 탭 사용 가능 (2.0.2)

파일변환 탭의 "여기에 파일을 놓으세요" 영역에 파일을 끌어 놓거나 「파일 선택」을 누르면 바로 변환할 포맷을 고르는 창이 뜹니다. 변환이 끝나면 앱의 「4. 결과 확인」 화면에서 결과 파일을 열거나 폴더를 볼 수 있습니다.

### 변환 포맷을 숫자 키패드 모양으로 (2.0.2)

원형 메뉴를 키보드 숫자패드와 같은 3×4 배열(7 HWPX·8 DOCX·9 EPUB / 4 HTML·5 취소·6 MD / 1 PDF·2 PDF 압축·3 PDF 합치기 / 0 JPG·. PNG·+ TXT)로 바꿨습니다. 숫자 키를 누르면 바로 그 포맷으로 변환하고, 5번이나 Esc는 취소입니다.

### 다이어그램·마인드맵 탭 바로 작동 (2.0.2)

다이어그램 탭에서 "Flutter Windows 앱에서만 사용할 수 있어요" 안내만 나오던 문제를 고쳐, 탭에서 바로 다이어그램을 그립니다. 마인드맵 탭은 마인드맵 모드로 열립니다. 편집기 위쪽의 제목·모드 전환 줄을 없애 편집 도구 줄이 맨 위에 옵니다.

> 시작 속도(기록): 첫 실행 스플래시 114.2ms(목표 100ms 미달), 재실행 화면 1.93·1.83초(목표 1.5초 미달), 캐시 실행 0.76초. 시작 속도 개선은 2.0.3 과제이며 2.0.3부터 배포 조건으로 다시 적용합니다.

<h2 align="center">v2.0.1 긴급 수정 릴리즈</h2>
<p align="center">2.0.0의 흰 화면·창 닫기 불가·탭 멈춤과 새 PC에서 변환 기능이 안 되던 문제를 고쳤습니다</p>

### 창 닫기(X)가 항상 동작 (2.0.1)

화면이 응답하지 않을 때 X를 눌러도 창이 닫히지 않고 프로그램이 뒤에 남던 문제를 고쳤습니다. 화면이 5초 안에 답하지 않거나 X를 한 번 더 누르면, 앱이 만든 한/글 프로세스까지 정리하고 바로 닫습니다. 정상일 때는 지금처럼 저장 확인 창이 먼저 나옵니다.

### 탭 ← 버튼 멈춤·하단 탭 사라짐 수정 (2.0.1)

탭 안에서 ← 버튼을 누르면 앱이 멈추던 문제를 고쳤습니다. 탭 안의 ← 버튼은 숨기고, 상단 메뉴는 해당 탭으로 이동하며, 하단 탭은 항상 보입니다.

### 새 PC에서 변환 기능이 안 되던 문제 수정 (2.0.1)

2.0.0은 함께 넣은 변환 엔진(kordoc 4.24.9)과 앱이 찾는 버전(4.21.30)이 달라, 이전 엔진이 없는 PC에서는 변환 기능이 동작하지 않았습니다. 버전을 4.24.9로 맞추고 고정했습니다.

### 실제 실행 파일로 화면·종료 확인 (2.0.1)

배포 전 자동 검사에서 실제 exe를 띄워 첫 화면에 내용이 그려지는지(측정 4.6초), X로 닫히는지(0.6초), 화면이 멈춘 상태에서도 X로 닫히는지를 확인합니다.

> 파일변환 탭은 새 변환 화면으로 교체하는 동안 잠시 비활성(누르면 "준비 중")입니다. 새 화면은 다음 버전에 넣습니다.
> 시작 속도(기록): 첫 실행 스플래시 166.9ms(목표 100ms 미달), 재실행 1.37~1.47초. 시작 속도 개선은 다음 버전 과제입니다.

<h2 align="center">새로워진 v2.0.0 메이저 릴리즈</h2>
<p align="center">차세대 통합 단일 셸(Flutter 6-Tab) 안착, 한글 타이포그래피 정밀 조판(표 줄간격 100%·자간 -25%, 원문자 콜론 정렬), 공공 표준 표 6대 템플릿 탑재</p>

### 차세대 통합 단일 셸 워크스페이스 (Flutter 6-Tab) (2.0.0)

6개 핵심 작업 도구(자간/행간 맞춤, 표 단위 서식, 표그림판, 다이어그램, 마인드맵, 공공도구함)가 하나의 단일 창 안에서 탭 전환으로 매끄럽게 연결됩니다. 탭 전환 시 창 닫기 보호 장치(CloseGuards)를 분리하여 백그라운드 작업 손실 없이 신속하게 화면을 넘나들 수 있습니다.

### 표 셀 줄간격 최소 100% 및 자간 -25% 보장 (TODO 76~82) (2.0.0)

표 안의 글자가 위아래로 답답하게 겹치지 않도록 줄간격을 최소 100%로 보장하고, 자간을 최소 -25%까지 조절하여 가독성을 극대화했습니다. 구형 20자 분기 휴리스틱을 전면 폐기하여 모든 표 칸에서 균일하고 단정한 조판 품질을 제공합니다.

### 원문자·항목기호 콜론 후속 자동 들여쓰기 정렬 (TODO 96) (2.0.0)

원문자(`①~⑳`), 번호(`1.`), 한글 기호 뒤에 콜론(`:`, `：`)이 오는 문단(`①사업목적:인공지능`)에서 둘째 줄 이상의 후속 문장이 콜론 뒤 본문 첫 글자에 수직으로 칼같이 일치하도록 자동 들여쓰기(Hanging Indent) 메트릭스를 적용했습니다.

### 플로우차트 네이티브 한글 도형 클립보드 복사 (TODO 164~168) (2.0.0)

다이어그램 및 흐름도 편집기에서 작성한 사각형, 타원, 화살표 연결선을 비트맵 이미지가 아닌 실제 한/글 고유의 네이티브 벡터 도형(`hp:rect`, `hp:ellipse`, `hp:connectLine`)으로 한/글에 즉시 붙여넣을 수 있습니다.

### 공공기관 행정 보고서 표준 표 6대 템플릿 탑재 (2.0.0)

행정안전부 및 기획재정부 보고서 지침을 준수한 6대 표준 표(요약 1칸 표, 2열 정의 표, 3~4열 비교 표, 간트차트 일정표, 예산 산출 표, Q&A 체크리스트 표) 정밀 메트릭스 및 프리셋이 탑재되었습니다.

<h2 align="center">이전 릴리즈 (v1.80.15)</h2>
<p align="center">표 템플릿 UI 중복 상단 메뉴 전면 삭제, PPT 스타일 가로 1줄 컴팩트 리본 및 한/글 즉시 복사 버튼 탑재</p>

좌측 갤러리의 템플릿 목록과 완전히 중복되던 최상단 가로 템플릿 이름 바를 전면 삭제하여 표 미리보기 및 편집 작업 공간을 대폭 넓혔습니다. 검색창은 36px 전폭 규격으로 확대하고 원클릭 내용 지우기 버튼을 탑재했습니다.

### PPT 스타일 가로 1줄 분류 리본 (Single-Row Ribbon) (1.80.14)

최대 6줄을 차지하던 20개 분류 버튼 칩을 가로 1줄 단정형 리본(좌우 `<` `>` 내비게이션 화살표, 28px 통일 규격, 시각적 아이콘 및 분류별 서식 개수 뱃지)으로 전면 교체하여 한눈에 쾌적하게 탐색할 수 있습니다.

### 우측 상세창 상단 즉시 복사 버튼 (1.80.14)

템플릿 선택 즉시 1클릭으로 한/글에 붙여넣을 수 있도록 상세창 상단 타이틀 옆에 `[ 📋 한/글로 복사 (Ctrl+V) ]` 주 액션 버튼을 전면 배치했습니다.

### 표그림판·다이어그램·마인드맵이 다시 열립니다. (1.80.9)

표그림판의 **「표 서식 모음 HWPX 파일을 찾을 수 없음」**, 다이어그램·마인드맵의 **404 오류**를 해결했습니다.
런처가 사용 중인 캐시를 지우던 원인을 고쳐 실행 중인 캐시와 새 버전 캐시를 보존하고, 정리할 캐시는 옮긴 뒤 삭제합니다.

### 표는 더 길게, 일정표 날짜는 자동으로. (1.80.9)

표 템플릿의 열·행 반복 단위를 **최대 50개**까지 늘립니다(깨지는 축은 실제 조판으로 확인한 30개·15개 등의 상한 적용).
연간 일정표는 **분기 1·2·3·4를 반복**하고 날짜 칸은 실제 달력에 따라 이어집니다. 주간 일정표는 첫 날짜(기본 **4.26.**)부터 주 단위 기간을 자동으로 채웁니다.
사진첨부용 모양 1·2는 사진과 설명 묶음을 아래로 덧붙입니다. 표 이름 막대는 자판형으로 모든 이름이 보이며, 내장 템플릿 미리보기 그림도 동봉했습니다.

### 바뀐 점: PDF 합치기 순서와 개발자 도구 정리. (1.80.9)

PDF 하나로 합치기에서 파일을 끌거나 **↑/↓**로 순서를 정합니다. 내장 표 그림은 다른 기능을 먼저 쓴 뒤에도 정상적으로 표시됩니다.
개발자 모드의 문서 도구(문서 검토·공공언어 교정·문서 구조 편집·작성 도우미·Markdown 내보내기·고급 문서 도구)를 삭제했습니다. **「텍스트 입력」의 텍스트 변환 기능은 유지**합니다.
**tldraw 도형 편집기 삭제(다이어그램·마인드맵은 그대로)**도 포함했습니다.

### 서식은 그림으로 고르고, 메뉴는 창을 줄여도 그대로. (1.80.8)

상단 **「서식 관리」**를 누르면 예시 보고서 첫 쪽 그림으로 서식을 고르고, 카드마다 서식예시 확인·서식예시 폴더·서식관리를 바로 씁니다.
창을 줄여도 상단 메뉴가 잘리지 않고(아이콘으로 표시), 표 템플릿은 분류별 색으로 구분되며 그림이 자동으로 채워집니다.

### 선을 그으면 표가 됩니다. 표그림판. (1.80.7)

상단 메뉴의 **「표그림판」**에서 점선 바둑판 용지에 가로·세로·대각선 직선을 그리면 한/글에 바로 붙여 넣는 표가 만들어집니다.
선으로 둘러싼 자리는 칸 하나로 합쳐지고 그리지 않은 경계는 보이지 않는 테두리가 되어 조직도처럼 상자와 선으로 된 서식도 자유롭게 그릴 수 있습니다.
도구(사각형·지우개·글·선택)와 선 굵기·종류 선택, 화면 이동·확대, 실행 취소를 지원하며 **「한/글에 붙여넣기용 복사」**로 표를 한/글에 바로 붙여넣습니다.

### 표 템플릿, 더 많이 늘리고 한눈에 고르기. (1.80.7)

화면을 T자형으로 넓혀 위쪽에 모든 표 이름 버튼을 나열하고 왼쪽 분류 목록도 잘림 없이 한눈에 보고 고를 수 있도록 개선했습니다.
현황표·추진절차·신구대조표의 행 조절, 일정표·행사시간표의 열 조절, 사진과 설명 묶음을 아래로 더하는 사진첨부표까지 [−][+]로 조절하는 정보단위 표를 대폭 늘렸습니다.
추진절차나 신구대조표처럼 화살표 그림이 들어간 표도 미리보기에서 화살표 모양을 그대로 확인하며 작업할 수 있습니다.

### 고른 서식 그대로, 내어쓰기까지. 쪽 맞춤은 여백부터. (1.80.6)

서식 관리에서 「적용할 서식」을 바꿔도 처음 서식에 고정되던 문제를 고치고, 서식 변경 시 항목기호별 내어쓰기와 부연설명 들여쓰기 옵션이 빠짐없이 함께 적용되도록 바로잡았습니다.
서식예시 폴더(`C:\HWP_AUTODOCFIT\서식예시`)에 HWP·HWPX 문서를 넣어 두면 앱을 켤 때나 서식 관리 창을 열 때 자동으로 감지하여 새 서식으로 등록합니다(원본 파일 및 현재 선택 서식 유지).
쪽 맞춤 시 줄간격(권장 160%)을 좁히기 전에 위·아래 여백을 최소 5mm까지 먼저 줄여 본문 가독성을 지킵니다(한 번에 적용의 기본 여백 단일 보고서 대상).

### 업데이트는 설정에서 바로. 기관 PC에서도. (1.80.6)

설정 → 프로그램의 **「지금 확인」**으로 새 버전을 확인하고, 진행률을 보며 내려받아 바꿉니다. GitHub가 막힌 기관 PC에서도 GitLab에서 받습니다.
설치본은 설치 파일로 조용히 설치한 뒤 다시 켜지고, 포터블은 실행 파일을 바꿔 끼웁니다. 폐쇄망 모드에서는 인터넷에 접속하지 않고 수동으로 바꾸는 방법을 안내합니다.

### 표 템플릿: 고르고, 늘리고, 붙여넣기. (1.80.6)

상단 표 메뉴(다이어그램·마인드맵·표 템플릿)에서 **「표 템플릿」**을 고르면 서식 모음을 실제 한/글 모양으로 보고 검색·즐겨찾기로 빠르게 찾습니다.
과제 묶음·시간 줄·일정표처럼 반복되는 정보단위를 [−][+]로 조절하면 연도나 번호가 자동으로 이어지고(+1), 미리보기 칸을 눌러 글을 바로 수정할 수 있습니다.
2~10개 팀 수를 정해 상자가 나란히 늘어나는 **조직도**도 지원하며, 칸 안의 글상자 표도 알맞게 비율을 맞춰 줍니다.
「한/글에 붙여넣기용 복사」를 누르면 빈 문단 없이 표만 깔끔하게 복사되어 한/글 창이 앞으로 뜨고, **Ctrl+V**로 서식 그대로 붙습니다.

### 탐색기에서 바로 변환. 명령줄도. (1.80.6)

윈도우 탐색기에서 파일을 우클릭해 **「한글편집 후처리」** 메뉴에서 HWPX·PDF 변환, PDF 하나로 합치기, PDF 압축을 바로 실행할 수 있습니다(설정에서 켜기·끄기 가능, 관리자 권한 불필요).
여러 파일을 한꺼번에 골라도 프로그램이 한 번에 모아서 차례대로 변환하고, 작업이 끝나면 알림 창으로 처리 결과를 알려 줍니다(D: 드라이브·업무 폴더의 파일도 됩니다).
업무 자동화를 위해 명령줄 도구도 지원하여 `HWP_AutoDocFit.exe convert` 명령으로 일괄 변환하고 형식 지정 및 작업 결과 코드를 확인할 수 있습니다.

<h2 align="center">v1.80.4</h2>
<p align="center">멈추면 바로 멈추고, 준말은 한/글 문서로. 옵션은 그림으로 한눈에. 이제 기관 PC에서도 GitLab에서 바로 받습니다.</p>

### 여러 파일을 PDF 하나로. (1.80.4)

파일 변환에서 **「PDF 하나로 합치기」**를 고르면 PDF·HWPX·HWP·그림을 넣은 순서대로 한 PDF로 묶습니다. 파일마다 책갈피가 달리고 원본은 그대로입니다.
이미 같은 형식인 파일(예: PDF→PDF)은 고를 수 없게 막았습니다.

### GitLab에서 바로 받기, 실행 준비 창은 또렷하게. (1.80.4)

GitHub가 막힌 기관 PC에서도 위 「받기」 링크가 GitLab에서 바로 내려받습니다.
처음 실행할 때 뜨는 「실행 준비」 창에서 옛 안내 문구와 새 문구가 겹쳐 보이던 문제를 고쳤습니다.

### 작업 중단·창 닫기, 이제 확실하게.

파일 변환(HWPX→PDF)을 시작하면 바로 오류가 나던 문제를 고쳤습니다.
한/글이 응답하지 않아도 **「작업 중단」 10초 뒤** 앱이 띄운 한/글을 정리해 작업을 끝냅니다. 창을 닫을 때는 15초 안에 반드시 닫히고, 한 번 더 닫으면 바로 강제 종료할 수 있습니다.
사용자가 따로 연 한/글은 건드리지 않습니다. 종료 확인 문구도 지금 하는 작업 이름과 「작업 중단하고 종료 / 계속 진행」 버튼으로 바꿨습니다.

### 준말은 한/글 문서에서 고칩니다.

「준말 관리」에서 **한/글로 준말 문서를 열어** `#준말` 아래 문단에 본말을 쓰고 저장하면 끝입니다. 작업을 시작할 때마다 문서를 다시 읽어 항상 최신 값을 씁니다.
제목·개요·중제목·붙임·표 서식 표는 본말에 `[서식:제목1]`처럼 적습니다. 지금까지 앱에 등록한 준말은 처음 문서를 만들 때 그대로 옮겨집니다.

### 옵션 설명은 적용 전·후 그림으로.

작업 방식 카드·세부 작업·설정 옆에 **실제 전·후 비교 그림**을 보여 줍니다. 그림을 누르면 크게 볼 수 있습니다. 조판 미리보기 엔진(자산 약 12MB)은 빼고 그림 1.4MB로 바꿨습니다.

### 1.80.2 — 첨부 한도에 걸리던 PDF는 가볍게. 기호가 무엇이든 위계대로. 둘째 줄까지 반듯하게.

### 무거운 PDF, 가볍게. 보안 PDF도 보안 그대로.

스캔본·사진이 많은 PDF를 넣고 파일 변환에서 **「PDF 압축」**을 누르세요. 글자·쪽은 그대로 두고 그림만 다시 저장해 메일·전자결재 첨부 한도 안으로 줄입니다.
인쇄·복사가 제한된 **보안 PDF도 같은 권한 그대로** 줄입니다. 보호가 풀린 사본은 만들지 않습니다.

<p align="center"><img src="docs/media/v180/pdf-compress.png" alt="스캔 PDF 2.2MB가 PDF 압축 후 533KB로 줄어든 모습, 글자는 그대로" width="860"><br>
<sub>스캔한 보고서 3쪽: 2.2MB → 533KB(76% 감소). 글자는 그대로 읽힙니다</sub></p>

### 어떤 항목기호를 써도, 같은 공문서 모양으로.

`□ ㅇ -`만 알아듣던 시절은 끝났습니다. `1.` `1.1.` `1.1.1.`, `가.` `1)` `(1)`, `①`, `Ⅰ.` `A.` `a)`, `◆ ▶ ➢`, `■ ● ▪`, `▣ ✓ →`까지.
문서에 쓰인 기호의 **위계를 스스로 읽어 내** 1·2·3단계에 `□`·`ㅇ`·`-` 서식을 입힙니다. 기호 글자는 손대지 않습니다.

<p align="center"><img src="docs/media/v180/marker-schemes.png" alt="같은 보고서를 □ㅇ- 체계와 1. 1.1. 1.1.1. 체계로 썼을 때 같은 서식으로 정리된 결과" width="860"><br>
<sub>같은 내용을 서로 다른 기호로 써도, 글꼴·크기·굵기·내어쓰기가 똑같이 정리됩니다</sub></p>

<p align="center"><img src="docs/media/v180/decimal-before-after.png" alt="1. 1.1. 1.1.1. 번호로 쓴 메모의 적용 전과 후" width="860"><br>
<sub>번호로만 쓴 메모(왼쪽) → 단계별 서식이 입혀진 보고서(오른쪽)</sub></p>

### 둘째 줄은 언제나 본문 첫 글자에서.

`ㅇ (현황)`의 둘째 줄은 `(` 아래, `- 항세기`는 `항` 아래, `* 항세기:`는 콜론 뒤 첫 글자 아래.
한/글의 Shift+Tab을 그 자리에서 직접 실행해 **눈대중 없이** 맞춥니다. 붙임 번호 `2.`도 `1.` 바로 아래에 섭니다.

<p align="center"><img src="docs/media/v180/indent-before-after.png" alt="내어쓰기 적용 전과 후 — 둘째 줄이 본문 첫 글자에 맞춰짐" width="860"></p>

### 한 쪽 안의 줄 간격은 하나로. 빈 문서 저장은 원천 차단.

쪽에 맞추려고 줄 간격을 줄이면 **같은 쪽 전체를 같은 값으로** 맞춥니다(사용자 검수에서 나온 개선).
드물게 txt 입력이 빈 문서로 저장되던 문제를 고쳤고, 만에 하나 결과가 비면 성공으로 넘기지 않고 멈춥니다.

<h2 align="center">자주 묻는 질문</h2>

<details><summary><b>정말 무료인가요?</b></summary>

네. 받아서 바로 쓰면 됩니다. 결제도, 회원 가입도 없습니다.
</details>

<details><summary><b>문서가 밖으로 나가지 않나요?</b></summary>

나가지 않습니다. 내 PC에 설치된 한/글을 직접 다뤄 처리합니다. 기본은 폐쇄망 모드라 앱이 스스로 외부에 접속하지 않습니다.
</details>

<details><summary><b>원본이 망가지면 어떡하죠?</b></summary>

원본은 열기만 하고 고치지 않습니다. 결과는 같은 폴더에 `(일괄적용)`·`(자간조정)` 같은 이름의 새 HWPX로 저장됩니다.
</details>

<details><summary><b>우리 기관 양식에도 맞출 수 있나요?</b></summary>

예시 보고서(HWP·HWPX·PDF)를 끌어다 놓으면 그 서식을 배웁니다. 이후에는 썸네일로 골라 쓰면 됩니다. 예시에 쓰인 항목기호가 `1.1.`이든 `◆`든 위계를 읽어 냅니다.
</details>

<details><summary><b>저희는 □ ㅇ - 대신 다른 기호를 써요.</b></summary>

괜찮습니다. 번호(`1.` `1.1.` `1-1` `가.` `1)` `(1)` `①`), 로마자·영문(`Ⅰ.` `A.` `a)`), 도형(`◆ ▶ ■ ● ✓ →` 등) 어떤 체계든 위계를 읽어 단계에 맞는 서식을 입힙니다. 기호 글자는 그대로 둡니다.
</details>

<details><summary><b>PDF가 첨부 한도를 넘어요. 보안 PDF도 줄일 수 있나요?</b></summary>

파일 변환에서 **PDF 압축**을 고르면 됩니다. 스캔본·사진 PDF에서 효과가 크고(시험 문서 66~78% 감소), 한/글로 만든 글자 위주 PDF는 이미 작아 "이미 충분히 작습니다"라고 알려 줍니다.
인쇄·복사 제한이 걸린 보안 PDF는 **같은 권한 그대로** 줄입니다. 열기 암호가 걸린 PDF와 문서보안(DRM) 파일, 전자서명 PDF는 줄이지 않습니다.
</details>

<details><summary><b>줄 간격은 건드리지 않았으면 해요.</b></summary>

한 번에 적용 카드의 **줄 간격 적용**을 끄면 문서의 줄 간격을 그대로 둡니다.
</details>
